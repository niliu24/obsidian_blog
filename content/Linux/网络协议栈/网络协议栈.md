> Linux 网络协议栈是内核中最复杂且历史悠久的子系统之一，从应用层 socket 接口到网卡硬件之间，经过了多层协议封装和内核框架的处理。理解网络协议栈的分层架构，是进行高性能网络编程和网络问题排查的基础。

## 分层架构

Linux 网络协议栈从上到下分为以下几个层次：

```
用户空间应用 (read/write / send/recv)
    │
    ▼
┌─────────────────────────────────────┐
│        系统调用层 (sys_sendto)        │
├─────────────────────────────────────┤
│        Socket 通用层 (VFS)           │
│    struct socket → struct sock      │
├─────────────────────────────────────┤
│       传输层协议 (TCP/UDP)            │
│    ﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊            │
│    TCP: 面向连接、可靠、流式          │
│    UDP: 无连接、不可靠、报文          │
├─────────────────────────────────────┤
│        网络层协议 (IP)               │
│    ﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊                │
│    IPv4/IPv6: 路由查找、分片重组      │
├─────────────────────────────────────┤
│       Netfilter 钩子 (iptables/nft)  │
│    NF_IP_PRE_ROUTING / LOCAL_IN /    │
│    FORWARD / LOCAL_OUT / POST_ROUTING│
├─────────────────────────────────────┤
│        邻居子系统 (ARP/ND)            │
├─────────────────────────────────────┤
│    网络设备层 (struct net_device)     │
│    ﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊﹊                    │
│    网卡驱动 → 中断/NAPI → 收包队列    │
├─────────────────────────────────────┤
│          硬件 (NIC / PHY)            │
└─────────────────────────────────────┘
```

### 各层职责

| 层次 | 核心模块 | 职责 |
|------|----------|------|
| 系统调用层 | `sys_sendto` / `sys_recvfrom` | 用户态到内核态的入口 |
| Socket 通用层 | `net/socket.c` | VFS socket 文件系统，统一接口 |
| 传输层 | `net/ipv4/tcp_ipv4.c` / `udp.c` | 端到端可靠/不可靠传输 |
| 网络层 | `net/ipv4/ip_output.c` / `ip_input.c` | 路由、分片、转发 |
| Netfilter | `net/netfilter/` | 包过滤、NAT、连接跟踪 |
| 邻居子系统 | `net/core/neighbour.c` | ARP 协议、ND 协议 |
| 设备层 | `net/core/dev.c` | 驱动抽象、NAPI 收包、队列管理 |
| 硬件 | 网卡驱动 | DMA 收发包、中断处理 |

## 数据收发路径

### 发送路径 (send)

```
应用程序 → send() → sys_sendto()
    → sock_sendmsg() → inet_sendmsg()
    → tcp_sendmsg() / udp_sendmsg()
        → ip_queue_xmit() / ip_append_data()
            → ip_local_out() → NF_INET_LOCAL_OUT (Netfilter)
                → dst_output() → ip_finish_output()
                    → neigh_output() (ARP 查找)
                        → dev_queue_xmit() (进入 Qdisc)
                            → sch_direct_xmit() → 网卡驱动 xmit()
                                → DMA 写入 Tx 描述符 → 网卡发出
```

### 接收路径 (recv)

```
网卡收到包 → DMA 写入 Rx 描述符 → 硬件中断
    → napi_schedule() → NAPI poll()
        → netif_receive_skb() → NF_INET_PRE_ROUTING (Netfilter)
            → ip_rcv() → NF_INET_FORWARD 或 NF_INET_LOCAL_IN
                → tcp_v4_rcv() / udp_rcv()
                    → tcp_queue_skb() (放入 receive buffer)
                        → sock_def_readable() → 唤醒等待进程
                            → recvmsg() → copy_to_user() 到用户空间
```

## 核心数据结构关系

```
用户进程
    │ fd (文件描述符)
    ▼
struct file (VFS)
    │ private_data
    ▼
struct socket (Socket 层)
    │ sock
    ▼
struct sock (传输层)
    │ sk
    ▼
struct sk_buff (报文缓冲区)  ←→  sk_buff_head (双向链表)
```
