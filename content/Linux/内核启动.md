> Linux 内核启动是从系统上电到用户空间第一个进程（init）运行的完整过程。经历 BIOS/UEFI → BootLoader → Kernel → init 四个阶段，每个阶段负责硬件初始化和将控制权交给下一阶段。

## 启动阶段全景

```
电源上电
    │
    ▼
BIOS / UEFI 固件
    │  POST (Power-On Self Test)
    │  枚举 PCIe 设备、初始化关键硬件
    │  从启动设备加载 BootLoader 到内存
    ▼
BootLoader (GRUB2 / systemd-boot)
    │  加载内核 bzImage 和 initramfs 到内存
    │  设置内核命令行参数 (cmdline)
    │  跳转到内核入口 (startup_32 / startup_64)
    ▼
内核解压与初始化 (arch/x86/boot/)
    │  解压内核 (decompress_kernel)
    │  设置早期页表、切换到保护模式/长模式
    ▼
内核主线初始化 (start_kernel)
    │  架构相关初始化 (setup_arch)
    │  内存初始化 (mm_init)
    │  调度器初始化 (sched_init)
    │  中断初始化 (init_IRQ)
    │  设备驱动初始化 (do_initcalls)
    ▼
挂载根文件系统 + 启动 init (PID 1)
```

## 各阶段详解

### 1. BIOS / UEFI

| 阶段 | BIOS (Legacy) | UEFI (现代) |
|------|-------------|------------|
| 固件类型 | 16 位实模式 | 32/64 位保护模式 |
| 启动方式 | 读取 MBR (512 字节) | 读取 GPT + EFI 分区 |
| 驱动加载位置 | 0x7C00 (固定地址) | 任意地址 |
| 安全启动 | 不支持 | Secure Boot 支持 |

BIOS 在完成 POST 后，从启动设备的第 0 扇区读取 MBR（Master Boot Record），MBR 中的引导代码定位并加载 BootLoader。

### 2. BootLoader (GRUB2)

GRUB2 是 Linux 最常用的 BootLoader：

```
GRUB2 启动流程:
  Stage 1 (boot.img) → 写入 MBR，加载 Stage 1.5
  Stage 1.5 (core.img) → 在 MBR 和第一分区之间，理解文件系统
  Stage 2 → 读取 /boot/grub/grub.cfg，显示菜单，加载内核
```

GRUB2 加载的内核文件：

| 文件 | 说明 |
|------|------|
| `vmlinuz` | 压缩的 Linux 内核 (bzImage) |
| `initramfs` / `initrd` | 初始根文件系统 (tmpfs)，包含驱动和挂载工具 |

### 3. 内核启动

内核从 `arch/x86/boot/header.S` 的 `_start` 入口开始：

```
startup_32 (保护模式入口)
    → startup_64 (长模式入口)
        → extract_kernel (解压内核)
            → x86_64_start_kernel → start_kernel()
```

`start_kernel()` 是架构无关的初始化入口，调用关键初始化函数：

| 函数 | 职责 |
|------|------|
| `setup_arch()` | 架构相关初始化（页表、MMIO、中断控制器） |
| `mm_init()` | 内存管理初始化（Buddy System、SLUB） |
| `sched_init()` | 调度器初始化 |
| `init_IRQ()` | 中断子系统初始化 |
| `init_timers()` | 时钟中断初始化 |
| `vfs_caches_init()` | VFS 初始化 |
| `rest_init()` | 创建 init 进程（PID 1）和 kthreadd（PID 2） |

### 4. initramfs 与根文件系统切换

initramfs 是嵌入在 bzImage 中的 cpio 压缩包，内核启动后将其挂载为 rootfs (tmpfs)：

```
内核挂载 initramfs 为 rootfs
    → 执行 /init (sh 脚本或二进制)
        → 加载必要的内核模块 (存储驱动、文件系统驱动)
        → 挂载真正的根文件系统 (sda1 / nvme0n1)
        → switch_root → 新的根文件系统
        → /sbin/init (systemd / OpenRC)
```

## 内核命令行参数 (cmdline)

BootLoader 通过 cmdline 向内核传递配置：

```bash
# 查看当前内核启动参数
cat /proc/cmdline

# 常见参数:
# root=/dev/sda1          根文件系统位置
# ro                      只读挂载根文件系统
# quiet                   减少内核日志输出
# console=ttyS0,115200    指定串口控制台
# init=/sbin/init         指定 init 程序
```

## 内核映像结构 (bzImage)

```
bzImage:
  setup.bin              → 实模式启动代码 (header.S)
  compressed/vmlinux.bin → 解压后的内核 ELF
```
