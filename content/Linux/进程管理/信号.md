> 信号（Signal）是 Linux 中最古老的进程间异步通知机制。信号可以由内核、其他进程或进程自身发送，用于通知进程发生了某个事件。典型应用包括终止进程（SIGKILL）、定时器超时（SIGALRM）、段错误（SIGSEGV）等。

## 信号生命周期

```
发送进程/kernel: kill / tkill / 硬件异常 / 终端驱动
      │
      ▼
目标进程 PCB (task_struct.pending)
      │  信号被记录在 pending 位图中
      ▼
目标进程被调度执行
      │
      ├── 内核在返回到用户空间前检查信号 (do_signal)
      │
      ▼
信号处理:
   ├── 忽略 (SIG_IGN)
   ├── 默认动作 (Term/Ign/Core/Stop/Cont)
   └── 自定义处理函数 (signal handler / sigaction)
```

## 常用信号列表

| 信号 | 编号 | 默认动作 | 说明 |
|------|------|----------|------|
| **SIGINT** | 2 | Term | 终端中断 (Ctrl+C) |
| **SIGQUIT** | 3 | Core | 终端退出 (Ctrl+\), 生成 core dump |
| **SIGKILL** | 9 | Term | 强制终止（不可捕获/忽略/阻塞） |
| **SIGBUS** | 7 | Core | 总线错误（未对齐访问） |
| **SIGSEGV** | 11 | Core | 段错误（非法内存访问） |
| **SIGPIPE** | 13 | Term | 向已关闭的管道写入 |
| **SIGALRM** | 14 | Term | 定时器超时（alarm/setitimer） |
| **SIGTERM** | 15 | Term | 终止请求（默认 kill） |
| **SIGCHLD** | 17 | Ign | 子进程状态变化 |
| **SIGSTOP** | 19 | Stop | 停止进程（不可捕获/忽略/阻塞） |
| **SIGTSTP** | 20 | Stop | 终端停止 (Ctrl+Z) |
| **SIGUSR1** | 10 | Term | 用户自定义信号 1 |
| **SIGUSR2** | 12 | Term | 用户自定义信号 2 |

## 信号处理 API

### sigaction (推荐)

```c
#include <signal.h>
#include <stdio.h>
#include <unistd.h>

void sigint_handler(int signo)
{
    printf("Caught SIGINT (%d)\n", signo);
    _exit(0); // 信号处理函数中应使用 _exit() 而非 exit()
}

int main()
{
    struct sigaction sa = {
        .sa_handler = sigint_handler,
        .sa_flags   = SA_RESTART,  // 被信号打断的系统调用自动重启
    };
    sigemptyset(&sa.sa_mask);

    if (sigaction(SIGINT, &sa, NULL) < 0) {
        perror("sigaction");
        return 1;
    }

    printf("Press Ctrl+C... (PID=%d)\n", getpid());
    while (1) pause(); // 等待信号
    return 0;
}
```

### 信号屏蔽 (阻塞)

```c
#include <signal.h>

// 阻塞 SIGINT
sigset_t set;
sigemptyset(&set);
sigaddset(&set, SIGINT);
sigprocmask(SIG_BLOCK, &set, NULL);  // 阻塞

// ... SIGINT 不会被递送，而是保持 pending ...

sigprocmask(SIG_UNBLOCK, &set, NULL); // 解除阻塞 → pending 信号被递送
```

## 信号 vs 其他 IPC

| 特性 | 信号 | 管道 | 共享内存 |
|------|------|------|----------|
| 数据类型 | 仅信号编号 | 字节流 | 任意结构 |
| 通信方向 | 单向通知 | 单向/双向 | 双向 |
| 带宽 | 极低（仅编号） | 适中 | 极高 |
| 异步性 | 完全异步 | 同步/异步 | 同步 |
| 典型场景 | 进程控制、异常通知 | 流式数据传输 | 高频数据交换 |

## 信号处理的注意事项

- 信号处理函数应尽可能简单（仅设置标志位），避免调用非可重入函数
- `printf`/`malloc` 等 libc 函数在信号处理函数中不安全
- **可重入安全**的函数: `write()`、`_exit()`、`sem_post()`
- 从信号处理函数中正确返回: 大多数平台自动恢复，但 `SA_NODEFER` 和 `SA_RESETHAND` 可改变行为
