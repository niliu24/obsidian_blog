> Linux 进程管理子系统负责进程的创建、调度、资源管理和通信。它以 **task_struct** 为进程描述符，通过 fork/exec 创建新进程，CFS 调度器分配 CPU 时间，并提供丰富的 IPC 机制实现进程间协作。

## 核心概念

Linux 进程管理围绕以下几个关键方面展开：

* **进程描述** — 每个进程由 `task_struct` 表示，包含 PID、状态、内存空间、文件描述符、信号处理等全部上下文
* **生命周期** — 进程经过 fork → exec → exit → wait 的完整生命周期，写时拷贝 (COW) 优化 fork 性能
* **线程实现** — Linux 将线程视为 " 轻量级进程 "，通过 `clone()` 系统调用创建，NPTL 提供 1:1 内核级线程
* **CPU 调度** — CFS 调度器以虚拟运行时 (vruntime) 为公平性依据，红黑树 O(log n) 选择下一个进程
* **进程间通信** — 提供管道、信号、共享内存、消息队列、信号量、Unix 域套接字等多种 IPC 机制
