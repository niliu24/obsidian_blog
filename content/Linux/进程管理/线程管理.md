> 在 Linux 中，线程是 " 轻量级进程 "（Light-Weight Process, LWP），通过 `clone()` 系统调用创建，与父进程共享地址空间和资源。NPTL（Native POSIX Thread Library）提供 1:1 内核级线程模型及完整的 POSIX 线程 API。

## 内核线程 vs 用户线程

| 特性 | 内核线程 (Kernel Thread) | 用户线程 (User Thread) | LWP (clone 线程) |
|------|--------------------------|------------------------|------------------|
| **调度者** | 内核 CFS 调度器 | 用户态线程库 | 内核 CFS 调度器 |
| **内核可见性** | 可见，独立的 task_struct | 不可见 | 可见，独立的 task_struct |
| **系统调用开销** | 直接 | 间接（避免阻塞） | 直接 |
| **多核利用** | 是（每个线程可跑不同核） | 否（除非提前让出） | 是 |
| **创建开销** | 较大 | 很小 | 中等 |
| **典型实现** | kthreadd 创建 | 协程 / Go goroutine | pthread_create (NPTL) |

## clone() 系统调用

`clone()` 是 Linux 创建线程的核心系统调用，通过标志位精细控制父子进程的资源共享：

```c
#define _GNU_SOURCE
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>

int clone(int (*fn)(void *), void *stack, int flags, void *arg, ...);
```

### 关键标志位

| 标志 | 含义 |
|------|------|
| `CLONE_VM` | 共享内存空间（mm_struct），pthread 默认设置 |
| `CLONE_FS` | 共享文件系统信息（umask、cwd） |
| `CLONE_FILES` | 共享文件描述符表 |
| `CLONE_SIGHAND` | 共享信号处理函数表 |
| `CLONE_THREAD` | 创建线程而非进程（同线程组） |
| `CLONE_SETTLS` | 设置线程局部存储 (TLS) |
| `CLONE_PARENT` | 新进程父进程为调用者的父进程 |
| `CLONE_NEWNS` | 创建新的 mount namespace |

pthread 创建线程时典型标志组合：

```c
// 实际由 NPTL 内部使用的标志
CLONE_VM | CLONE_FS | CLONE_FILES | CLONE_SIGHAND | CLONE_THREAD | CLONE_SETTLS
```

## NPTL —— 1:1 线程模型

```
        用户空间                        内核空间
    ┌─────────────────┐          ┌─────────────────┐
    │   pthread_t 1   │◄────────►│  task_struct A  │  PID: 12345 (TGID)
    │   pthread_t 2   │◄────────►│  task_struct B  │  PID: 12346 (TID)
    │   pthread_t 3   │◄────────►│  task_struct C  │  PID: 12347 (TID)
    │   pthread_t 4   │◄────────►│  task_struct D  │  PID: 12348 (TID)
    └─────────────────┘          └─────────────────┘
                                      │ 共享 │
                              ┌───────┴───────┐
                              │ mm (地址空间)  │
                              │ files (FD表)  │
                              │ signal (处理)  │
                              └───────────────┘
```

* 每个用户线程对应一个内核 `task_struct`，由内核独立调度
* 线程组通过 `tgid` (thread group ID) 关联，也就是通常说的 PID
* 真正的线程 ID 通过 `gettid()` 系统调用获取（内核 PID）
* NPTL 取代了早期的 LinuxThreads 库，解决了信号处理、同步等问题

## POSIX 线程 API

### 创建与终止

| 函数 | 说明 |
|------|------|
| `pthread_create()` | 创建新线程 |
| `pthread_join()` | 等待线程终止并回收资源 |
| `pthread_detach()` | 分离线程（终止后自动回收） |
| `pthread_exit()` | 终止当前线程 |
| `pthread_cancel()` | 取消另一线程 |
| `pthread_self()` | 获取当前线程 ID |

```c
#include <pthread.h>
#include <stdio.h>

void *worker(void *arg) {
    int id = *(int *)arg;
    printf("Thread %d: started\n", id);
    return (void *)(long)id;
}

int main() {
    pthread_t t1, t2;
    int id1 = 1, id2 = 2;
    void *ret1, *ret2;

    pthread_create(&t1, NULL, worker, &id1);
    pthread_create(&t2, NULL, worker, &id2);

    pthread_join(t1, &ret1);
    pthread_join(t2, &ret2);

    printf("Thread %ld finished, Thread %ld finished\n",
           (long)ret1, (long)ret2);
    return 0;
}
```

编译: `gcc -pthread thread_demo.c -o thread_demo`

### 互斥锁

| 函数 | 说明 |
|------|------|
| `pthread_mutex_init()` | 初始化互斥锁 |
| `pthread_mutex_destroy()` | 销毁互斥锁 |
| `pthread_mutex_lock()` | 加锁（阻塞） |
| `pthread_mutex_trylock()` | 尝试加锁（不阻塞） |
| `pthread_mutex_unlock()` | 解锁 |

```c
#include <pthread.h>
#include <stdio.h>

#define N 1000000

pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
long counter = 0;

void *increment(void *arg) {
    for (int i = 0; i < N; i++) {
        pthread_mutex_lock(&mutex);
        counter++;
        pthread_mutex_unlock(&mutex);
    }
    return NULL;
}

int main() {
    pthread_t t1, t2;

    pthread_create(&t1, NULL, increment, NULL);
    pthread_create(&t2, NULL, increment, NULL);

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    printf("Expected: %d, Actual: %ld\n", 2 * N, counter);
    pthread_mutex_destroy(&mutex);
    return 0;
}
```

### 互斥锁类型

| 类型 | 行为 |
|------|------|
| `PTHREAD_MUTEX_NORMAL` | 标准互斥锁，死锁时直接阻塞 |
| `PTHREAD_MUTEX_ERRORCHECK` | 检测死锁，返回 EDEADLK |
| `PTHREAD_MUTEX_RECURSIVE` | 允许同一线程重复加锁 |
| `PTHREAD_MUTEX_DEFAULT` | 同 NORMAL |

### 条件变量

| 函数 | 说明 |
|------|------|
| `pthread_cond_wait()` | 等待条件（原子释放锁并阻塞） |
| `pthread_cond_signal()` | 唤醒一个等待线程 |
| `pthread_cond_broadcast()` | 唤醒所有等待线程 |

### 读写锁

| 函数 | 类型 |
|------|------|
| `pthread_rwlock_rdlock()` | 读加锁（可共享） |
| `pthread_rwlock_wrlock()` | 写加锁（独占） |

## 线程局部存储 (TLS)

### __thread 关键字

使用 GCC `__thread`（或 C11 `_Thread_local`）修饰的全局/静态变量，每个线程拥有独立副本。

```c
#include <stdio.h>
#include <pthread.h>

__thread int tls_counter = 0;  // 每个线程独立的计数器

void *thread_func(void *arg) {
    int id = *(int *)arg;
    for (int i = 0; i < 3; i++) {
        tls_counter++;
        printf("Thread %d: tls_counter = %d\n", id, tls_counter);
    }
    return NULL;
}

int main() {
    pthread_t t1, t2;
    int id1 = 1, id2 = 2;

    pthread_create(&t1, NULL, thread_func, &id1);
    pthread_create(&t2, NULL, thread_func, &id2);

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);
    return 0;
}
```

输出（顺序可能不同）：

```
Thread 1: tls_counter = 1
Thread 1: tls_counter = 2
Thread 1: tls_counter = 3
Thread 2: tls_counter = 1
Thread 2: tls_counter = 2
Thread 2: tls_counter = 3
```

### pthread_key_create

运行时动态创建 TLS 键：

```c
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>

pthread_key_t key;

void destructor(void *ptr) {
    free(ptr);
}

void *thread_func(void *arg) {
    int *val = malloc(sizeof(int));
    *val = (int)(long)arg;
    pthread_setspecific(key, val);       // 设置线程专属键值

    int *ret = pthread_getspecific(key); // 获取线程专属键值
    printf("Thread: stored %d, got %d\n", *(int *)arg, *ret);
    return NULL;
}

int main() {
    pthread_t t1, t2;

    pthread_key_create(&key, destructor);  // 创建 TLS 键和析构函数

    pthread_create(&t1, NULL, thread_func, (void *)42);
    pthread_create(&t2, NULL, thread_func, (void *)99);

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    pthread_key_delete(key);
    return 0;
}
```

## 线程安全函数

POSIX 定义的异步信号安全函数（Async-Signal-Safe）可以在信号处理函数中调用，列表包括：

* `write()`, `read()`, `open()`, `close()`
* `wait()`, `waitpid()`
* `kill()`, `raise()`
* `sigaction()`

**不安全**（不可在信号处理中调用）：

* `malloc()` / `free()` — 因为全局堆锁
* `printf()` / `sprintf()` — 因为缓冲区和锁
* `pthread_mutex_lock()` — 如果已持有锁，会死锁自己
