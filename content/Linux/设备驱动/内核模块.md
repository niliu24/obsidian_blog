> 内核模块（Kernel Module）是 Linux 内核动态扩展能力的机制。模块以 `.ko`（Kernel Object）格式的 ELF 文件存在，可在运行时加载和卸载，无需重新编译内核或重启系统。

## .ko 文件结构

内核模块是 `.ko` 格式的 ELF 文件，与用户空间 ELF 类似但包含内核特有的 section：

| Section | 用途 |
|---------|------|
| `.modinfo` | 模块信息（作者、许可证、参数描述） |
| `.gnu.linkonce.this_module` | `struct module` 实例 |
| `.init.text` | `module_init()` 函数的代码 |
| `.exit.text` | `module_exit()` 函数的代码 |
| `__versions` | 符号版本信息（CRC） |

## 模块加载流程 (`insmod`)

```
insmod → 内核 sys_finit_module()
    → load_module(): 解析 ELF、分配内存、重定位符号
    → do_init_module(): 调用 module_init()
    → 模块状态变为 MODULE_STATE_LIVE
```

## 模块卸载流程 (`rmmod`)

```
rmmod → 内核 sys_delete_module()
    → 检查模块引用计数 (try_module_get/module_put)
    → 调用 module_exit()
    → 释放模块占用的内存
```

## 常用命令

| 命令 | 功能 |
|------|------|
| `insmod mod.ko` | 加载模块（需指定路径） |
| `rmmod mod` | 卸载模块 |
| `modprobe mod` | 自动加载模块及其依赖 |
| `lsmod` | 列出已加载模块 |
| `modinfo mod.ko` | 查看模块信息 |
| `depmod` | 生成模块依赖关系 |

## Hello World 内核模块

```c
#include <linux/init.h>
#include <linux/module.h>
#include <linux/kernel.h>

MODULE_LICENSE("GPL");
MODULE_AUTHOR("Your Name");
MODULE_DESCRIPTION("A simple Hello World kernel module");
MODULE_VERSION("1.0");

static int __init hello_init(void)
{
    pr_info("Hello, Kernel! Module loaded.\n");
    return 0; // 0 = success, negative = error
}

static void __exit hello_exit(void)
{
    pr_info("Goodbye, Kernel! Module unloaded.\n");
}

module_init(hello_init);
module_exit(hello_exit);
```

对应的 Makefile：

```makefile
obj-m += hello.o

all:
    make -C /lib/modules/$(shell uname -r)/build M=$(PWD) modules

clean:
    make -C /lib/modules/$(shell uname -r)/build M=$(PWD) clean
```
