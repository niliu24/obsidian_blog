> 信号量（Semaphore）是允许固定数量持有者的睡眠锁。与 mutex（最多一个持有者）不同，信号量支持多个并发持有者，适用于资源计数场景。

## 基本 API

```c
#include <linux/semaphore.h>

DEFINE_SEMAPHORE(my_sema);  // 初始值为 1（相当于 mutex）

struct semaphore count_sema;
sema_init(&count_sema, 5); // 初始值 5, 最多 5 个并发访问

down(&count_sema);          // P 操作 (获取)，可睡眠
// ... 访问资源 ...
up(&count_sema);            // V 操作 (释放)

down_interruptible(&count_sema); // 可被信号打断的版本
down_trylock(&count_sema);       // 非阻塞版本
```

## 与 Mutex 对比

| 特性 | Mutex | Semaphore |
|------|-------|-----------|
| 最大持有者数 | 1（互斥） | 1-N（计数） |
| 优先级继承 | ✅ | ❌ |
| 使用场景 | 临界区保护 | 资源计数、生产者 - 消费者 |
| 当前推荐 | 首选 | 已被 mutex/completion 取代大部分用例 |

> 信号量在内核中大多已被 mutex 和 completion 取代，仅保留在特定的计数场景中。
