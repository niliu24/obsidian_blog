> 读写锁（Read-Write Lock）区分读和写操作：多个读者可以同时持有锁，但写者需要独占。适合读多写少的场景。

## rwlock_t (自旋版本)

```c
#include <linux/rwlock.h>

DEFINE_RWLOCK(my_rwlock);

// 读者
read_lock(&my_rwlock);      // 多个读者可同时进入
// ... 读取共享数据 ...
read_unlock(&my_rwlock);

// 写者
write_lock(&my_rwlock);     // 等待所有读者释放，然后独占
// ... 修改共享数据 ...
write_unlock(&my_rwlock);

// 中断安全版本
unsigned long flags;
read_lock_irqsave(&my_rwlock, flags);
write_lock_irqsave(&my_rwlock, flags);
```

## rwsem (睡眠版本)

```c
#include <linux/rwsem.h>

DECLARE_RWSEM(my_rwsem);

// 读者
down_read(&my_rwsem);       // 多个并发读
// ... 读取 ...
up_read(&my_rwsem);

// 写者
down_write(&my_rwsem);      // 独占
// ... 写入 ...
up_write(&my_rwsem);
```

## rwlock vs rwsem 选型

| 特性 | rwlock (自旋) | rwsem (睡眠) |
|------|-------------|-------------|
| 上下文 | 任意（中断安全） | 仅进程上下文 |
| 临界区长度 | 短 | 长（可睡眠） |
| 读端并发度 | 多读者同时 | 多读者同时 |
| 写者饥饿风险 | 有（读者优先） | 有 |
