> 原子操作（Atomic Operations）是对整数的无锁原子读写。对于简单的计数器和标志位，原子操作比锁更轻量，无需自旋或睡眠。

## 基本 API

```c
#include <linux/types.h>

atomic_t counter;    // 32 位原子变量
atomic64_t big;     // 64 位原子变量

// 初始化
atomic_set(&counter, 0);
// 或 ATOMIC_INIT(0);

// 操作
atomic_inc(&counter);                // counter++
atomic_dec(&counter);                // counter--
atomic_add(10, &counter);            // counter += 10
atomic_sub(5, &counter);             // counter -= 5
int val = atomic_read(&counter);     // 读取

// 原子操作并测试结果
int old = atomic_fetch_add(5, &counter);

// 原子条件操作
if (atomic_dec_and_test(&counter))   // 减到 0 返回 true
    pr_info("counter reached zero\n");
```

## 实现原理

原子操作在不支持单指令原子性的平台（如早期 ARM）上通过 spinlock 实现，在 x86 上直接映射为 `LOCK` 前缀指令（如 `LOCK XADD`）。
