> Linux 内存管理是内核最核心的子系统之一，负责虚拟地址到物理地址的映射、物理内存的分配与回收、进程地址空间的管理，以及缺页异常的处理。它通过硬件 MMU 配合多级页表实现高效的地址转换，并通过 Buddy System + SLUB 分配器管理物理内存。

## 核心职责

| 职责 | 说明 |
|------|------|
| 地址空间隔离 | 内核空间与用户空间分离，进程之间地址空间隔离 |
| 虚拟到物理映射 | 通过页表将虚拟地址转换为物理地址 |
| 物理内存管理 | Buddy System 管理连续物理页，SLUB 管理内核对象 |
| 缺页异常处理 | 延迟分配物理页、Swap 换入、写时复制 |
| 进程地址空间 | 管理每个进程的 text/data/heap/stack/mmap 区域 |
| 内存回收 | kswapd 回收、页面置换、OOM killer |

## 整体架构

```
用户进程 (虚拟地址空间)
    │  MMU + TLB (硬件地址转换)
    ▼
页表 (PGD → PUD → PMD → PTE)
    │
    ▼
物理内存 ── Buddy System (页级分配器)
               │
               ▼
            SLUB Allocator (内核对象缓存)
```
