> Linux 中每个进程拥有独立的虚拟地址空间，由 `mm_struct` 描述，通过若干 `vm_area_struct` (VMA) 管理不同的内存区域。进程地址空间决定了代码段、数据段、堆、栈、内存映射区等的布局和权限。

## mm_struct

每个进程的 `task_struct` 通过 `mm` 字段指向其内存描述符：

```c
// include/linux/sched.h
struct task_struct {
    // ...
    struct mm_struct   *mm;       // 进程地址空间（主进程）
    struct mm_struct   *active_mm; // 内核线程借用 active_mm
    // ...
};
```

```c
// include/linux/mm_types.h
struct mm_struct {
    struct vm_area_struct *mmap;          // VMA 链表头
    struct rb_root         mm_rb;         // VMA 红黑树根
    unsigned long          mmap_base;     // mmap 区域基址
    unsigned long          task_size;     // 用户空间大小
    pgd_t                 *pgd;           // 页全局目录（CR3 值）
    atomic_t               mm_users;      // 共享该地址空间的用户数
    atomic_t               mm_count;      // mm_struct 引用计数
    int                    map_count;     // VMA 数量
    spinlock_t             page_table_lock; // 页表锁

    // 各段边界
    unsigned long          start_code, end_code;   // 代码段
    unsigned long          start_data, end_data;   // 数据段
    unsigned long          start_brk, brk;         // 堆
    unsigned long          start_stack;            // 栈
    unsigned long          arg_start, arg_end;     // 参数
    unsigned long          env_start, env_end;     // 环境变量

    // RSS 统计
    atomic_long_t          rss_stat;               // RSS 计数
};
```

## VMA (vm_area_struct)

`vm_area_struct` 描述进程地址空间中的**一段连续的虚拟内存区域**，同一 VMA 内所有页具有相同的权限和后端存储。

```c
// include/linux/mm_types.h
struct vm_area_struct {
    unsigned long          vm_start;     // 起始地址
    unsigned long          vm_end;       // 结束地址
    struct rb_node         vm_rb;        // 红黑树节点
    struct list_head       anon_vma_chain; // 匿名 VMA 链
    struct anon_vma       *anon_vma;     // 匿名页反向映射

    const struct vm_operations_struct *vm_ops; // VMA 操作表
    struct file           *vm_file;      // 映射的文件（NULL 如果匿名）
    unsigned long          vm_pgoff;     // 文件偏移

    unsigned long          vm_flags;     // VMA 标志
    // ...
};
```

### VMA 组织方式

VMA 同时使用两种数据结构组织：

| 结构 | 用途 | 操作复杂度 |
|------|------|-----------|
| **双向链表** (`mmap`) | 遍历所有 VMA（如 `/proc/maps`） | O(n) |
| **红黑树** (`mm_rb`) | 按地址快速查找 VMA（缺页处理） | O(log n) |

### vm_flags 标志

| 标志 | 说明 |
|------|------|
| `VM_READ` | 可读 |
| `VM_WRITE` | 可写 |
| `VM_EXEC` | 可执行 |
| `VM_SHARED` | 共享映射（与其它进程共享物理页） |
| `VM_GROWSDOWN` | 可向下扩展（栈） |
| `VM_GROWSUP` | 可向上扩展（很少用） |
| `VM_IO` | 映射 MMIO 区域 |
| `VM_PFNMAP` | 直接映射物理页帧（不含 struct page） |
| `VM_MAYREAD/WRITE/EXEC/SHARE` | 允许的权限（用于 mprotect 检查） |

### 典型的 VMA 操作

```c
// 查找 addr 所在的 VMA
struct vm_area_struct *find_vma(struct mm_struct *mm, unsigned long addr);

// 插入新 VMA（mmap 系统调用路径）
unsigned long do_mmap(struct file *file, unsigned long addr,
                      unsigned long len, unsigned long prot,
                      unsigned long flags, unsigned long pgoff);

// 删除 VMA（munmap 系统调用路径）
int do_munmap(struct mm_struct *mm, unsigned long start, size_t len);
```

## 进程内存布局

x86_64 下典型进程地址空间布局（地址从低到高）：

```
0x0000000000000000
    ┌─────────────────────┐
    │  代码段 (text)       │  只读可执行, 包含程序指令
    ├─────────────────────┤
    │  数据段 (data)       │  已初始化的全局变量
    ├─────────────────────┤
    │  BSS 段              │  未初始化的全局变量（匿名映射）
    ├─────────────────────┤
    │  堆 (heap)           │  brk() 动态扩展, 低地址→高地址增长
    │     ↓                │
    │     ↑                │
    ├─────────────────────┤
    │  mmap 映射区         │  mmap 映射文件/匿名, 高地址→低地址增长
    │  共享库              │
    ├─────────────────────┤
    │     ↓                │
    │     ↑                │
    │  栈 (stack)          │  函数调用帧, 高地址→低地址增长
    ├─────────────────────┤
    │  环境变量/参数       │
    ├─────────────────────┤
    │  [vvar] [vdso]       │  内核映射（快速系统调用、时间等）  │  [vsyscall]           │
    └─────────────────────┘
0x00007FFFFFFFFFFF
```

### 各段说明

| 段 | 存储内容 | 权限 | 大小变化 | 分配方式 |
|----|----------|------|----------|----------|
| text | 程序指令 (ELF .text) | r-x | 固定 | exec 时加载 |
| data | 初始化全局变量 (ELF .data) | rw- | 固定 | exec 时加载 |
| bss | 未初始化的全局变量 (ELF .bss) | rw- | 固定 | exec 时映射零页 |
| heap | `malloc`/`new` 小对象 | rw- | `brk`/`sbrk` 动态扩展 | `brk` 系统调用 |
| mmap | 共享库、`malloc` 大对象、文件映射 | 依权限 | `mmap`/`munmap` | `mmap` 系统调用 |
| stack | 局部变量、函数调用帧 | rw- | 自动增长（`VM_GROWSDOWN`） | `page fault` 自动扩展 |
| vdso | 内核提供的用户态辅助代码 | r-x | 固定 | exec 时内核映射 |

## brk 与 mmap

进程的堆分配依赖两个系统调用：`brk` 和 `mmap`。

### brk / sbrk

`brk` 通过移动 `mm_struct->brk` 指针调整堆的结束位置。

```c
#include <unistd.h>

// sbrk(0) 返回当前堆顶
void *heap_end = sbrk(0);
printf("当前堆顶: %p\n", heap_end);

// 扩展堆 4096 字节
void *new_area = sbrk(4096);
if (new_area == (void*)-1) {
    perror("sbrk");
    return;
}

// 使用 new_area ...
strcpy(new_area, "Hello from heap");

// 缩小堆
sbrk(-4096);
```

**特点**: 只能线性扩展/收缩，**不能**释放堆中间的已分配块，仅用于 `malloc` 实现中小型分配。

### mmap 分配大内存

glibc 的 `malloc` 在分配超过 `MMAP_THRESHOLD`（默认 128 KB）时，使用 `mmap` 而非 `brk`：

```c
#include <sys/mman.h>
#include <unistd.h>

// 分配 1 MB 匿名映射
size_t size = 1024 * 1024;
void *buf = mmap(NULL, size,
                 PROT_READ | PROT_WRITE,
                 MAP_PRIVATE | MAP_ANONYMOUS,
                 -1, 0);

if (buf == MAP_FAILED) {
    perror("mmap");
    return;
}

// 使用 buf ...
// 释放
munmap(buf, size);
```

**特点**: 通过 `mmap` 分配的内存映射在 `mmap` 区域，每个映射是一个独立 VMA，可以独立释放。

### 对比

| 特性 | brk / sbrk | mmap (大块) |
|------|------------|-------------|
| 操作 | 移动堆指针 | 创建/销毁 VMA |
| 物理页分配 | 缺页时按需分配 | 缺页时按需分配 |
| 释放灵活性 | 只能 LIFO 释放 | 任意顺序 `munmap` |
| 性能 | 快（无 VMA 创建） | 中等（需 VMA 操作） |
| 适用大小 | 小对象 (< 128 KB) | 大对象 (>= 128 KB) |
| 映射类型 | 匿名 (ANON) | 匿名或文件 |

## 查看进程地址空间

### 读取 /proc/self/maps

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    FILE *maps = fopen("/proc/self/maps", "r");
    if (!maps) {
        perror("fopen");
        return 1;
    }

    char line[256];
    while (fgets(line, sizeof(line), maps)) {
        printf("%s", line);
    }
    fclose(maps);

    // 观察堆和栈地址
    int stack_var = 0;
    void *heap_var = malloc(1);
    printf("\n栈变量: %p\n", &stack_var);
    printf("堆变量: %p\n", heap_var);
    free(heap_var);

    return 0;
}
```

编译运行后输出与 `maps` 对比，可以清晰看到各段在地址空间中的位置。

### 读取 /proc/<pid>/smaps

`smaps` 提供每个 VMA 的详细内存统计：

```bash
cat /proc/self/smaps | head -30
```

```

Size:                 24 kB

Shared_Clean:         24 kB

Private_Dirty:         0 kB

Anonymous:             0 kB
```

### 关键字段含义

| 字段 | 说明 |
|------|------|
| Size | VMA 虚拟大小 |
| Rss | 驻留在物理内存中的页数 |
| Pss | Proportional Set Size（考虑共享页的比例 RSS） |
| Shared_Clean/Dirty | 与其他进程共享的干净/脏页 |
| Private_Clean/Dirty | 私有干净/脏页 |
| Swap | 已换出到 Swap 的页数 |
| AnonHugePages | 透明大页 (THP) 使用量 |
| Locked | `mlock` 锁定的页数 |

### 进程内存统计工具

```bash
# 查看进程内存摘要
cat /proc/<pid>/status | grep -E 'Vm(RSS|Size|Data|Stk|Exe)'

# 动态监测
watch -n 1 'cat /proc/<pid>/smaps | grep -E "^Pss:" | awk "{sum+=\$2} END {print sum \" kB\"}"'

# 使用 pmap
pmap -x <pid> | sort -k 2 -n -r | head -10

# 查看系统内存压力
cat /proc/pressure/memory
# some avg10=0.00 avg60=0.00 avg300=0.00 total=0
# full avg10=0.00 avg60=0.00 avg300=0.00 total=0
```
