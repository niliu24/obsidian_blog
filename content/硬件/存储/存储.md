> 存储子系统是计算机的持久化数据层，从机械硬盘 (HDD) 到固态硬盘 (SSD) 再到非易失性内存，存储技术在过去二十年经历了革命性变化。理解不同存储技术的性能特征与适用场景，是设计和优化大规模数据系统的关键。

## 存储技术演进

```
1980s-2000s        2010s             2020s
    │                 │                  │
   HDD           SATA SSD          NVMe SSD
(机械磁盘)       (SATA 接口 SSD)    (NVMe/PCIe SSD)
    │                 │                  │
   10-15ms          ~100μs           ~10μs
   100-200 IOPS     50-100K IOPS     500K-1M+ IOPS

                   Optane (3D XPoint)   ← 介于 DRAM 和 NAND 之间
                   (已停产, 被 CXL 取代)

                   CXL 内存扩展          ← 持久化内存新方向
```

## 三大主流存储对比

| 特性 | HDD (机械硬盘) | SATA SSD | NVMe SSD |
|------|---------------|---------|---------|
| 接口 | SATA / SAS | SATA | NVMe over PCIe |
| 顺序读取 | ~200 MB/s | ~550 MB/s | ~3-14 GB/s |
| 顺序写入 | ~200 MB/s | ~520 MB/s | ~2-10 GB/s |
| 随机读取 4K (IOPS) | ~100-200 | ~50,000-100,000 | ~500,000-1,500,000 |
| 随机写入 4K (IOPS) | ~100-200 | ~30,000-80,000 | ~200,000-700,000 |
| 延迟 (读) | ~5-15 ms | ~50-150 μs | ~5-20 μs |
| 延迟 (写) | ~5-15 ms | ~20-80 μs | ~10-30 μs |
| 容量 | 1-24 TB | 256 GB-4 TB | 256 GB-8 TB |
| 价格/GB | ~$0.01-0.02 | ~$0.05-0.10 | ~$0.07-0.15 |
| 寿命 (TBW) | 不受限 | 中 (60-600 TBW) | 中 - 高 (150-1200 TBW) |
| 抗震 | 差 (机械结构) | 好 (无活动部件) | 好 |
| 功耗 | ~6-10 W | ~2-5 W | ~5-10 W |

> **IOPS**：每秒输入/输出操作数 (Input/Output Operations Per Second)，是随机访问性能的核心指标。HDD 因寻道时间的物理限制，IOPS 被锁定在数百量级，SSD 则在这个维度上实现了 3-4 个数量级的飞跃。

## 何时使用哪种存储

| 场景 | 推荐存储 | 原因 |
|------|---------|------|
| 操作系统 / 应用程序 | NVMe SSD | 低延迟随机访问，系统响应快 |
| 热数据 / 数据库 WAL | NVMe SSD (Optane 级) | 低延迟、高耐久写入 |
| 温数据 / 日志归档 | SATA SSD | 平衡性能和成本 |
| 冷数据 / 备份 | HDD / 磁带 | 大容量低成本 |
| 大数据顺序读写 | HDD (大容量) | 顺序带宽尚可，成本最低 |
| 虚拟化 / 容器 | NVMe SSD | 高 IOPS 满足多租户隔离 |
| 数据库 OLTP | NVMe SSD | 随机读写关键 |
| 数据仓库 / OLAP | NVMe SSD + 大内存 | 扫描吞吐量关键 |
| 边缘 / IoT 设备 | SATA SSD / eMMC | 成本和功耗约束 |
| 分级存储 | NVMe SSD (缓存层) + HDD (容量层) | 组合最优性价比 |

### 典型分层方案

```
性能层 (NVMe SSD):  数据库热数据、缓存、索引
  │
容量层 (SATA SSD):  温数据、日志、中间结果
  │
归档层 (HDD/磁带):  备份、历史数据、合规归档
```

## NVMe 为什么比 SATA 快得多

* **协议差异**: SATA SSD 使用 AHCI 协议，设计于 HDD 时代，单队列、单中断；NVMe 使用多队列（最大 64K 队列对），充分发挥多核 CPU 并行能力
* **接口差异**: SATA 3.0 带宽上限 6 Gbps（~550 MB/s）；PCIe 3.0 x4 带宽 ~3.5 GB/s，PCIe 4.0 x4 带宽 ~7 GB/s，PCIe 5.0 x4 带宽 ~14 GB/s
* **驱动路径**: AHCI 需要经过系统中断 + 驱动轮询；NVMe 支持 polling mode + 用户态驱动 (SPDK)

## 存储性能指标速查

| 指标 | 定义 | 典型值 |
|------|------|--------|
| 延迟 (Latency) | 单次 I/O 完成时间 | HDD: 5-15ms, SSD: 10-100μs |
| IOPS | 每秒 I/O 操作数 | HDD: ~200, NVMe SSD: ~1M |
| 带宽 (Throughput) | 每秒数据传输量 | HDD: ~200MB/s, NVMe: ~7GB/s |
| 尾部延迟 (P99/P99.9) | 最慢的 1%/0.1% 操作延迟 | SSD P99: ~1ms 内 |
| 耐久度 (Endurance) | 总写入量上限 (TBW) | 消费级: 300TBW, 企业级: 10+ PBW |
