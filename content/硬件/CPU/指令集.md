> 指令集架构 (ISA) 是软件和硬件之间的**接口契约**，定义了 CPU 能执行的全部指令及其编码格式、寄存器模型、寻址模式。主流 ISA 分为 CISC（x86）和 RISC（ARM/RISC-V）两大阵营。

## CISC vs RISC

| 特性 | CISC (x86) | RISC (ARM/RISC-V) |
|------|-----------|------------------|
| **设计哲学** | 指令功能强大，一条指令完成复杂操作 | 指令简单，一条指令只完成基本操作 |
| **指令长度** | 变长（1-15 字节） | 定长（ARM: 4 字节；RV32I: 4 字节） |
| **指令数量** | 多（~1000+ 条） | 少（ARMv8: ~300 条；RV32I: ~50 条） |
| **寻址模式** | 多（~10+ 种） | 少（Load-Store 风格，~2-3 种） |
| **寄存器** | 少（16 个通用寄存器，x86-64: 16 个） | 多（ARM: 31 个；RV64I: 32 个） |
| **内存操作** | 多数指令可直接操作内存（如 `add [mem], reg`） | 只有 Load/Store 指令访问内存 |
| **译码复杂度** | 高（变长、前缀码、复杂指令边界） | 低（定长、规整、译码简单） |
| **功耗效率** | 较低 | 较高 |
| **典型代表** | Intel/AMD x86, x86-64 | ARM Cortex, Apple Silicon, RISC-V |
| **市场定位** | 桌面、服务器（性能优先） | 移动、嵌入式、IoT（功耗优先） |

> 现代 x86 CPU 内部通过**微码 (Microcode)** 将复杂 CISC 指令翻译成类似 RISC 的微操作 (μop)，再在 RISC 风格的执行核心上执行。因此，当代 x86 实际上是 "CISC 外表 + RISC 核心 "。

## x86-64 (AMD64 / Intel 64)

### 寄存器模型

x86-64 提供 16 个 64 位通用寄存器（`rax`, `rbx`, `rcx`, `rdx`, `rsi`, `rdi`, `rbp`, `rsp`, `r8`-`r15`），加上指令指针 `rip` 和标志寄存器 `rflags`。

| 寄存器 | 64 位 | 32 位 | 16 位 | 8 位 | 用途约定 (System V ABI) |
|--------|-------|-------|-------|------|------------------------|
| 累加器 | `rax` | `eax` | `ax` | `al` | 返回值 |
| 基址 | `rbx` | `ebx` | `bx` | `bl` | 被调用者保存 |
| 计数 | `rcx` | `ecx` | `cx` | `cl` | 第 4 个参数 |
| 数据 | `rdx` | `edx` | `dx` | `dl` | 第 3 个参数 |
| 源索引 | `rsi` | `esi` | `si` | `sil` | 第 2 个参数 |
| 目标索引 | `rdi` | `edi` | `di` | `dil` | 第 1 个参数 |
| 基指针 | `rbp` | `ebp` | `bp` | `bpl` | 栈帧基址 |
| 栈指针 | `rsp` | `esp` | `sp` | `spl` | 栈顶指针 |
| 临时 | `r8`-`r15` | `r8d`-`r15d` | `r8w`-`r15w` | `r8b`-`r15b` | 第 5-6 个参数 / 临时 |

### 寻址模式

x86-64 的寻址模式可概括为：

```
[ base + index * scale + displacement ]
```

| 模式 | 示例 | 说明 |
|------|------|------|
| 寄存器 | `mov rax, rbx` | `rbx` → `rax` |
| 立即数 | `mov rax, 42` | 42 → `rax` |
| 直接 | `mov rax, [0x12345678]` | 内存地址 0x12345678 的值 → `rax` |
| 基址 | `mov rax, [rbp+8]` | `rbp+8` 地址的值 → `rax` |
| 基址 + 索引 | `mov rax, [rbx+rcx*4]` | `rbx + rcx*4` 地址的值 → `rax` |
| RIP 相对 | `mov rax, [rip+offset]` | 当前指令地址 + offset → `rax`（位置无关代码） |

### 指令编码结构

x86-64 指令编码格式（最长 15 字节）：

```
[Prefix] [REX] [Opcode] [ModR/M] [SIB] [Displacement] [Immediate]
 0-4B     1B     1-3B     1B      1B     0/1/2/4B       0/1/2/4B
```

```
示例: add rax, rbx 的编码

REX.W = 0x48 (64 位操作数)
Opcode = 0x01 (ADD rm, r)
ModR/M = 0xD8 (mod=11, reg=rbx, rm=rax)

编码结果: 48 01 D8
```

## ARM (AArch64)

AArch64（ARMv8-A 开始的 64 位执行模式）是典型的 RISC 架构。

### 寄存器模型

| 寄存器类 | 数量 | 说明 |
|----------|------|------|
| 通用寄存器 `x0`-`x30` | 31 | 64 位，`w0`-`w30` 为 32 位别名 |
| 栈指针 `SP` | 1 | 与 `x31` 编码共享 |
| 零寄存器 `XZR`/`WZR` | 1 | 读返回 0，写被忽略 |
| 程序计数器 `PC` | 1 | 不可直接寻址 |
| 浮点/SIMD 寄存器 `v0`-`v31` | 32 | 128 位，可作 8/16/32/64 位的 SIMD 操作 |

调用约定 (AAPCS64)：`x0`-`x7` 参数/返回值，`x19`-`x28` 被调用者保存，`x30` 链接寄存器 (LR)。

### 固定长度编码

所有 AArch64 指令为 **32 位 (4 字节)**，简化译码：

```
31     25 24     21 20    16 15   12 11    5 4       0
┌─────────┬─────────┬─────────┬─────────┬─────────┬─────────┐
│ Opcode  │  Shift  │   Rm    │  imm6   │  Rn     │   Rd    │
└─────────┴─────────┴─────────┴─────────┴─────────┴─────────┘
```

### 加载/存储架构

只有 `ldr`/`str` 指令可访问内存，所有算术指令都在寄存器之间操作：

```asm
// AArch64 汇编示例
ldr   w0, [x1]        // 从 x1 指向的内存加载 4 字节到 w0
ldr   x2, [x3, #8]    // 从 x3+8 加载 8 字节到 x2
add   w4, w0, w5      // w4 = w0 + w5（寄存器运算）
mul   x6, x2, x7      // x6 = x2 * x7
str   w4, [x1]        // 将 w4 写回 x1 指向的内存
```

## RISC-V

RISC-V 是**开放、模块化**的 ISA，由 UC Berkeley 设计，RISC-V 基金会维护。

### 模块化 ISA 设计

```
基础整数 ISA (必需)             可选扩展
┌──────────────────┐    ┌──────────────────────┐
│  RV32I / RV64I    │    │  M: 整数乘除扩展       │
│  ~50 条指令        │    │  A: 原子操作扩展        │
│  32/64 位寄存器     │    │  F/D: 单/双精度浮点     │
│  固定 32 位编码     │    │  C: 压缩指令 (16 位)   │
└──────────────────┘    │  V: 向量扩展            │
                        │  B: 位操作扩展           │
                        │  K: 密码学扩展           │
                        │  H: 虚拟化扩展           │
                        └──────────────────────┘
```

| 基础 ISA | 地址空间 | 寄存器宽度 | 典型用途 |
|----------|---------|-----------|---------|
| **RV32I** | 32 位 | 32 位 | 微控制器、IoT |
| **RV64I** | 64 位 | 64 位 | 应用处理器、桌面、服务器 |
| **RV128I** | 128 位 | 128 位 | 未来大地址空间（实验性） |

### RISC-V 指令格式

RISC-V 所有指令为 32 位（RV32I/RV64I），按操作数类型分为 6 种格式：

```
    31    27 26  25 24   20 19   15 14   12 11    7 6       0
R:  ┌─────────┬─────┬────────┬────────┬───────┬────────┬────────┐
    │ funct7  │ rs2 │  rs1   │ funct3 │  rd   │ opcode │
    └─────────┴─────┴────────┴────────┴───────┴────────┴────────┘

I:  ┌───────────────────┬────────┬───────┬────────┬────────┐
    │    imm[11:0]      │  rs1   │funct3 │   rd   │ opcode │
    └───────────────────┴────────┴───────┴────────┴────────┘

S:  ┌─────────┬─────┬────────┬────────┬──────────┬────────┐
    │imm[11:5]│ rs2 │  rs1   │funct3 │ imm[4:0] │ opcode │
    └─────────┴─────┴────────┴────────┴──────────┴────────┘

B:  ┌─────────┬─────┬────────┬────────┬──────────┬────────┐
    │imm[12]  │ rs2 │  rs1   │funct3 │ imm[4:1] │ opcode │
    │imm[10:5]│     │        │       │ imm[11]  │        │
    └─────────┴─────┴────────┴────────┴──────────┴────────┘

U:  ┌───────────────────────────┬──────────┬────────┐
    │       imm[31:12]          │   rd     │ opcode │
    └───────────────────────────┴──────────┴────────┘

J:  ┌───────────────────────────┬──────────┬────────┐
    │ imm[20][10:1][11][19:12]  │   rd     │ opcode │
    └───────────────────────────┴──────────┴────────┘
```

```asm
# RISC-V RV64I 汇编示例
add   x1, x2, x3      # x1 = x2 + x3
addi  x4, x5, 42      # x4 = x5 + 42
lw    x6, 0(x7)       # x6 = *(int*)x7
sw    x6, 4(x8)       # *(int*)(x8+4) = x6
beq   x1, x2, label   # if x1 == x2 goto label
jal   x0, func        # 无条件跳转到 func（x0 = 废弃的返回地址）
```

## SIMD 扩展

SIMD (Single Instruction, Multiple Data) 让一条指令同时处理多个数据元素。

### x86 SIMD 扩展一览

| 扩展 | 推出年份 | 寄存器 | 位宽 | 数据类型 |
|------|---------|--------|------|---------|
| **MMX** | 1997 | `mm0`-`mm7` | 64 位 | 整数（复用 x87 寄存器） |
| **SSE** | 1999 | `xmm0`-`xmm15` | 128 位 | 单精度浮点 + 整数 |
| **SSE2** | 2001 | `xmm0`-`xmm15` | 128 位 | 双精度浮点 + 更多整数 |
| **SSSE3/SSE4** | 2006-2008 | `xmm0`-`xmm15` | 128 位 | 洗牌、点积、字符串处理 |
| **AVX** | 2011 (Sandy Bridge) | `ymm0`-`ymm15` | 256 位 | 浮点 + 整数 |
| **AVX2** | 2013 (Haswell) | `ymm0`-`ymm15` | 256 位 | 整数 + 聚集 (Gather) |
| **AVX-512** | 2017 (Skylake-X) | `zmm0`-`zmm31` | 512 位 | 掩码 + 广播 + 冲突检测 |
| **AVX10** | 2023 | `zmm` | 128/256/512 | 统一 AVX-512 到所有核心 |

### SIMD 向量加法概念

```c
// 标量版本：串行加法
void add_arrays_scalar(float *a, float *b, float *c, int n) {
    for (int i = 0; i < n; i++) {
        c[i] = a[i] + b[i];
    }
}

// 编译器自动向量化 (使用 -O2 -march=native -ftree-vectorize)
// 编译器会自动生成 SSE/AVX 指令
```

```asm
; AVX 向量加法（一次处理 8 个单精度浮点数）
; a_addr 在 rdi, b_addr 在 rsi, c_addr 在 rdx
; 256 位 ymm 寄存器 = 8 × 32 位 float

loop:
    vmovups ymm0, [rdi + rcx]      ; 加载 a[i..i+7] 到 ymm0
    vmovups ymm1, [rsi + rcx]      ; 加载 b[i..i+7] 到 ymm1
    vaddps  ymm0, ymm0, ymm1       ; 8 个浮点同时相加
    vmovups [rdx + rcx], ymm0      ; 存回 c[i..i+7]
    add     rcx, 32                ; 前进 32 字节 (8 个 float)
    cmp     rcx, rdi_size          ; 比较是否处理完
    jl      loop                   ; 循环
```

```
标量加法:          a0  +  b0  →  c0     ← 1 条加法指令
                  a1  +  b1  →  c1     ← 再 1 条
                  ... (共 n 条指令)

AVX 向量加法:     a0 a1 ... a7  +  b0 b1 ... b7  →  c0 c1 ... c7  ← 1 条 vaddps 指令
                  (一条指令处理 8 个浮点加法，吞吐提升 8x)
```

| 数据类型 | SSE (128-bit) | AVX (256-bit) | AVX-512 |
|----------|--------------|--------------|---------|
| `float` (32-bit) | 4 个 | 8 个 | 16 个 |
| `double` (64-bit) | 2 个 | 4 个 | 8 个 |
| `int32` (32-bit) | 4 个 | 8 个 | 16 个 |
| `int64` (64-bit) | 2 个 | 4 个 | 8 个 |

### ARM SIMD 扩展

| 扩展 | 寄存器 | 位宽 | 说明 |
|------|--------|------|------|
| **NEON** | `v0`-`v31` | 128 位 | ARMv7 引入，ARMv8 必选，支持整数和浮点 SIMD |
| **SVE** (Scalable Vector Extension) | `z0`-`z31` | 128-2048 位 (可变) | ARMv8.2 引入，向量长度对软件透明 |
| **SVE2** | `z0`-`z31` | 128-2048 位 | ARMv9 必选，增强加密和 DSP 操作 |

> NEON 固定 128 位；SVE 的向量长度由硬件实现决定（如 Fujitsu A64FX 为 512 位），软件可自适应。

## ISA 比较总结

| 特性 | x86-64 | ARM AArch64 | RISC-V (RV64GC) |
|------|--------|-------------|-----------------|
| **设计哲学** | CISC 变长 | RISC 定长 | RISC 定长 + 模块化 |
| **指令长度** | 1-15 字节 | 4 字节 | 4 字节（加 C 扩展可混合 2 字节） |
| **通用寄存器** | 16 | 31 | 32 |
| **指令数量** | ~1500+ | ~300 | ~50 (RV64I) + 扩展 |
| **条件码** | EFLAGS 隐式 | 无（条件执行用分支） | 无（条件执行用分支） |
| **内存模型** | 强有序 (TSO) | 弱有序 (RCsc) | 弱有序 (RVWMO) |
| **授权** | 专有 (Intel/AMD) | 专有 (ARM) | **开源免授权** |
| **主要市场** | 桌面、服务器 | 移动、嵌入式、服务器 | 灵活（嵌入到超级计算机） |
| **SIMD** | SSE/AVX/AVX-512 | NEON/SVE/SVE2 | V 扩展 (向量) |
| **最新版本** | x86-64 (2003/2008) | ARMv9.2 (2021) | RISC-V 2024 规范 |
