> 总线（Bus）是计算机系统中连接 CPU、内存、GPU 和外设的通信骨干。总线的带宽和延迟直接决定了数据在组件之间流动的速度，是系统性能的关键瓶颈之一。

## 数据流路径

```
CPU ←→ Memory (通过内存控制器)
  ↑
  PCIe Root Complex
  ↑
PCIe Switch (可选)
  ↑
GPU / NVMe SSD / NIC / 其他外设
```

* **CPU ↔ GPU**: 显存访问（通过 BAR）、命令提交（通过 Doorbell）、DMA 传输，全部经过 PCIe
* **CPU ↔ Storage**: NVMe SSD 通过 PCIe 直连，延迟低至微秒级
* **CPU ↔ NIC**: 高速网卡通过 PCIe 传输网络数据，依赖 MSI-X 多队列中断
* **CPU ↔ Memory**: 内存通过内存总线直连（非 PCIe），但 CXL 正在将 PCIe PHY 引入缓存一致性域

## 核心指标

| 指标 | 说明 |
|------|------|
| 带宽 | 每秒可传输的数据量（GB/s），取决于通道数 × 每通道速率 × 编码效率 |
| 延迟 | 一次事务从发起到完成的时间（纳秒/微秒级） |
| 拓扑 | 组件间的连接方式（点对点 / 树形 / 网状） |
| 协议开销 | 编码方案引入的有效数据比例（如 128b/130b 编码损失 ~1.5%） |

## 其他总线

| 总线 | 速率 | 典型用途 |
|------|------|----------|
| USB 3.2 Gen2x2 | 20 Gbps | 外设（键鼠、存储、摄像头） |
| USB4 | 40 Gbps | 外设 + Thunderbolt 兼容 + PCIe tunneling |
| SATA III | 6 Gbps | 传统硬盘/SSD（逐步被 NVMe 取代） |
| I2C | 100 Kbps~3.4 Mbps | 板级低速设备（温度传感器、EEPROM、电源管理） |
| SPI | 数十 Mbps | 板级中速设备（Flash、显示控制器、ADC/DAC） |

## 调试工具

```bash
# 查看 PCIe 拓扑树
lspci -t

# 查看所有 PCIe 设备的详细信息（包括 BAR、Capabilities）
lspci -vvv

# 查看 PCIe 地址空间映射
cat /proc/iomem

# 查看 DMA 分配情况
cat /proc/iomem | grep -i dma

# 查看 MSI/MSI-X 中断分布
cat /proc/interrupts

# PCIe 错误统计
cat /sys/kernel/debug/pci/*/err_status
```
