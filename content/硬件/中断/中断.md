> 中断（Interrupt）是硬件向 CPU 异步通知事件发生的机制，使 CPU 无需轮询即可响应外设、定时器、错误等事件。从 8259 PIC 到 APIC 再到 MSI/MSI-X，中断机制经历了从物理线到消息化的演变。

## 中断演进

```
8259 PIC (1981, PC/AT)
  → APIC (1990s, Pentium, SMP)
    → MSI/MSI-X (2000s, PCIe, 消息中断)
```

| 阶段                      | 特点                                 | 限制                     |
| ----------------------- | ---------------------------------- | ---------------------- |
| [8259 PIC](8259-PIC.md) | 15 个 IRQ 线 + 级联                    | 单 CPU、IRQ 线有限、不可扩展     |
| [APIC](APIC.md)         | Local APIC + I/O APIC，支持 SMP       | 仍需物理线连接 I/O APIC       |
| [MSI/MSI-X](MSI.md)     | 中断通过 PCIe Memory Write TLP 发送，无物理线 | 设备必须支持 PCIe Capability |

## Linux 中断处理

中断在 Linux 内核中的完整处理流程，包括 Top Half/Bottom Half 分离设计、request_irq 注册机制、softirq/tasklet/workqueue 底半部对比、irq_desc/irq_chip/irq_domain 子系统架构、Threaded IRQ 机制、中断延迟分析、PREEMPT_RT 实时性以及调试工具，详见 [Linux 中断处理](../../Linux/中断处理/中断处理.md)。
