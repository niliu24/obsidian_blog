> Intel 8259A 是早期 x86 平台的可编程中断控制器（Programmable Interrupt Controller），为单 CPU 系统设计，通过 IRQ 引脚接收外设中断并转发给 CPU。

## 架构

```
外设 → IRQ 引脚 → 8259A → INTR 引脚 → CPU
                    ↑
                    ├── 向量号 (IVR)
                    ├── 优先级仲裁器
                    └── 级联控制
```

每个 8259 管理 8 个 IRQ 输入，两片级联提供 15 个 IRQ：

```
Master (8259A #1)            Slave (8259A #2)
  IRQ0 → 定时器                IRQ8  → RTC
  IRQ1 → 键盘                  IRQ9  → ACPI / 其他
  IRQ2 → 级联到 Slave ──────►  IRQ10 → 保留
  IRQ3 → COM2                  IRQ11 → 保留
  IRQ4 → COM1                  IRQ12 → PS/2 鼠标
  IRQ5 → 声卡 / LPT2           IRQ13 → FPU
  IRQ6 → 软盘控制器            IRQ14 → 主 ATA
  IRQ7 → LPT1                  IRQ15 → 从 ATA
```

## 工作流程

1. 外设拉高 IRQ 引脚
2. 8259A 检查 IMR（Interrupt Mask Register），若未屏蔽则锁存到 IRR
3. 优先级仲裁器比较 IRR 中所有 pending 位，选出最高优先级
4. 向 CPU 发出 INTR 信号
5. CPU 响应（INTA 周期），8259A 将对应向量号放到数据总线
6. CPU 读取向量号，跳转到 IDT 对应表项执行 ISR

## 寄存器

| 寄存器 | 全称 | 功能 |
|--------|------|------|
| IRR | Interrupt Request Register | 记录已到达但未服务的请求 |
| ISR | In-Service Register | 记录正在被 CPU 服务的中断 |
| IMR | Interrupt Mask Register | 位掩码屏蔽特定 IRQ |
| ICW1-4 | Initialization Command Words | 初始化配置（级联、触发方式、向量基址） |
| OCW1-3 | Operation Control Words | 运行时控制（EOI、屏蔽、优先级轮转） |

## 缺陷

| 问题 | 影响 |
|------|------|
| 15 个 IRQ 上限 | 无法满足外设数量增长 |
| IRQ 共享困难 | 多个设备共用同一 IRQ 时 ISR 需遍历链表 |
| 无 SMP 支持 | 多 CPU 系统中无法路由中断到指定核心 |
| 固定优先级 | 无法动态调整优先级 |
| 物理线限制扩展性 | 每增加 IRQ 需要额外引脚 |
