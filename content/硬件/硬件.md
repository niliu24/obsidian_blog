> 计算机硬件以**冯·诺依曼架构**为基础，由控制单元、算术逻辑单元、存储器、输入和输出五大部分组成。现代系统在此基础上扩展为包含 CPU、GPU、内存、存储、总线和中断机制的复杂层次结构。

## 冯·诺依曼架构

冯·诺依曼架构（Von Neumann Architecture）的核心思想是**存储程序**——指令和数据存放在同一存储器中，由程序计数器顺序驱动执行。

```
┌─────────────────────────────────────────────────────────┐
│                     冯·诺依曼体系结构                       │
│                                                         │
│  ┌──────────────┐         ┌──────────────────┐          │
│  │   控制单元      │◄──控制──┤                  │          │
│  │  (Control     │──状态──►│    主存储器        │          │
│  │   Unit)       │         │  (指令 + 数据)     │          │
│  └──────┬───────┘         └──────────────────┘          │
│         │     ▲                      ▲                   │
│         │     │                      │                   │
│  ┌──────▼──────┴──┐         ┌───────┴────────┐          │
│  │   输入设备       │         │    输出设备       │          │
│  │  (Input)       │         │   (Output)      │          │
│  └────────────────┘         └────────────────┘          │
│                                                         │
│  ┌────────────────────────────────────────────────┐     │
│  │          算术逻辑单元 (ALU)                      │     │
│  └────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────┘
```

### 五大部分

| 部件 | 功能 |
|------|------|
| **控制单元 (CU)** | 从存储器取指令、译码、产生控制信号驱动数据通路 |
| **算术逻辑单元 (ALU)** | 执行算术（加减乘除）和逻辑（与或非异或）运算 |
| **主存储器 (Memory)** | 存放指令和数据，按地址访问，统一编址 |
| **输入设备 (Input)** | 将外部数据送入计算机（键盘、鼠标、网卡、磁盘） |
| **输出设备 (Output)** | 将计算结果输出到外部（显示器、打印机、网卡、磁盘） |

### 冯·诺依曼 vs 哈佛架构

| 特性 | 冯·诺依曼 | 哈佛架构 |
|------|-----------|----------|
| 指令与数据存储 | 同一存储器、同一总线 | 独立存储器、独立总线 |
| 并行度 | 指令和数据不能同时取（冯·诺依曼瓶颈） | 可同时取指令和数据 |
| 典型应用 | 通用计算机（x86、ARM） | 嵌入式/DSP（单片机、MCU） |
| 修改程序 | 容易（自修改代码） | 困难（指令 ROM 不可写） |
| 现代变体 | — | **Modified Harvard**（独立 L1 指令/数据缓存，共享 L2/L3 内存） |

> 现代 CPU 内部实际采用 **Modified Harvard 架构**——L1 缓存分指令缓存 (I-cache) 和数据缓存 (D-cache)，但共享同一主存地址空间。

## 硬件层次结构

计算机硬件按速度与容量构成金字塔层次：

```
               寄存器          ◄── 1 周期 (~0.3 ns)
              ┌─────┐
             │ L1  │            ◄── 3-5 周期 (~1 ns)
            │  L2  │           ◄── 10-15 周期 (~4 ns)
           │   L3  │          ◄── 30-50 周期 (~10 ns)
          │  主存   │          ◄── 100-300 周期 (~100 ns)
         │  本地SSD │         ◄── 10-100 μs
        │  网络存储  │        ◄── 1-100 ms
```

| 层级 | 典型延迟 | 容量 | 由谁管理 |
|------|---------|------|---------|
| 寄存器 | ~0.3 ns | 几百字节 | 编译器/硬件 |
| L1 缓存 | ~1 ns | 32-64 KB | 硬件 |
| L2 缓存 | ~4 ns | 256-512 KB | 硬件 |
| L3 缓存 | ~10 ns | 2-32 MB | 硬件 |
| DRAM 主存 | ~100 ns | 8-512 GB | 操作系统 |
| SSD (NVMe) | ~10 μs | 256 GB-2 TB | 操作系统/驱动 |
| HDD | ~10 ms | 1-20 TB | 操作系统/驱动 |
