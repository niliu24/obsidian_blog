> 栈和队列是两种受限访问的线性数据结构。栈遵循 LIFO（后进先出），队列遵循 FIFO（先进先出）。它们的操作都是 O(1)，是许多高级算法和系统设计的基础组件。

## 栈 (Stack) — LIFO

### 基本操作

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| `push(val)` | O(1) | 入栈 |
| `pop()` | O(1) | 出栈 |
| `top()` / `peek()` | O(1) | 查看栈顶 |
| `isEmpty()` | O(1) | 判空 |

### 顺序栈实现

```cpp
template<typename T>
class ArrayStack {
    std::vector<T> data;
public:
    void push(const T& val) { data.push_back(val); }
    void pop()              { data.pop_back(); }
    T& top()               { return data.back(); }
    bool empty()           { return data.empty(); }
};
```

### 应用场景

| 场景 | 说明 |
|------|------|
| 函数调用栈 | 局部变量、返回地址、栈帧管理 |
| 括号匹配 | `{[()]}` 合法性检查 |
| 表达式求值 | 中缀→后缀、后缀求值 |
| DFS 非递归 | 手动用栈模拟系统调用栈 |
| 撤销/重做 | Ctrl+Z 和 Ctrl+Y 的实现 |
| 浏览器的前进/后退 | 两个栈维护访问历史 |

### 单调栈 (Monotonic Stack)

栈内元素保持单调递增/递减，用于 O(n) 解决 " 下一个更大/更小元素 " 问题：

```cpp
// 寻找每个元素的下一个更大元素 (NGE)
vector<int> nextGreaterElement(vector<int>& nums) {
    vector<int> res(nums.size(), -1);
    stack<int> st;  // 单调递减栈, 存下标
    for (int i = 0; i < nums.size(); i++) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            res[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return res;
}
```

## 队列 (Queue) — FIFO

### 基本操作

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| `push(val)` / `enqueue` | O(1) | 入队 |
| `pop()` / `dequeue` | O(1) | 出队 |
| `front()` | O(1) | 查看队首 |
| `isEmpty()` | O(1) | 判空 |

### 循环队列

用定长数组实现，通过两个指针 + 取模避免搬移：

```cpp
template<typename T>
class CircularQueue {
    std::vector<T> data;
    int head = 0, tail = 0, size = 0;
public:
    CircularQueue(int cap) : data(cap) {}
    bool enqueue(const T& val) {
        if (size == data.size()) return false;
        data[tail] = val;
        tail = (tail + 1) % data.size();
        size++;
        return true;
    }
    T dequeue() {
        T val = data[head];
        head = (head + 1) % data.size();
        size--;
        return val;
    }
    bool empty() { return size == 0; }
};
```

### 单调队列 (Monotonic Queue)

滑动窗口最大值/最小值 O(n) 解法：

```cpp
// 滑动窗口最大值
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    vector<int> res;
    deque<int> dq;  // 存下标, 维护单调递减
    for (int i = 0; i < nums.size(); i++) {
        // 移除窗口外的元素
        if (!dq.empty() && dq.front() <= i - k)
            dq.pop_front();
        // 维护单调性: 弹出所有小于当前值的元素
        while (!dq.empty() && nums[dq.back()] < nums[i])
            dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1)
            res.push_back(nums[dq.front()]);
    }
    return res;
}
```

## 双端队列 (Deque)

两端都可以插入和删除的队列，C++ `std::deque` 是分段连续内存实现：

```cpp
#include <deque>
std::deque<int> dq;
dq.push_front(1);  // 头部插入 O(1)
dq.push_back(2);   // 尾部插入 O(1)
dq.pop_front();    // 头部删除 O(1)
dq.pop_back();     // 尾部删除 O(1)
dq[0];             // 随机访问 O(1)
```

## 栈 vs 队列选型

| 场景 | 结构 |
|------|------|
| 括号匹配 / 表达式求值 | 栈 |
| BFS / 消息队列 / 任务调度 | 队列 |
| LRU 缓存 | 双向链表 + 哈希表 |
| 滑动窗口 | 单调队列 (Deque) |
| 下一个更大元素 | 单调栈 |
| 双端 BFS | 双端队列 |
