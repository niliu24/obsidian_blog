> 数组和链表是最基础的两种线性数据结构。数组提供 O(1) 随机访问但插入/删除需 O(n) 搬移；链表插入/删除 O(1) 但查找需 O(n)。它们是所有其他数据结构的基础构件。

## 数组 (Array)

连续内存存储，通过下标 O(1) 访问。

### 动态数组

```cpp
// C++ std::vector — 动态扩容数组
std::vector<int> v;
v.push_back(1);  // 均摊 O(1)，尾部插入
v[0];            // O(1) 随机访问

// 扩容策略: 容量翻倍(×2)，均摊 O(1)
// 均摊分析: n 次 push_back 总拷贝次数 = 1+2+4+...+n/2 < 2n
```

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 随机访问 | O(1) | 下标直接寻址 |
| 尾部插入 | O(1)* | 均摊 O(1)，触发扩容时 O(n) |
| 中间插入 | O(n) | 需搬移插入点后的元素 |
| 删除 | O(n) | 需搬移删除点后的元素 |
| 查找 | O(n) | 线性扫描 |

### 内存特性

- **缓存友好**: 连续内存，预取命中率高
- **空间浪费**: 动态数组预留容量未满时存在浪费

## 链表 (Linked List)

节点包含数据 + 指针，散落在内存各处。

### 单向链表

```
head → [data|next] → [data|next] → [data|next] → NULL
```

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(nullptr) {}
};

// 头插法 O(1)
ListNode *new_node = new ListNode(val);
new_node->next = head;
head = new_node;

// 删除节点 O(1) (已知前驱)
prev->next = cur->next;
delete cur;
```

### 双向链表

```
head ⇄ [prev|data|next] ⇄ [prev|data|next] ⇄ [prev|data|next] ⇄ tail
```

| 操作 | 单向链表 | 双向链表 |
|------|---------|---------|
| 头部插入 | O(1) | O(1) |
| 尾部插入 | O(n) / O(1)(有尾指针) | O(1) |
| 已知节点删除 | O(n)(需找前驱) | O(1) |
| 查找 | O(n) | O(n) |

### 经典问题

```cpp
// 反转链表
ListNode* reverse(ListNode *head) {
    ListNode *prev = nullptr, *cur = head;
    while (cur) {
        ListNode *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}

// 快慢指针 — 找中点/检测环
ListNode* findMiddle(ListNode *head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

## 跳表 (Skip List)

在有序链表上增加多层索引，实现 O(log n) 查找。Redis 有序集合 (ZSet) 的底层实现之一。

```
Level 3:  1 ──────────────────────→ 8
Level 2:  1 ──────→ 4 ────────────→ 8
Level 1:  1 → 2 → 4 → 5 ──→ 7 → 8 → 9
Base:     1 → 2 → 4 → 5 → 7 → 8 → 9 → 10
```

* **查找**: 从最高层开始，向右移动直到大于目标值，向下移一层，重复
* **插入**: 随机生成层数，逐层插入节点
* **复杂度**: 查找/插入/删除均为 O(log n) 期望

## 数组 vs 链表选型

| 场景 | 推荐 | 原因 |
|------|------|------|
| 频繁随机访问 | 数组 | O(1) vs O(n) |
| 频繁头部插入/删除 | 链表 | O(1) vs O(n) |
| 缓存敏感 | 数组 | 连续内存，高缓存命中 |
| LRU 缓存 | 双向链表+哈希表 | O(1) 移动节点 |
| 栈/队列实现 | 动态数组 | 均摊 O(1) + 缓存友好 |
