> 图（Graph）是一组顶点和边的集合，是最通用的数据结构。几乎所有复杂的关系模型都可以抽象为图：社交网络的人物关系、城市间的道路、网页的超链接、任务间的依赖关系。图的表示和遍历是所有图算法的基础。

## 图的基本概念

| 概念 | 说明 |
|------|------|
| 顶点 (Vertex) | 图中的节点，集合 V |
| 边 (Edge) | 顶点间的连接，集合 E |
| 有向/无向 | 边是否有方向 |
| 权值 (Weight) | 边上的数值，表示距离/代价/容量 |
| 度 (Degree) | 与该顶点相连的边数 |
| 路径 (Path) | 顶点序列，相邻顶点有边相连 |
| 环 (Cycle) | 起点=终点的路径 |
| 连通分量 | 图中连通的最大子图 |

## 图的存储

### 邻接矩阵

```
   0 1 2 3
  ┌───────┐
0 │0 1 0 1│
1 │1 0 1 0│
2 │0 1 0 1│
3 │1 0 1 0│
  └───────┘
```

| 特性 | 复杂度 |
|------|--------|
| 空间 | O(V²) |
| 检测边 | O(1) |
| 遍历邻接点 | O(V) |
| 适合场景 | 稠密图 (E≈V²) |

### 邻接表

```
0 → [1→3]
1 → [0→2]
2 → [1→3]
3 → [0→2]
```

```cpp
// 邻接表实现
struct Graph {
    vector<vector<pair<int, int>>> adj; // adj[u] = {v, weight}

    Graph(int n) : adj(n) {}

    void addEdge(int u, int v, int w) {
        adj[u].emplace_back(v, w);
        // 无向图加: adj[v].emplace_back(u, w);
    }
};
```

| 特性 | 复杂度 |
|------|--------|
| 空间 | O(V + E) |
| 检测边 | O(degree(v)) |
| 遍历邻接点 | O(degree(v)) |
| 适合场景 | 稀疏图 (E≪V²) |

### 存储方式对比

| 图类型 | 推荐存储 | 理由 |
|--------|---------|------|
| 稠密图 (E≈V²) | 邻接矩阵 | O(V²) 空间但 O(1) 查边 |
| 稀疏图 (E≪V²) | 邻接表 | 更省空间 |
| 频繁查边 | 邻接矩阵 | O(1) |
| 频繁遍历 | 邻接表 | 不扫描不存在边 |

## 图的表示变体

| 表示方式 | 适用场景 |
|----------|----------|
| **边列表** | Kruskal 算法、批量处理 |
| **前向星** | 按起始点排序的边列表，内存紧凑 |
| **十字链表** | 有向图同时快速获取出边和入边 |
| **邻接多重表** | 无向图快速删除边 |
