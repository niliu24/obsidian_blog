> 分治（Divide & Conquer）和回溯（Backtracking）是两种核心的算法范式。分治将大问题递归拆为独立小问题再合并，各子问题互不重叠；回溯在解空间中系统搜索，通过剪枝（pruning）缩小搜索空间。它们各自统治了排序、FFT、排列组合和约束满足问题。

## 分治三步骤

```
1. 分解 (Divide):   将原问题分解为若干个规模较小的同类子问题
2. 解决 (Conquer):  递归求解子问题。若子问题足够小则直接求解
3. 合并 (Combine):  将各子问题的解合并为原问题的解
```

### 递推关系与复杂度

| 递推式 | 复杂度 | 示例 |
|--------|--------|------|
| `T(n) = 2T(n/2) + O(n)` | O(n log n) | 归并排序、快速排序 (平均) |
| `T(n) = 2T(n/2) + O(1)` | O(n) | 线段树建树 |
| `T(n) = T(n-1) + O(n)` | O(n²) | 回溯 N 皇后 |
| `T(n) = 2T(n-1) + O(1)` | O(2ⁿ) | 子集枚举 |
| `T(n) = T(n/2) + O(1)` | O(log n) | 二分查找 |

### 主定理 (Master Theorem)

对于递推式 `T(n) = a·T(n/b) + f(n)`:

| 条件 | T(n) |
|------|------|
| f(n) = O(n^(log_b a - ε)) | Θ(n^(log_b a)) |
| f(n) = Θ(n^(log_b a)) | Θ(n^(log_b a) · log n) |
| f(n) = Ω(n^(log_b a + ε)) + 正则条件 | Θ(f(n)) |

## 经典分治实例

### 快速幂

```cpp
// xⁿ 用 O(log n) 而非 O(n)
double fastPow(double x, int n) {
    if (n == 0) return 1;
    double half = fastPow(x, n / 2);
    return n % 2 == 0 ? half * half : half * half * x;
}
```

### 大整数乘法 (Karatsuba)

```
X = a·2^(n/2) + b, Y = c·2^(n/2) + d
X·Y = ac·2ⁿ + ((a+b)(c+d) - ac - bd)·2^(n/2) + bd

T(n) = 3T(n/2) + O(n) = O(n^1.585)
比传统 O(n²) 更快
```

## 回溯算法

回溯在解空间中通过 " 尝试 → 检查 → 撤销 " 的循环系统搜索。核心是**搜索树**的构造和**剪枝**。

### 回溯框架

```cpp
void backtrack(状态& state, 路径& path) {
    if (终止条件) {
        保存解;
        return;
    }
    for (选择 : 候选集合) {
        if (无效选择) continue;  // 剪枝
        path.push(选择);
        backtrack(新状态, path);  // 递归
        path.pop();                // 撤销 (回溯)
    }
}
```

### N 皇后问题

```cpp
vector<vector<string>> solveNQueens(int n) {
    vector<vector<string>> res;
    vector<string> board(n, string(n, '.'));
    vector<bool> col(n), diag1(2*n), diag2(2*n);

    function<void(int)> dfs = [&](int row) {
        if (row == n) {
            res.push_back(board);
            return;
        }
        for (int c = 0; c < n; c++) {
            int d1 = row - c + n, d2 = row + c;
            if (col[c] || diag1[d1] || diag2[d2]) continue;  // 剪枝
            col[c] = diag1[d1] = diag2[d2] = true;
            board[row][c] = 'Q';
            dfs(row + 1);
            board[row][c] = '.';
            col[c] = diag1[d1] = diag2[d2] = false;
        }
    };
    dfs(0);
    return res;
}
```

复杂度分析：合法解的数量是 O(n!)，但剪枝后实际搜索节点远小于 n!。

### 全排列

```cpp
vector<vector<int>> permute(vector<int>& nums) {
    vector<vector<int>> res;
    sort(nums.begin(), nums.end()); // 去重用
    vector<bool> used(nums.size());

    function<void(vector<int>&)> dfs = [&](vector<int>& cur) {
        if (cur.size() == nums.size()) {
            res.push_back(cur);
            return;
        }
        for (int i = 0; i < nums.size(); i++) {
            if (used[i]) continue;
            // 去重: 相同元素不能在同一层重复使用
            if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;
            used[i] = true;
            cur.push_back(nums[i]);
            dfs(cur);
            cur.pop_back();
            used[i] = false;
        }
    };
    vector<int> cur;
    dfs(cur);
    return res;
}
```

## 剪枝策略

| 策略 | 说明 | 示例 |
|------|------|------|
| **可行性剪枝** | 当前状态不可能产生合法解，立即返回 | N 皇后列/对角线检查 |
| **最优性剪枝** | 当前状态不可能产生比已知解更好的解 | TSP 当前长度 > 已记录最短路径 |
| **顺序优化** | 优先搜索约束最强的分支 (最少剩余值) | 数独中从空格最少的区域开始 |
| **对称性剪枝** | 利用对称性避免重复搜索 | 棋盘对称、排列排序去重 |

## 分治 vs 回溯 vs DP

| 特性 | 分治 | 回溯 | DP |
|------|------|------|-----|
| 子问题关系 | 独立不重叠 | 搜索树分支 | 重叠 |
| 是否记忆化 | 否 | 可选 (记忆化搜索) | 是 (核心) |
| 解保证 | 最优 | 全部可行解 | 最优 |
| 典型输出 | 一个解 | 所有解 | 最优值 |
