> 贪心算法（Greedy Algorithm）在每一步选择中都采取当前状态下的最优决策，期望最终得到全局最优解。贪心不总是正确——它要求问题具备**贪心选择性质**（局部最优能推导全局最优）和**最优子结构**。Dijkstra 和 Huffman 编码是贪心最经典的实例。

## 贪心成立的条件

| 性质 | 说明 |
|------|------|
| **贪心选择性质** | 全局最优解可以通过做局部最优选择得到 |
| **最优子结构** | 问题的最优解包含子问题的最优解 |

> 验证贪心正确性通常用**交换论证**（exchange argument）：假设存在一个不包含贪心选择的最优解，通过交换操作证明贪心选择同样构成最优解。

## 经典贪心问题

### 1. 活动选择问题

给定 n 个活动的开始和结束时间，选出最多的互不相交的活动：

```cpp
// 贪心策略: 最早结束优先
int maxActivities(vector<pair<int,int>>& events) {
    // events = {start, end}, 按 end 排序
    sort(events.begin(), events.end(),
         [](auto& a, auto& b) { return a.second < b.second; });
    int count = 0, lastEnd = -1;
    for (auto [s, e] : events) {
        if (s >= lastEnd) {
            count++;
            lastEnd = e;
        }
    }
    return count;
}
```

### 2. 分数背包 (Fractional Knapsack)

```cpp
// 与 0-1 背包不同, 物品可拆分, 贪心最优
double fractionalKnapsack(vector<Item>& items, double W) {
    // Item: {weight, value}
    sort(items.begin(), items.end(),
         [](auto& a, auto& b) {
             return (double)a.value/a.weight > (double)b.value/b.weight;
         });
    double total = 0;
    for (auto& item : items) {
        if (W >= item.weight) {
            total += item.value;
            W -= item.weight;
        } else {
            total += item.value * (W / item.weight);
            break;
        }
    }
    return total;
}
```

### 3. Huffman 编码

构建最优前缀编码树，频率高的字符用短码，频率低的用长码：

```cpp
struct Node { char ch; int freq; Node *left, *right; };
auto cmp = [](Node* a, Node* b) { return a->freq > b->freq; };

Node* buildHuffmanTree(unordered_map<char,int>& freq) {
    priority_queue<Node*, vector<Node*>, decltype(cmp)> pq(cmp);
    for (auto [ch, f] : freq) pq.push(new Node{ch, f, nullptr, nullptr});
    while (pq.size() > 1) {
        auto left = pq.top(); pq.pop();
        auto right = pq.top(); pq.pop();
        pq.push(new Node{'\0', left->freq + right->freq, left, right});
    }
    return pq.top();  // root of Huffman tree
}
```

## 图论中的贪心

| 算法 | 贪心选择 | 证明 |
|------|---------|------|
| **Dijkstra** | 每次取出未确定的最小距离节点 | 非负权保证贪心选择正确 |
| **Prim (MST)** | 每次加入与当前树最近的节点 | 割性质 (cut property) |
| **Kruskal (MST)** | 每次加入不构成环的最小边 | 割性质 + 并查集 |

## 贪心 vs DP

```cpp
// 问题: 凑出 amount 元的最少硬币数

// 贪心 — 每次取面值最大的硬币 (不一定最优!)
// coins = {10, 6, 1}, amount = 12
// 贪心: 10 + 1 + 1 = 3 枚 (次优)
// 正确: 6 + 6 = 2 枚

// DP — 总能找到最优解
int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, INT_MAX);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++)
        for (int c : coins)
            if (i >= c && dp[i-c] != INT_MAX)
                dp[i] = min(dp[i], dp[i-c] + 1);
    return dp[amount] == INT_MAX ? -1 : dp[amount];
}
```

| 场景 | 用贪心? | 说明 |
|------|--------|------|
| 硬币找零 (特定面值) | ✅ | 如 coins={1,5,25,100} 确定性最优 |
| 硬币找零 (任意面值) | ❌ | 可能非最优，需 DP |
| 最短路径 (非负权) | ✅ (Dijkstra) | 贪心选择成立 |
| 最小生成树 | ✅ (Prim/Kruskal) | 割性质保证 |
| 0-1 背包 | ❌ | 贪心不是最优解 |
