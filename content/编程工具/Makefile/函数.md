## Makefile 函数

Makefile 函数格式：`$(function arguments)` 或 `${function arguments}`。参数之间用逗号或空格分隔。

### 文本处理

```makefile
# $(subst FROM,TO,TEXT) — 字符串替换（字面量）
$(subst ee,EE,feet on the street)  # fEEt on the strEEt

# $(patsubst PATTERN,REPLACEMENT,TEXT) — 模式替换
$(patsubst %.c,%.o,main.c foo.c)   # main.o foo.o

# $(strip STRING) — 去除首尾多余空格
$(strip   a  b   c  )              # a b c

# $(findstring FIND,IN) — 查找子串，找到返回子串本身，否则空
$(findstring a,a b c)               # a

# $(filter PATTERN...,TEXT) — 保留匹配的单词
$(filter %.c,main.c foo.h bar.c)   # main.c bar.c

# $(filter-out PATTERN...,TEXT) — 剔除匹配的单词
$(filter-out %.h,main.c foo.h)     # main.c

# $(sort LIST) — 排序去重（字典序）
$(sort foo bar foo baz)            # bar baz foo

# $(word N,TEXT) — 取第 N 个单词（从 1 开始）
$(word 2,foo bar baz)              # bar

# $(wordlist S,E,TEXT) — 取第 S 到 E 个单词
$(wordlist 1,2,foo bar baz)        # foo bar

# $(words TEXT) — 单词个数
$(words foo bar baz)               # 3

# $(firstword TEXT) — 第一个单词
$(firstword foo bar baz)           # foo

# $(lastword TEXT) — 最后一个单词
$(lastword foo bar baz)            # baz
```

### 文件名处理

```makefile
# $(dir NAMES...) — 取目录部分（含末尾 /）
$(dir src/foo.c hacks)             # src/ ./

# $(notdir NAMES...) — 取文件名部分
$(notdir src/foo.c hacks)          # foo.c hacks

# $(suffix NAMES...) — 取后缀（含 .）
$(suffix src/foo.c src/bar.h)      # .c .h

# $(basename NAMES...) — 去后缀
$(basename src/foo.c src/bar.h)    # src/foo src/bar

# $(addsuffix SUFFIX,NAMES...) — 追加后缀
$(addsuffix .o,main foo)           # main.o foo.o

# $(addprefix PREFIX,NAMES...) — 追加前缀
$(addprefix build/,$(OBJS))        # build/foo.o build/bar.o

# $(join LIST1,LIST2) — 逐对拼接
$(join a b,.c .h)                  # a.c b.h

# $(wildcard PATTERN) — 通配符展开（等价于 shell glob）
$(wildcard src/*.c)

# $(realpath NAMES...) — 规范化为绝对路径
$(realpath ./foo.c)

# $(abspath NAMES...) — 转绝对路径（不解析符号链接）
$(abspath ./foo.c)
```

### 条件函数

```makefile
# $(if CONDITION,THEN[,ELSE]) — 条件分支
$(if $(filter-out,$(OBJS)),has-objects,no-objects)

# $(or COND1,COND2,...) — 返回第一个非空值
CFLAGS = $(or $(CUSTOM_CFLAGS),-O2)

# $(and COND1,COND2,...) — 全非空则返回最后一项
ALL_OK = $(and $(CC),$(LD),ready)
```

### 循环与求值

```makefile
# $(foreach VAR,LIST,TEXT) — 遍历列表
SRCS = main.c foo.c bar.c
OBJS = $(foreach src,$(SRCS),$(basename $(src)).o)

# $(call VARIABLE,PARAM1,PARAM2,...) — 调用自定义宏
reverse = $(2) $(1)
$(call reverse,a,b)                # b a

# $(eval TEXT) — 动态定义 Makefile 规则
$(eval $(call generate_rules,$(MODULES)))

# $(value VAR) — 取变量未经展开的原始值
FOO = $(BAR)
BAR = hello
$(value FOO)                       # $(BAR)
```

`call` + `eval` 组合用于批量生成规则：

```makefile
# 为每个模块生成编译规则的宏
define COMPILE_MODULE
$(1): $(1).c
	$$(CC) -c $$< -o $$@
endef

# 批量套用
$(foreach mod,$(MODULES),$(eval $(call COMPILE_MODULE,$(mod))))
```

### 元信息

```makefile
# $(origin VAR) — 变量来源
$(origin CC)       # default / environment / file / command\ line / override / automatic / undefined

# $(flavor VAR) — 变量类型
$(flavor CC)       # recursive / simple / undefined

# $(error TEXT...) — 致命错误，立即终止
$(error Unsupported platform: $(PLATFORM))

# $(warning TEXT...) — 警告，继续执行
$(warning VERSION is not set, using default)

# $(info TEXT...) — 信息输出
$(info Building $(TARGET) for $(PLATFORM)...)
```

### Shell

```makefile
# $(shell COMMAND) — 执行 shell 命令，返回 stdout（去除末尾换行）
DATE = $(shell date +%Y%m%d)
GIT_HASH = $(shell git rev-parse --short HEAD)
SRCS = $(shell find . -name '*.c')
```

`shell` 在变量展开时执行，结果缓存到变量中。避免在每条规则中重复调用开销大的命令。

### 函数速查

| 分类 | 函数 |
|------|------|
| 文本 | `subst` `patsubst` `strip` `findstring` `filter` `filter-out` `sort` `word` `wordlist` `words` `firstword` `lastword` |
| 文件名 | `dir` `notdir` `suffix` `basename` `addsuffix` `addprefix` `join` `wildcard` `realpath` `abspath` |
| 条件 | `if` `or` `and` |
| 循环 | `foreach` |
| 高级 | `call` `eval` `value` |
| 调试 | `error` `warning` `info` |
| Shell | `shell` |
| 元信息 | `origin` `flavor` |
