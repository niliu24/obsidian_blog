## Makefile 基本语法

Makefile 定义工程的编译规则，由 GNU Make 解释执行，实现自动化编译链接。核心理念：只有依赖比目标新的文件才重新编译。

### 规则语法

```makefile
target ... : prerequisites ...
	recipe
```

* `target`：目标文件、可执行文件或伪目标（如 `clean`）
* `prerequisites`：生成 target 所需的依赖文件
* `recipe`：生成 target 的 Shell 命令，**必须用 Tab 缩进**（不能用空格）
* 若 prerequisites 中任一文件比 target 新，recipe 被执行

```makefile
# 简单示例
hello: hello.o
	gcc -o hello hello.o

hello.o: hello.c
	gcc -c hello.c
```

### 变量

```makefile
# 定义
CC = gcc
CFLAGS = -Wall -g
objects = main.o foo.o bar.o

# 使用 $(...) 或 ${...}
program: $(objects)
	$(CC) $(CFLAGS) -o program $(objects)
```

| 变量类型 | 展开方式 | 示例 |
|---------|---------|------|
| 递归展开 `=` | 使用时展开 | `VAR = $(OTHER)` |
| 简单展开 `:=` | 定义时立即展开 | `VAR := $(shell date)` |
| 条件赋值 `?=` | 未定义时才赋值 | `CC ?= gcc` |
| 追加 `+=` | 追加值 | `CFLAGS += -O2` |

#### 自动变量

| 变量 | 含义 |
|------|------|
| `$@` | 当前目标名 |
| `$<` | 第一个依赖文件 |
| `$^` | 所有依赖文件（去重） |
| `$+` | 所有依赖文件（不去重） |
| `$?` | 所有比目标新的依赖文件 |
| `$*` | 目标去掉后缀的主干名（隐含规则中） |

```makefile
# 使用自动变量简化
hello.o: hello.c
	$(CC) $(CFLAGS) -c $< -o $@
```

### 伪目标 (PHONY)

声明不对应实际文件的标签目标，即使存在同名文件也会执行：

```makefile
.PHONY: clean all install

clean:
	rm -f *.o program

all: program

install:
	cp program /usr/local/bin
```

### 隐含规则

Make 内置常见后缀的自动推导规则，无需显式写出：

```makefile
# 隐含规则已知 .c → .o 的编译命令，以下可省略
# main.o: main.c
# 	$(CC) -c main.c

# 只需写依赖
program: main.o utils.o
	$(CC) -o $@ $^
main.o: main.c defs.h
utils.o: utils.c defs.h
```

查看所有隐含规则：`make -p | grep -A1 '^[^#]'`

### 模式规则

用 `%` 通配符定义通用编译规则：

```makefile
# %.o 匹配所有 .o 文件
%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

# 多个目标
%.o: %.c common.h
	$(CC) $(CFLAGS) -c $< -o $@
```

### 条件判断

```makefile
# 根据变量值
ifeq ($(DEBUG), 1)
    CFLAGS += -g -O0
else
    CFLAGS += -O2
endif

# 根据变量是否定义
ifdef VERSION
    DEFS += -DVERSION=\"$(VERSION)\"
endif
```

### include 与 submake

```makefile
# 引入其他 Makefile 片段
include config.mk
-include local.mk   # 文件不存在不报错（- 前缀）

# 子目录 make
subdirs:
	$(MAKE) -C lib
	$(MAKE) -C src

# 导出变量到子 make
export CFLAGS
```

### 多目标与静态模式规则

```makefile
# 静态模式规则：限定目标范围
$(OBJS): %.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

# 等价于为每个 $(OBJS) 中的文件单独定义 %o: %.c 规则
```

### 常用编译变量约定

| 变量 | 默认值 | 用途 |
|------|--------|------|
| `CC` | `cc` | C 编译器 |
| `CXX` | `g++` | C++ 编译器 |
| `CFLAGS` | — | C 编译选项 |
| `CXXFLAGS` | — | C++ 编译选项 |
| `LDFLAGS` | — | 链接选项 |
| `LDLIBS` | — | 链接库（如 `-lm`） |
| `MAKE` | `make` | make 命令 |
| `RM` | `rm -f` | 删除命令 |

### 完整示例

```makefile
# 编译器和选项
CC = gcc
CFLAGS = -Wall -Wextra -std=c11
LDFLAGS =
LDLIBS = -lm

# 调试模式
ifeq ($(DEBUG), 1)
    CFLAGS += -g -O0 -DDEBUG
else
    CFLAGS += -O2
endif

# 源文件与目标
SRCS = $(wildcard src/*.c)
OBJS = $(patsubst src/%.c, build/%.o, $(SRCS))
TARGET = program

.PHONY: all clean

all: $(TARGET)

# 链接
$(TARGET): $(OBJS)
	$(CC) $(LDFLAGS) -o $@ $^ $(LDLIBS)

# 编译
build/%.o: src/%.c
	@mkdir -p build
	$(CC) $(CFLAGS) -c $< -o $@
	@echo "  CC  $<"

# 清理
clean:
	$(RM) -r build $(TARGET)
```

### 调试技巧

```bash
make -n        # 打印但不执行命令（dry-run）
make -p        # 打印所有规则和变量
make -d        # 详细调试输出
make -j4       # 并行编译（4 个作业）
make -k        # 错误后继续编译其他目标
make -s        # 静默模式（不打印命令）
```

在 Makefile 中使用 `$(info …)` 和 `$(warning …)` 打印调试信息：

```makefile
$(info SRCS = $(SRCS))
$(warning Current target: $@)
```
