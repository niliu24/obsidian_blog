> 树是计算机科学中最重要的非线性数据结构。从文件系统的目录层级到数据库的索引结构，从语法解析的 AST 到网络的路由表，树无处不在。树解决了线性结构无法高效组织的层次数据和有序数据管理问题。

## 二叉树基础

### 遍历 (全部 O(n))

```
        A
      /   \
     B     C
    / \   / \
   D   E F   G

前序 (根左右): A B D E C F G  → 树序列化
中序 (左根右): D B E A F C G  → BST 有序输出
后序 (左右根): D E B F G C A  → 文件系统大小计算
层序 (按层):   A B C D E F G  → BFS
```

```cpp
// 中序遍历 (递归)
void inorder(TreeNode *root) {
    if (!root) return;
    inorder(root->left);
    visit(root);
    inorder(root->right);
}

// 层序遍历 (迭代)
vector<vector<int>> levelOrder(TreeNode *root) {
    vector<vector<int>> res;
    queue<TreeNode*> q;
    if (root) q.push(root);
    while (!q.empty()) {
        int sz = q.size();
        vector<int> level;
        while (sz--) {
            auto n = q.front(); q.pop();
            level.push_back(n->val);
            if (n->left)  q.push(n->left);
            if (n->right) q.push(n->right);
        }
        res.push_back(level);
    }
    return res;
}
```

### 二叉树属性

| 性质 | 公式 |
|------|------|
| 第 i 层最大节点数 | `2^(i-1)` |
| 深度为 k 的最大节点数 | `2^k - 1` |
| 叶子节点数 | `n₂ + 1` (n₂ 为度=2 的节点数) |
| 满二叉树高度 | `⌈log₂(n+1)⌉` |

## 二叉搜索树 (BST)

**性质**: 左子树所有值 < 根 < 右子树所有值。

| 操作 | 平均 | 最坏 |
|------|------|------|
| 查找 | O(log n) | O(n) (退化成链表) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |

```cpp
// BST 查找
TreeNode* search(TreeNode *root, int val) {
    while (root) {
        if (val == root->val) return root;
        root = val < root->val ? root->left : root->right;
    }
    return nullptr;
}

// BST 插入
TreeNode* insert(TreeNode *root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val)
        root->left = insert(root->left, val);
    else
        root->right = insert(root->right, val);
    return root;
}

// BST 删除 (Hibbard)
TreeNode* remove(TreeNode *root, int key) {
    if (!root) return nullptr;
    if (key < root->val) {
        root->left = remove(root->left, key);
    } else if (key > root->val) {
        root->right = remove(root->right, key);
    } else {
        // 单子或叶子节点
        if (!root->left)  return root->right;
        if (!root->right) return root->left;
        // 双子节点: 找后继 (右子树最小), 替换并删除后继
        TreeNode *succ = root->right;
        while (succ->left) succ = succ->left;
        root->val = succ->val;
        root->right = remove(root->right, succ->val);
    }
    return root;
}
```

## 平衡二叉搜索树

### AVL 树

**严格平衡**: 任何节点的左右子树高度差 ≤ 1。通过四种旋转恢复平衡：

| 失衡模式 | 旋转 | 场景 |
|----------|------|------|
| LL (左子左插) | 右旋 (R) | |
| RR (右子右插) | 左旋 (L) | |
| LR (左子右插) | 左旋 + 右旋 (LR) | |
| RL (右子左插) | 右旋 + 左旋 (RL) | |

AVL 查询快（严格平衡），但插入/删除需要多次旋转，适合读多写少场景。

### 红黑树 (Red-Black Tree)

**近似平衡**: 通过五条性质保证最长路径 ≤ 2× 最短路径。

| 性质 | 说明 |
|------|------|
| 1. 节点颜色 | 每个节点非红即黑 |
| 2. 根节点 | 根节点为黑色 |
| 3. 红节点子 | 红色节点的子节点必须是黑色 (无连续红) |
| 4. 黑高度 | 从任意节点到 null 叶子的每条路径有相同数目的黑色节点 |
| 5. 叶子节点 | null 节点视为黑色 |

**AVL vs 红黑树**

| 特性 | AVL | 红黑树 |
|------|-----|--------|
| 平衡度 | 严格 (高度差 ≤1) | 近似 (≤2×) |
| 查找速度 | 略快 (更矮) | 略慢 |
| 插入/删除 | 旋转较多 | 旋转较少 (最多 3 次) |
| 应用 | 数据库索引 | Java TreeMap, C++ std::map, Linux CFS, epoll |

## B-Tree / B+Tree

面向磁盘的平衡多路搜索树，单节点包含多个 key，节点大小对齐磁盘页（通常 4KB-16KB）。

### B-Tree vs B+Tree

| 特性 | B-Tree | B+Tree |
|------|--------|--------|
| 数据存储 | 内部节点也存数据 | 仅叶子节点存数据 |
| 内部节点 | 存 key + 子节点指针 | 仅存 key + 子节点指针 (更紧凑) |
| 叶子节点 | 无链表 | 叶子节点之间形成有序链表 |
| 范围查询 | 需回溯 | O(log n + k) (链表遍历) |
| 应用 | 早期 RDBMS | MySQL InnoDB, PostgreSQL |

```
B+Tree 结构:
        [5|10]              ← 内部节点 (仅 key)
       /   |   \
   [1|3] [6|8] [12|15]     ← 内部节点
   / | \  / | \   / | \
  [1][3][5][6][8] [10][12][15] ← 叶子节点 (key+data 或 key+指针)
  ↕链表↕
```

## Trie (前缀树 / 字典树)

用于高效存储和检索字符串集合。每个节点代表一个前缀，边代表字符。

```
root
  ├─a
  │ └─p
  │   └─p("*")
  │     └─l
  │       └─e("*")
  └─o
    └─r("*")
```

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 插入 | O(L) | L = 字符串长度 |
| 查找 | O(L) | 与树中已有字符串数量无关 |
| 前缀查询 | O(L+k) | k = 匹配前缀的字符串数 |

应用场景：自动补全、拼写检查、IP 路由 (最长前缀匹配)、XOR 最大值。
