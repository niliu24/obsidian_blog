> 红黑树是一种**近似平衡**的二叉搜索树，通过颜色约束和旋转操作保证最长路径不超过最短路径的 2 倍。与 AVL 的严格高度平衡不同，红黑树牺牲少量平衡度换取更少的旋转开销，在实际工程中应用最广。

## 五条性质

1. **节点颜色** — 每个节点非红即黑
2. **根节点** — 根节点为黑色
3. **叶子节点** — NULL 节点视为黑色
4. **红色节点的子节点必须是黑色** — 路径上无连续红色
5. **黑高度一致** — 从任意节点到其所有 NULL 叶子节点路径上的黑色节点数相同

## 核心推论

- 性质 4 + 5 → 最长路径 (红黑交替) ≤ 2 × 最短路径 (全黑)
- 一棵有 n 个节点的红黑树高度 ≤ 2 log₂(n+1)
- 查找/插入/删除均为 **O(log n)**

## 旋转

红黑树的旋转与 AVL 完全相同，但触发条件基于颜色而非高度：

```
RIGHT_ROTATE(z):              LEFT_ROTATE(z):
      z                            z
     / \                          / \
    y   T4                       T1  y
   / \          →                   / \
  x   T3                          T2  x
 / \                                  / \
T1 T2                                T3 T4
```

## 插入 — 伪代码

新节点**初始为红色**（不破坏性质 5），插入后检查并修复性质 4：

```
算法 RB_INSERT(tree, key):
    node ← NEW_RED_NODE(key)
    执行标准 BST 插入，将 node 挂入合适位置
    RB_INSERT_FIXUP(tree, node)

算法 RB_INSERT_FIXUP(tree, node):
    当 node.parent.color == RED:  // 违反了性质4
        p ← node.parent
        g ← p.parent           // 祖父一定为黑 (否则之前就已违反)
        uncle ← g.left 如果 p == g.right 否则 g.right

        如果 uncle 存在且 uncle.color == RED:
            // 情况1: 叔父为红 — 颜色翻转
            p.color ← BLACK
            uncle.color ← BLACK
            g.color ← RED
            node ← g          // 上溯检查

        否则:  // 叔父为黑
            如果 node 是 p 的右子 且 p 是 g 的左子:
                // 情况2: ↑z字形 — 先左旋p
                LEFT_ROTATE(p)
                node ← p
                p ← node.parent
            否则如果 node 是 p 的左子 且 p 是 g 的右子:
                // 对称的z字形
                RIGHT_ROTATE(p)
                node ← p
                p ← node.parent

            // 情况3: /字形 — 旋转 + 重新着色
            p.color ← BLACK
            g.color ← RED
            如果 p == g.left: RIGHT_ROTATE(g)
            否则:            LEFT_ROTATE(g)

    tree.root.color ← BLACK   // 性质2: 根始终为黑
```

### 插入修复图示

```
情况1 (叔父红): 颜色翻转，上溯
     g(B)                g(R)
    /   \               /   \
  p(R)  u(R)    →     p(B)  u(B)
  /                   /
node(R)             node(R)

情况2+3 (叔父黑, z字形→/字形): 旋转解决
     g(B)                   g(B)                   p(B)
    /   \                  /   \                  /   \
  p(R)  u(B)    →        p*(R) u(B)     →      node(R) g(R)
    \                    /                            \
    node(R)           node(R)                         u(B)

  (情况2: 左旋p)        (情况3: 右旋g + 重新着色)
```

## 删除 — 伪代码

删除比插入复杂。核心：如果被删节点是**黑色**，会产生"双黑"问题，需要修复：

```
算法 RB_REMOVE(tree, key):
    找到并执行标准 BST 删除，记录被删节点 x
    如果 x.color == BLACK:    // 删除黑色节点破坏了性质5
        RB_DELETE_FIXUP(tree, x 替代位置)
    tree.root.color ← BLACK

算法 RB_DELETE_FIXUP(tree, node):
    // node 是 "双黑" 节点代理, sibling 是其兄弟
    当 node != tree.root 且 node.color == BLACK:
        sibling ← node 的兄弟

        如果 sibling.color == RED:
            // 情况1: 兄弟为红 → 转为兄弟为黑
            sibling.color ← BLACK
            node.parent.color ← RED
            如果 node == node.parent.left: LEFT_ROTATE(node.parent)
            否则:                         RIGHT_ROTATE(node.parent)
            sibling ← node 的兄弟

        // 兄弟为黑
        如果 sibling.left.color == BLACK 且 sibling.right.color == BLACK:
            // 情况2: 兄弟两子全黑
            sibling.color ← RED
            node ← node.parent          // 双黑上移

        否则:
            如果 node == node.parent.left:
                如果 sibling.right.color == BLACK:
                    // 情况3: 兄弟右子黑 (左子红)
                    sibling.left.color ← BLACK
                    sibling.color ← RED
                    RIGHT_ROTATE(sibling)
                    sibling ← node 的兄弟
                // 情况4: 兄弟右子红
                sibling.color ← node.parent.color
                node.parent.color ← BLACK
                sibling.right.color ← BLACK
                LEFT_ROTATE(node.parent)
                node ← tree.root        // 修复完成，终止循环

            否则:  // node 是右子 (对称处理)
                // ...

    node.color ← BLACK
```

## AVL vs 红黑树

| 特性 | AVL | 红黑树 |
|------|-----|--------|
| 平衡度 | 严格 (高度差 ≤ 1) | 近似 (≤ 2×) |
| 查找速度 | 略快 (树更矮) | 略慢 |
| 插入旋转次数 | O(log n) | 最多 2 次 |
| 删除旋转次数 | O(log n) | 最多 3 次 |
| 适用场景 | 读远多于写 | 读写均衡/写较多 |
| 标准库使用 | — | C++ `std::map`, Java `TreeMap` |
