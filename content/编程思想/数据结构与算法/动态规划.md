> 动态规划（Dynamic Programming）通过将问题分解为重叠子问题，并保存子问题的解来避免重复计算。它适用于具有**最优子结构**和**重叠子问题**的问题。DP 是算法竞赛和面试中的核心考察点，也是解决现实优化问题（背包、序列比对、最短路径）的强大工具。

## 核心概念

| 概念 | 说明 |
|------|------|
| **最优子结构** | 问题的最优解包含子问题的最优解 |
| **重叠子问题** | 不同的递归分支访问相同的子问题 |
| **状态定义** | dp[i][j] 表示什么含义——最关键的一步 |
| **状态转移** | dp[i][j] = min/max/sum(dp[prev]) + cost |
| **无后效性** | 当前状态一旦确定，后续决策不受之前决策影响 |

## DP 与分治、贪心的区别

| 特性 | 分治 | 动态规划 | 贪心 |
|------|------|----------|------|
| 子问题关系 | 独立不重叠 | 重叠 | 无需回溯 |
| 选择 | 合并子问题解 | 尝试所有选择，择优 | 仅做当前最优 |
| 典型复杂度 | O(n log n) | O(n²)~O(n³) | O(n log n) |
| 保证最优 | ✅ | ✅ | 仅在特定条件下 |

## DP 经典问题

### 1. 0-1 背包

```cpp
// dp[i][w]: 前 i 件物品, 容量 w 下的最大价值
int knapsack(vector<int>& wt, vector<int>& val, int W) {
    int n = wt.size();
    vector<int> dp(W + 1);
    for (int i = 0; i < n; i++)
        for (int w = W; w >= wt[i]; w--)  // 逆序, 防重复使用
            dp[w] = max(dp[w], dp[w - wt[i]] + val[i]);
    return dp[W];
}
```

| 变体 | 区别 |
|------|------|
| 0-1 背包 | 每种物品取 0 或 1 次 |
| 完全背包 | 每种物品无限次 (内循环正序) |
| 多重背包 | 每种物品有限次数 (二进制拆分) |

### 2. 最长公共子序列 (LCS)

```cpp
int lcs(string& a, string& b) {
    int m = a.size(), n = b.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1));
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (a[i-1] == b[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    return dp[m][n];
}
```

### 3. 最长递增子序列 (LIS)

```cpp
// O(n log n) — 耐心排序法
int lis(vector<int>& nums) {
    vector<int> piles;  // piles[i] = 第 i 堆的顶部值
    for (int x : nums) {
        auto it = lower_bound(piles.begin(), piles.end(), x);
        if (it == piles.end()) piles.push_back(x);
        else *it = x;
    }
    return piles.size();
}

// O(n²) DP — 更通用的版本
int lis_dp(vector<int>& nums) {
    vector<int> dp(nums.size(), 1);
    for (int i = 0; i < nums.size(); i++)
        for (int j = 0; j < i; j++)
            if (nums[i] > nums[j])
                dp[i] = max(dp[i], dp[j] + 1);
    return *max_element(dp.begin(), dp.end());
}
```

### 4. 编辑距离 (Levenshtein)

```cpp
int editDistance(string& a, string& b) {
    int m = a.size(), n = b.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1));
    for (int i = 0; i <= m; i++) dp[i][0] = i;  // 全删除
    for (int j = 0; j <= n; j++) dp[0][j] = j;  // 全插入
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (a[i-1] == b[j-1])
                dp[i][j] = dp[i-1][j-1];
            else
                dp[i][j] = min({dp[i-1][j],    // 删除
                                dp[i][j-1],    // 插入
                                dp[i-1][j-1]}) // 替换
                         + 1;
    return dp[m][n];
}
```

## DP 类型与技巧

| 类型 | 特征 | 典型问题 |
|------|------|----------|
| **线性 DP** | dp[i] 依赖 dp[i-1] 等少量状态 | 爬楼梯、最大子数组和 |
| **区间 DP** | dp[l][r] 处理区间 | 矩阵链乘、石子合并 |
| **背包 DP** | dp[i][w] 两维：物品 × 容量 | 0-1 背包系列 |
| **树形 DP** | 在树结构上做 DP，后序遍历 | 打家劫舍 III |
| **状态压缩 DP** | 用位掩码表示状态 | TSP (旅行商)、集合覆盖 |
| **数位 DP** | dp[pos][state] 处理数字的每一位 | 不包含连续的 1、1~N 的计数 |

### 空间优化：滚动数组

```cpp
// 斐波那契: O(n) 时间, O(1) 空间
long long fib(int n) {
    long long a = 0, b = 1;
    for (int i = 0; i < n; i++)
        a = exchange(b, a + b);
    return a;
}
```

## 如何设计 DP 算法

```
1. 定义状态: dp[i] 表示什么? → 能用更少维吗?
2. 确认状态变量: 什么决定了一个状态? (位置? 容量? 阶段?)
3. 推导转移方程: 当前状态由哪些前置状态推导过来?
4. 确定基本情况和遍历顺序: 确保依赖的状态先被计算
5. 考虑空间优化: 能否滚动数组? 能否原位修改?
```
