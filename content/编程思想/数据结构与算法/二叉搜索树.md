> 二叉搜索树（Binary Search Tree, BST）的性质：对于任意节点，左子树所有值 < 节点值 < 右子树所有值。这一性质使得有序遍历、范围和查找等操作高效执行。在不平衡的情况下 BST 可能退化为链表。

## 核心性质

- **中序遍历得到升序序列**
- 查找/插入/删除平均 O(log n)，最坏 O(n)（退化成链表）
- 相同的 key 集合可能构建出多种不同形态的 BST

## 复杂度

| 操作 | 平均 | 最坏 |
|------|------|------|
| 查找 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 (Hibbard) | O(log n) | O(n) |
| 最小/最大值 | O(log n) | O(n) |
| 前驱/后继 | O(log n) | O(n) |

## 查找 — 从根节点逐层比较

```
算法 SEARCH(node, key):
    当 node != NULL:
        如果 key == node.key: 返回 node
        如果 key < node.key:  node ← node.left
        否则:               node ← node.right
    返回 NULL
```

## 插入 — 找到正确位置后挂入叶子

```
算法 INSERT(node, key):
    如果 node == NULL: 返回 NEW_NODE(key)
    如果 key < node.key:
        node.left ← INSERT(node.left, key)
    否则如果 key > node.key:
        node.right ← INSERT(node.right, key)
    返回 node
```

## 删除 (Hibbard) — 三种情况

```
算法 REMOVE(node, key):
    如果 node == NULL: 返回 NULL

    如果 key < node.key:
        node.left ← REMOVE(node.left, key)
    否则如果 key > node.key:
        node.right ← REMOVE(node.right, key)
    否则:  // 找到待删除节点
        情况1: 无左子 → 返回 node.right
        情况2: 无右子 → 返回 node.left
        情况3: 双子节点:
            succ ← GET_MIN(node.right)       // 找后继
            node.key ← succ.key               // 用后继值替换
            node.right ← REMOVE(node.right, succ.key)  // 删除后继
    返回 node
```

### Hibbard 删除的问题

- 对称使用前驱和后继会导致树偏向一侧
- 多次删除后，树的高度倾向于 O(√n) 而非 O(log n)
- 这是 BST 需要平衡树（AVL、红黑树）的关键原因

## 寻找最小/最大

```
算法 GET_MIN(node):
    当 node.left != NULL: node ← node.left
    返回 node

算法 GET_MAX(node):
    当 node.right != NULL: node ← node.right
    返回 node
```

## 寻找前驱/后继

```
算法 SUCCESSOR(node):
    // 中序遍历中的下一个节点
    如果 node.right != NULL: 返回 GET_MIN(node.right)
    // 否则向上找第一个 " 当前节点在其左子树中 " 的祖先
    p ← node.parent
    当 p != NULL 且 node == p.right:
        node ← p
        p ← p.parent
    返回 p

算法 PREDECESSOR(node):
    // 中序遍历中的上一个节点
    如果 node.left != NULL: 返回 GET_MAX(node.left)
    p ← node.parent
    当 p != NULL 且 node == p.left:
        node ← p
        p ← p.parent
    返回 p
```
