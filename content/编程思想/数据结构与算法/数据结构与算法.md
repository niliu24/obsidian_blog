> 数据结构与算法是计算机科学的两大核心支柱。数据结构决定数据如何组织和存储，算法定义如何高效地操作和处理数据。两者密不可分——数据结构的选择直接影响算法的效率，而算法的设计往往由数据结构驱动。

## 核心概念

| 概念 | 说明 |
|------|------|
| **数据结构** | 数据在内存中的组织方式，决定了访问、插入、删除等操作的时间复杂度 |
| **算法** | 解决特定问题的步骤序列，核心评价指标是时间复杂度与空间复杂度 |
| **复杂度分析** | 分析算法随输入规模增长时资源消耗的变化趋势 |
| **ADT（抽象数据类型）** | 仅定义操作语义而不规定底层实现（如栈支持 push/pop） |

## 复杂度分析速查

### 常见时间复杂度

| 复杂度 | 名称 | 典型场景 | n=10^6 时操作数 |
|--------|------|----------|----------------|
| O(1) | 常数 | 数组随机访问、哈希查找 | 1 |
| O(log n) | 对数 | 二分查找、平衡树查找 | ~20 |
| O(n) | 线性 | 遍历数组、链表 | 10^6 |
| O(n log n) | 线性对数 | 归并排序、堆排序 | ~2×10^7 |
| O(n²) | 平方 | 冒泡排序、双重循环 | 10^12 (不可行) |
| O(2ⁿ) | 指数 | 暴力子集枚举 | 天文数字 |

### 各数据结构操作复杂度

| 数据结构 | 访问 | 查找 | 插入 | 删除 | 空间 |
|----------|------|------|------|------|------|
| 数组 | O(1) | O(n) | O(n) | O(n) | O(n) |
| 链表 | O(n) | O(n) | O(1) | O(1) | O(n) |
| 跳表 | O(log n) | O(log n) | O(log n) | O(log n) | O(n) |
| 哈希表 | — | O(1)* | O(1)* | O(1)* | O(n) |
| 二叉搜索树 | O(log n)* | O(log n)* | O(log n)* | O(log n)* | O(n) |
| 平衡树 (AVL/红黑) | O(log n) | O(log n) | O(log n) | O(log n) | O(n) |
| B-Tree | O(log n) | O(log n) | O(log n) | O(log n) | O(n) |
| 二叉堆 | O(1) (max) | O(n) | O(log n) | O(log n) | O(n) |
| 斐波那契堆 | O(1) (min) | O(n) | O(1) | O(log n)* | O(n) |

> `*` 表示均摊复杂度；哈希表的 O(1) 假设负载因子受控；BST 的 O(log n) 假设树平衡。

## 数据结构选型指南

```
需要 O(1) 随机访问? ─── YES → 数组 / 动态数组
     └─ NO → 需要 O(1) 头尾操作? ─── YES → 双端队列 (Deque)
             └─ NO → 需要 LIFO? ─── YES → 栈
                    └─ NO → 需要 FIFO? ─── YES → 队列
                            └─ NO → 需要 key-value 查找? ─── YES → 哈希表 / 平衡树
```
