> 查找是在数据结构中定位目标元素的操作。不同数据结构决定了可用的查找策略——数组用二分查找达到 O(log n)，哈希表用键映射达到 O(1)，字符串用 KMP/Boyer-Moore 等模式匹配算法。

## 查找算法总览

| 算法 | 数据结构 | 平均 | 最坏 | 前提 |
|------|----------|------|------|------|
| 线性查找 | 任意 | O(n) | O(n) | 无 |
| 二分查找 | 有序数组 | O(log n) | O(log n) | 有序 + 随机访问 |
| 插值查找 | 有序数组 | O(log log n) | O(n) | 均匀分布 |
| 指数查找 | 有序数组 | O(log n) | O(log n) | 无界/大数组 |
| 哈希查找 | 哈希表 | O(1) | O(n) | 良好哈希函数 |
| BST 查找 | BST | O(log n) | O(n) | 平衡树保证 |
| KMP | 字符串 | O(n+m) | O(n+m) | 前缀函数 |
| Boyer-Moore | 字符串 | O(n/m) | O(n×m) | 实际极快 |
| Robin-Karp | 字符串 | O(n+m) | O(n×m) | 滚动哈希 |

## 二分查找

### 标准二分查找

```cpp
int binarySearch(vector<int>& arr, int target) {
    int lo = 0, hi = arr.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;  // 防溢出
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) lo = mid + 1;
        else                   hi = mid - 1;
    }
    return -1;
}
```

### 二分查找变体

```cpp
// 第一个等于 target 的位置 (lower_bound)
int lowerBound(vector<int>& arr, int target) {
    int lo = 0, hi = arr.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] < target) lo = mid + 1;
        else                   hi = mid;
    }
    return lo;  // lo == 插入位置
}

// 第一个大于 target 的位置 (upper_bound)
int upperBound(vector<int>& arr, int target) {
    int lo = 0, hi = arr.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] <= target) lo = mid + 1;
        else                    hi = mid;
    }
    return lo;
}
```

### C++ 标准库

```cpp
#include <algorithm>

bool found = binary_search(v.begin(), v.end(), 42);
auto lb = lower_bound(v.begin(), v.end(), x);  // >=x 的第一个
auto ub = upper_bound(v.begin(), v.end(), x);  // >x 的第一个

// x 的个数: ub - lb
// x 的范围: [lb, ub)

// 在非随机访问数据结构上 (如 set):
set<int> s;
auto it = s.lower_bound(42);  // O(log n), 不能用 std::lower_bound
```

## 字符串匹配

### KMP (Knuth-Morris-Pratt)

利用前缀函数避免主串指针回退，O(n+m) 时间：

```cpp
vector<int> buildLPS(const string& pat) {
    vector<int> lps(p.size());
    for (int i = 1, len = 0; i < p.size(); ) {
        if (p[i] == p[len]) lps[i++] = ++len;
        else if (len)       len = lps[len - 1];
        else                lps[i++] = 0;
    }
    return lps;
}

int kmp(const string& text, const string& pat) {
    auto lps = buildLPS(pat);
    int i = 0, j = 0;
    while (i < text.size()) {
        if (text[i] == pat[j]) { i++; j++; }
        if (j == pat.size()) return i - j;  // 匹配成功
        if (i < text.size() && text[i] != pat[j])
            j ? j = lps[j-1] : i++;
    }
    return -1;
}
```

### 实际应用中的字符串搜索

| 场景 | 算法 | 原因 |
|------|------|------|
| `grep` / 文本搜索 | Boyer-Moore | 文本大、模式短 BM 极快 |
| 编辑器 Ctrl+F | Boyer-Moore | 跳跃式移动 |
| `Ctrl+P` 文件搜索 | 子序列匹配 / fuzzy matching | 非精确匹配 |
| DNA 序列 | KMP/Rabin-Karp | 多位字符、多重匹配 |
| 入侵检测 | Aho-Corasick | 多模式同时匹配 |
