> 图算法解决三类核心问题：**遍历**（如何访问所有节点）、**路径**（两点间最优路径）、**连通性**（图的结构特性）。图的表示方式（邻接矩阵 vs 邻接表）直接影响算法复杂度的实现。

## 图的遍历

### BFS (广度优先)

逐层访问，队列实现。求无权图最短路径：

```cpp
vector<int> bfs(Graph& g, int start) {
    vector<int> dist(g.size(), -1);
    queue<int> q;
    q.push(start);
    dist[start] = 0;

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (auto [v, _] : g.adj[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return dist;
}
```

### DFS (深度优先)

沿一条路径深入到底，栈/递归实现。检测环、拓扑排序、强连通分量：

```cpp
void dfs(Graph& g, int u, vector<bool>& visited) {
    visited[u] = true;
    for (auto [v, _] : g.adj[u])
        if (!visited[v]) dfs(g, v, visited);
}
```

| 特性 | BFS | DFS |
|------|-----|-----|
| 实现结构 | 队列 | 栈/递归 |
| 最短路径 | ✅ (无权图) | ❌ |
| 拓扑排序 | ✅ (Kahn) | ✅ (后序) |
| 环检测 | 中等 | ✅ (三色标记) |
| 连通分量 | ✅ | ✅ |

## 最短路径

| 算法 | 权值限制 | 复杂度 | 适用图 |
|------|---------|--------|--------|
| **BFS** | 无权 | O(V+E) | 无权图 |
| **Dijkstra** | 非负权 | O((V+E)log V) | 有向/无向，不能有负边 |
| **Bellman-Ford** | 无限制 | O(VE) | 可处理负权边，检测负环 |
| **Floyd-Warshall** | 无限制 | O(V³) | 所有点对 (APSP) |
| **A\*** | 非负权 | O(E) | 有启发式，最优路径 |

### Dijkstra (标准堆实现)

```cpp
vector<int> dijkstra(Graph& g, int src) {
    vector<int> dist(g.size(), INT_MAX);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d != dist[u]) continue;  // 过时 entry
        for (auto [v, w] : g.adj[u]) {
            if (dist[v] > d + w) {
                dist[v] = d + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

> 在稠密图中 (E≈V²)，使用**斐波那契堆**可将复杂度降至 O(E + V log V)。但在实践中，二叉堆已足够。

### Bellman-Ford

```cpp
bool bellmanFord(Graph& g, int src, vector<int>& dist) {
    dist.assign(g.size(), INT_MAX);
    dist[src] = 0;
    for (int i = 0; i < g.size() - 1; i++)
        for (int u = 0; u < g.size(); u++)
            for (auto [v, w] : g.adj[u])
                if (dist[u] != INT_MAX && dist[v] > dist[u] + w)
                    dist[v] = dist[u] + w;
    // 检测负环
    for (int u = 0; u < g.size(); u++)
        for (auto [v, w] : g.adj[u])
            if (dist[u] != INT_MAX && dist[v] > dist[u] + w)
                return true;  // 存在负环
    return false;
}
```

## 拓扑排序

任务调度、依赖解析、编译顺序等有向无环图 (DAG) 的核心算法：

```cpp
vector<int> topologicalSort(Graph& g) {
    vector<int> indegree(g.size());
    for (int u = 0; u < g.size(); u++)
        for (auto [v, _] : g.adj[u])
            indegree[v]++;

    queue<int> q;
    for (int i = 0; i < g.size(); i++)
        if (indegree[i] == 0) q.push(i);

    vector<int> order;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (auto [v, _] : g.adj[u])
            if (--indegree[v] == 0) q.push(v);
    }
    return order;  // size() < n 则存在环
}
```

## 最小生成树 (MST)

| 算法 | 复杂度 | 策略 | 适用 |
|------|--------|------|------|
| **Prim** | O((V+E)log V) | 从节点出发，每次连最近的未连接节点 | 稠密图 |
| **Kruskal** | O(E log E) | 从边出发，按权值排序，并查集判环 | 稀疏图 |
