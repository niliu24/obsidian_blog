> 二叉树（Binary Tree）是每个节点最多有两个子节点的树结构。它是二叉搜索树、AVL、红黑树等高级树结构的基础。

## 二叉树类型

| 类型 | 定义 |
|------|------|
| **满二叉树** | 所有非叶子节点都有两个子节点，叶子在同一层 |
| **完全二叉树** | 除最后一层外每层都满，最后一层的节点靠左排列 |
| **完美二叉树** | 所有内部节点都有两个子节点，所有叶子在同一层 |
| **平衡二叉树** | 对于任意节点，左右子树高度差不超过 1 |

## 二叉树属性

| 性质 | 公式 |
|------|------|
| 第 i 层最大节点数 | `2^(i-1)` |
| 深度为 k 的最大节点数 | `2^k - 1` |
| 叶子节点数 | `n₂ + 1` (n₂ 为度=2 的节点数) |
| 满二叉树高度 | `⌈log₂(n+1)⌉` |
| 完全二叉树高度 | `⌊log₂n⌋ + 1` |

## 遍历

```
        A
      /   \
     B     C
    / \   / \
   D   E F   G

前序 (根左右): A B D E C F G
中序 (左根右): D B E A F C G
后序 (左右根): D E B F G C A
层序 (按层):   A B C D E F G
```

### 深度优先遍历 (DFS) — 伪代码

```
算法 PREORDER(node):
    如果 node == NULL: 返回
    访问(node)
    PREORDER(node.left)
    PREORDER(node.right)

算法 INORDER(node):
    如果 node == NULL: 返回
    INORDER(node.left)
    访问(node)
    INORDER(node.right)

算法 POSTORDER(node):
    如果 node == NULL: 返回
    POSTORDER(node.left)
    POSTORDER(node.right)
    访问(node)
```

### 迭代版中序遍历 — 显式栈

```
算法 INORDER_ITERATIVE(root):
    栈 S ← 空
    node ← root
    当 node != NULL 或 S 非空:
        当 node != NULL:
            S.push(node)
            node ← node.left
        node ← S.pop()
        访问(node)
        node ← node.right
```

### 层序遍历 (BFS) — 伪代码

```
算法 LEVELORDER(root):
    如果 root == NULL: 返回
    队列 Q ← [root]
    当 Q 非空:
        node ← Q.dequeue()
        访问(node)
        如果 node.left  != NULL: Q.enqueue(node.left)
        如果 node.right != NULL: Q.enqueue(node.right)
```

## 二叉树存储

| 方式 | 优势 | 劣势 |
|------|------|------|
| **链式存储** | 灵活，无空间浪费 | 非连续内存，缓存不友好 |
| **数组存储** | 连续内存，O(1) 找父子节点 | 稀疏树浪费空间 |

```
数组存储 (0-based):
  节点 i 的父节点: ⌊(i-1)/2⌋
  节点 i 的左子:   2i + 1
  节点 i 的右子:   2i + 2
```
