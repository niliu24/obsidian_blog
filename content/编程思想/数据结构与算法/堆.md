> 堆（Heap）是一种特殊的完全二叉树，满足堆序性质：父节点的键值总是不小于（大顶堆）或不大于（小顶堆）子节点的键值。堆是实现优先队列的标准结构，在堆排序、Top-K、Dijkstra 等算法中扮演核心角色。

## 二叉堆结构

堆用数组存储完全二叉树，父子关系通过下标计算：

```
索引关系 (0-based):
  父: (i-1)/2
  左子: 2i + 1
  右子: 2i + 2

        0
      /   \
     1     2
    / \   / \
   3   4 5   6

存储: [0, 1, 2, 3, 4, 5, 6]
```

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| `push` | O(log n) | 上滤 (sift-up) |
| `pop` | O(log n) | 下滤 (sift-down) |
| `top` / `peek` | O(1) | 返回堆顶 |
| `heapify` | O(n) | 批量建堆 |
| `update` | O(log n) | 修改元素值后调整 |

## 实现 (C++ 大顶堆)

```cpp
template<typename T>
class MaxHeap {
    vector<T> data;

    void siftUp(int i) {
        while (i > 0) {
            int p = (i - 1) >> 1;
            if (data[p] >= data[i]) break;
            swap(data[p], data[i]);
            i = p;
        }
    }

    void siftDown(int i) {
        int n = data.size();
        while (true) {
            int largest = i;
            int l = (i << 1) + 1, r = l + 1;
            if (l < n && data[l] > data[largest]) largest = l;
            if (r < n && data[r] > data[largest]) largest = r;
            if (largest == i) break;
            swap(data[i], data[largest]);
            i = largest;
        }
    }

public:
    void push(const T& val) {
        data.push_back(val);
        siftUp(data.size() - 1);
    }

    void pop() {
        data[0] = data.back();
        data.pop_back();
        if (!data.empty()) siftDown(0);
    }

    T& top() { return data[0]; }
    bool empty() { return data.empty(); }
};
```

## 堆排序

利用堆的性质进行 O(n log n) 原地排序：

```cpp
void heapSort(vector<int>& arr) {
    // 1. 建堆 O(n)
    int n = arr.size();
    for (int i = (n>>1)-1; i >= 0; i--)
        siftDown(arr, n, i);  // 自底向上下滤

    // 2. 排序 O(n log n)
    for (int i = n-1; i > 0; i--) {
        swap(arr[0], arr[i]);  // 最大元素移到末尾
        siftDown(arr, i, 0);   // 缩小堆, 重新调整
    }
}
```

## C++ 标准库使用

```cpp
#include <queue>
#include <vector>
#include <functional>

// 大顶堆 (默认)
priority_queue<int> max_pq;
max_pq.push(3); max_pq.push(1); max_pq.push(5);
int top = max_pq.top(); // 5

// 小顶堆
priority_queue<int, vector<int>, greater<int>> min_pq;
min_pq.push(3); min_pq.push(1); min_pq.push(5);
int top2 = min_pq.top(); // 1

// 自定义比较器 (lambda)
struct Node { int val; };
auto cmp = [](Node& a, Node& b) { return a.val < b.val; };
priority_queue<Node, vector<Node>, decltype(cmp)> pq(cmp);
```

## Top-K 问题

求第 K 大元素，维护 K 大小的小顶堆：

```cpp
int kthLargest(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int x : nums) {
        pq.push(x);
        if (pq.size() > k) pq.pop();
    }
    return pq.top();  // 堆顶即第 K 大
}
```

| 变体 | 堆类型 | 堆大小 | 复杂度 |
|------|--------|--------|--------|
| 第 K 大 | 小顶堆 | K | O(n log k) |
| 第 K 小 | 大顶堆 | K | O(n log k) |
| 前 K 大 | 小顶堆 | K | O(n log k) |

## 堆的其他变体

| 变体 | 特点 | 应用 |
|------|------|------|
| **斐波那契堆** | `decrease-key` O(1) 均摊, 删除 O(log n) 均摊 | Dijkstra 加速 |
| **二项堆** | 由多个二项树组成，合并 O(log n) | 可合并优先队列 |
| **配对堆** | 实现简单，实际性能优秀 | 实践中最快 |
