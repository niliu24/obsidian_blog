> 排序是将数据按特定顺序排列的基本操作。排序算法可分为**比较排序**（依赖两两比较，下界 O(n log n)）和**非比较排序**（利用值的特性突破下界）。实际工程中，语言标准库的排序通常是多种算法的混合体（如 TimSort、Introsort）。

## 排序算法总览

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 适用场景 |
|------|------|------|------|------|------|----------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ | 教学 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | ❌ | 教学 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ | 小数组/近乎有序 |
| 希尔排序 | O(n log n) | O(n log² n) | O(n log² n) | O(1) | ❌ | 嵌入式 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ | 外排序/链表 |

## 核心排序实现

### 快速排序 (Quick Sort)

```cpp
// Lomuto 分区
int partition(vector<int>& arr, int lo, int hi) {
    int pivot = arr[hi];
    int i = lo;
    for (int j = lo; j < hi; j++)
        if (arr[j] < pivot)
            swap(arr[i++], arr[j]);
    swap(arr[i], arr[hi]);
    return i;
}

void quickSort(vector<int>& arr, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(arr, lo, hi);
    quickSort(arr, lo, p - 1);
    quickSort(arr, p + 1, hi);
}
```

优化要点：三数取中选 pivot、小数组切插入排序、尾递归优化。

### 归并排序 (Merge Sort)

```cpp
void mergeSort(vector<int>& arr, int lo, int hi, vector<int>& tmp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(arr, lo, mid, tmp);
    mergeSort(arr, mid + 1, hi, tmp);
    // 合并两个有序段
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi)
        tmp[k++] = arr[i] <= arr[j] ? arr[i++] : arr[j++];
    while (i <= mid) tmp[k++] = arr[i++];
    while (j <= hi)  tmp[k++] = arr[j++];
    copy(tmp.begin() + lo, tmp.begin() + hi + 1, arr.begin() + lo);
}
```

### 计数排序 (Counting Sort)

```cpp
void countingSort(vector<int>& arr) {
    int maxVal = *max_element(arr.begin(), arr.end());
    vector<int> count(maxVal + 1);
    for (int x : arr) count[x]++;
    for (int i = 0, j = 0; i <= maxVal; i++)
        while (count[i]-- > 0) arr[j++] = i;
}
```

## 工程实践中的排序

| 语言/库 | 算法 | 说明 |
|---------|------|------|
| C++ `std::sort` | **Introsort** | 快排 + 堆排 (防退化) + 插入排序 (小数组) |
| Java `Arrays.sort` (对象) | TimSort | 归并排序的改进版 |
| Python `sorted()` | **TimSort** | 利用数据中已有序的 run |
| Go `sort.Sort` | **Pattern-Defeating QuickSort** | 快排变体 |

### Introsort 策略

```
1. 递归深度 < 2·log₂n → 快速排序
2. 递归深度超标     → 堆排序 (保证 O(n log n))
3. 子数组 < 16 个   → 插入排序
```

### TimSort 核心思想

* 找到数据中的自然有序段（run），最小 run 长度 32-64
* 对短 run 用二分插入排序延长
* 用类似归并排序的方式合并 run
* 对几乎已排序数据接近 O(n)

## 稳定性的重要性

| 场景 | 为什么需要稳定 |
|------|---------------|
| 数据库多列排序 | 先按价格排，再按日期排——日期排序不能破坏价格排序 |
| Excel 排序 | 多级排序的正确性依赖于底层排序的稳定性 |
| Radix Sort | 从低位到高位逐位排序，每一轮依赖上一轮的稳定性 |
