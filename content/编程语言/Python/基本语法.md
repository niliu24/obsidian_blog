## Python 基本语法

Python 的语法设计强调可读性和简洁性，以**缩进**（而非花括号）定义代码块，支持动态类型、丰富的运算符和控制流结构。

### 缩进与代码块

Python 使用**缩进**（通常 4 个空格）代替 `{}` 表示代码块，所有同层级的语句必须对齐：

```python
def greet(name):
    if len(name) > 0:
        print(f"Hello, {name}!")   # 缩进 4 空格
    else:
        print("Hello, World!")     # 对齐至 if
```

> **注意**：混用 Tab 和空格会引发 `IndentationError`。PEP 8 推荐使用 4 个空格。

### 变量与动态类型

变量不需要声明类型，赋值即创建。类型在运行时由解释器推断：

```python
x = 42          # int
y = 3.14        # float
name = "Python" # str
is_ok = True    # bool
x = "changed"   # 类型可以改变（动态类型）
```

变量命名规则：字母/下划线开头，区分大小写，不能使用关键字。

### 基本类型

| 类型 | 示例 | 说明 |
|------|------|------|
| `int` | `42`, `0xff`, `0b1010` | 任意精度整数 |
| `float` | `3.14`, `1.5e-10` | 双精度浮点数（C double） |
| `bool` | `True`, `False` | `bool` 是 `int` 的子类，`True == 1` |
| `str` | `"hello"`, `'hello'` | Unicode 字符串，不可变 |
| `NoneType` | `None` | 表示空值，类似 C 的 `NULL` |

```python
# 类型检查
print(type(42))        # <class 'int'>
print(isinstance(3.14, float))  # True
```

### 类型提示（Type Hints，Python 3.5+）

类型提示不强制检查，但可被 IDE（PyCharm、VSCode）和静态检查器（mypy、pyright）利用：

```python
def add(a: int, b: int) -> int:
    return a + b

# 复杂类型（需 import typing）
from typing import List, Dict, Optional, Union

def process(items: List[int]) -> Optional[str]:
    if not items:
        return None
    return str(sum(items))

# Python 3.10+ 可直接使用内置泛型
def merge(data: list[int | str]) -> dict[str, int]:
    return dict(enumerate(data))
```

### 运算符

**算术运算符：**

```python
+  -  *  /       # 加、减、乘、除（/ 永远返回 float）
//                # 整除
%                 # 取模
**                # 幂运算
```

**比较 / 逻辑 / 身份运算符：**

```python
==  !=  <  >  <=  >=    # 比较
and  or  not             # 逻辑运算
is   is not              # 身份比较（内存地址）
in   not in              # 成员检查
```

```python
# 链式比较
x = 5
print(1 < x < 10)   # True（Python 独有语法）

# 身份 vs 相等
a = [1, 2]
b = [1, 2]
print(a == b)        # True（值相等）
print(a is b)        # False（不同对象）

# in 运算符
print("hello" in "hello world")  # True
print(3 in [1, 2, 3])            # True
```

### 控制流

#### if / elif / else

```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"    # 进入此分支
elif score >= 70:
    grade = "C"
else:
    grade = "D"
```

#### for 循环

```python
# 遍历 range
for i in range(5):           # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 10, 3):    # 2, 5, 8
    print(i)

# 遍历可迭代对象
for item in ["a", "b", "c"]:
    print(item)

for key, value in {"x": 1, "y": 2}.items():
    print(key, value)
```

#### while 循环

```python
count = 0
while count < 3:
    print(count)
    count += 1
```

#### break / continue / pass

```python
for n in range(10):
    if n == 2:
        continue          # 跳过 2
    if n == 5:
        break             # 提前退出
    if n == 0:
        pass              # 占位，什么也不做
    print(n)
```

#### match / case（Python 3.10+）

```python
def describe(value):
    match value:
        case 0:
            return "零"
        case 1 | 2 | 3:
            return "小数字"
        case int():
            return "大数字"
        case str():
            return f"字符串: {value}"
        case _:
            return "其他"

print(describe(42))    # 大数字
print(describe("hi"))  # 字符串: hi
```

### 推导式（Comprehensions）

```python
# 列表推导
squares = [x**2 for x in range(10) if x % 2 == 0]
# [0, 4, 16, 36, 64]

# 字典推导
square_map = {x: x**2 for x in range(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 集合推导
unique = {x % 3 for x in range(10)}
# {0, 1, 2}

# 生成器表达式（惰性求值）
total = sum(x**2 for x in range(1000))
```

### 异常处理

#### try / except / else / finally

```python
try:
    result = 10 / int(input("输入数字: "))
except ValueError as e:
    print("无效数字:", e)
except ZeroDivisionError:
    print("不能除以零")
else:
    print(f"结果是: {result}")     # 无异常时执行
finally:
    print("无论如何都会执行")       # 清理资源
```

#### 抛出异常

```python
def withdraw(balance, amount):
    if amount > balance:
        raise ValueError(f"余额不足: {balance} < {amount}")
    return balance - amount
```

#### 自定义异常

```python
class InsufficientFundsError(Exception):
    """自定义异常，用于账户余额不足的场景"""
    def __init__(self, balance, amount):
        self.balance = balance
        self.amount = amount
        super().__init__(f"余额 {balance} < 取款 {amount}")

raise InsufficientFundsError(100, 200)
```

### with 语句（上下文管理器）

自动管理资源（文件、锁、数据库连接等）：

```python
# 文件自动关闭
with open("data.txt", "r") as f:
    content = f.read()
# 离开 with 块自动调用 f.close()

# 自定义上下文管理器
class ManagedResource:
    def __enter__(self):
        print("获取资源")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("释放资源")
        return False  # False = 不吞异常

with ManagedResource() as res:
    print("使用资源")
    # 抛出 ResourceWarning 等
```

Python 标准库的 `contextlib` 也提供 `@contextmanager` 装饰器简化自定义：

```python
from contextlib import contextmanager

@contextmanager
def managed():
    print("获取资源")
    yield
    print("释放资源")

with managed():
    print("使用资源")
```

### f-string

Python 3.6+ 引入的字符串格式化，最推荐的方式：

```python
name = "Alice"
age = 30
print(f"{name} is {age} years old")
# Alice is 30 years old

# 表达式与格式化
print(f"pi = {3.14159:.2f}")   # pi = 3.14
print(f"hex = {255:#x}")       # hex = 0xff
print(f"{'right':>10}")        # "     right"（右对齐）

# Python 3.8+：调试模式
print(f"{name=}, {age=}")      # name='Alice', age=30

# 多行 f-string
name = "Bob"
summary = (
    f"Name: {name}\n"
    f"Age: {age}\n"
    f"Adult: {age >= 18}"
)
```

### 输入与输出

```python
# 输出
print("Hello", "World", sep=", ", end="!\n")

# 输入
name = input("请输入名字: ")      # 始终返回 str
age = int(input("请输入年龄: "))  # 需要显式转换

# 文件读写
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello\n")
    f.writelines(["line1\n", "line2\n"])

with open("output.txt", "r") as f:
    for line in f:
        print(line.strip())
```
