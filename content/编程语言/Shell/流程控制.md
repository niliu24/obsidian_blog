## 流程控制

### 退出码与条件判断

Shell 流程控制围绕命令的**退出码**（Exit Code）展开：0 表示成功，非 0 表示失败。

```bash
true        # 退出码 0
false       # 退出码 1
ls /etc     # 成功 → 0
ls /x       # 失败 → 2
echo $?     # 查看上一条命令的退出码
```

### if/elif/else

```bash
if condition; then
    # condition 退出码为 0 时执行
elif condition2; then
    # condition2 退出码为 0 时执行
else
    # 所有条件都不满足时执行
fi
```

`then` 可以放在同一行（用 `;` 分隔），也可以换行：

```bash
if [ "$1" = "start" ]; then
    echo "Starting..."
elif [ "$1" = "stop" ]; then
    echo "Stopping..."
else
    echo "Usage: $0 {start|stop}"
fi
```

### 条件测试：`[ ]` vs `[ ]( .md)` vs `test`

| 形式 | 说明 | 示例 |
|------|------|------|
| `test condition` | 原始测试命令 | `test -f /etc/passwd` |
| `[ condition ]` | `test` 的别名，注意两侧空格 | `[ -f /etc/passwd ]` |
| `[ condition ]( condition .md)` | Bash 扩展关键字，支持更丰富语法 | `[ $str == *.txt ]( $str == *.txt .md)` |

**`[ ]( .md)` 的优势**：

* 支持 `==` 模式匹配和 `=~` 正则匹配
* 变量展开不会触发分词，无需额外引号
* 支持 `&&` `||`（而 `[ ]` 中只能用 `-a` `-o`）
* 支持括号分组

```bash
name="hello.txt"

# [ ] 需要额外小心引号
if [ "$name" = "hello.txt" ]; then ...

# [ ]( .md) 更安全、更强大
if [ $name == *.txt ]( $name == *.txt .md); then           # 模式匹配
    echo "是文本文件"
fi

if [[ $name =~ ^hello\.[a-z]+$ ]]; then # 正则匹配
    echo "匹配正则"
fi

if [ -f "$file" && -r "$file" ]( -f "$file" && -r "$file" .md); then # && 直接使用
    echo "文件存在且可读"
fi
```

### 测试运算符

#### 文件测试

| 运算符 | 为真条件 | 运算符 | 为真条件 |
|--------|---------|--------|---------|
| `-e` | 文件存在 | `-f` | 是普通文件 |
| `-d` | 是目录 | `-L` | 是符号链接 |
| `-r` | 当前用户可读 | `-w` | 当前用户可写 |
| `-x` | 当前用户可执行 | `-s` | 文件大小 > 0 |
| `-O` | 被当前用户拥有 | `-G` | 组匹配当前用户 |
| `-nt` | 比目标文件新 | `-ot` | 比目标文件旧 |

```bash
if [ -f /etc/passwd ]( -f /etc/passwd .md); then
    echo "文件存在"
fi

if [ -d /tmp && -w /tmp ]( -d /tmp && -w /tmp .md); then
    echo "/tmp 存在且可写"
fi

if [ "$file1" -nt "$file2" ]( "$file1" -nt "$file2" .md); then
    echo "$file1 比 $file2 新"
fi
```

#### 字符串比较

| 运算符 | 为真条件 | [ ] | [ ]( .md) |
|--------|---------|-----|-------|
| `=` / `==` | 字符串相等 | `=` 仅 POSIX | 两者皆可 |
| `!=` | 字符串不等 | 支持 | 支持 |
| `<` / `>` | 字典序比较 | 需转义 `\<` | 直接使用 |
| `-z` | 字符串为空（长度 0） | 支持 | 支持 |
| `-n` | 字符串非空 | 支持 | 支持 |

```bash
str=""

if [ -z "$str" ]( -z "$str" .md); then
    echo "空字符串"
fi

if [ "apple" < "banana" ]( "apple" < "banana" .md); then
    echo "apple 排在 banana 前面"
fi
```

#### 数值比较

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `-eq` | 等于 | `[ $a -eq $b ]( $a -eq $b .md)` |
| `-ne` | 不等于 | `[ $a -ne $b ]( $a -ne $b .md)` |
| `-lt` | 小于 | `[ $a -lt $b ]( $a -lt $b .md)` |
| `-le` | 小于等于 | `[ $a -le $b ]( $a -le $b .md)` |
| `-gt` | 大于 | `[ $a -gt $b ]( $a -gt $b .md)` |
| `-ge` | 大于等于 | `[ $a -ge $b ]( $a -ge $b .md)` |

数值比较不能用 `>` `<`（那是字符串重定向和比较）：

```bash
a=10
b=20

if [ $a -lt $b ]( $a -lt $b .md); then
    echo "$a < $b"
fi

# 也可以使用 (( )) 进行算术比较（推荐）
if (( a < b )); then
    echo "$a < $b"
fi

if (( a + b == 30 )); then
    echo "a + b = 30"
fi
```

### for 循环

#### 遍历列表

```bash
# 遍历字面列表
for fruit in apple banana cherry; do
    echo "I like $fruit"
done

# 遍历通配符结果
for file in *.txt; do
    echo "处理文件: $file"
done

# 遍历命令输出
for user in $(cut -d: -f1 /etc/passwd); do
    echo "用户: $user"
done

# 遍历数组
arr=(one two three)
for item in "${arr[@]}"; do
    echo "$item"
done
```

#### C 风格 for

```bash
for (( i = 0; i < 10; i++ )); do
    echo "i = $i"
done

# 步进
for (( i = 0; i < 100; i += 10 )); do
    echo "$i"
done

# 倒序
for (( i = 10; i > 0; i-- )); do
    echo "$i"
done
```

### while 循环

```bash
# 计数器
count=0
while (( count < 5 )); do
    echo "count: $count"
    (( count++ ))
done

# 读取文件行（最安全的逐行读取方式）
while IFS= read -r line; do
    echo "行: $line"
done < /etc/passwd

# 无限循环
while true; do
    echo "运行中..."
    sleep 1
done

# 等待条件（如等待进程退出）
while pgrep -x mysqld > /dev/null; do
    echo "MySQL 还在运行..."
    sleep 2
done
echo "MySQL 已停止"
```

### until 循环

`until` 和 `while` 相反：条件为假时执行，为真时退出：

```bash
count=0
until (( count >= 5 )); do    # count >= 5 时为真，退出循环
    echo "count: $count"
    (( count++ ))
done
```

### break 与 continue

```bash
for i in {1..10}; do
    if (( i == 3 )); then
        continue              # 跳过 3，继续下一次循环
    fi
    if (( i == 8 )); then
        break                 # 到 8 退出整个循环
    fi
    echo "i: $i"
done
# 输出: 1 2 4 5 6 7

# 嵌套循环中跳出外层（使用标签）
for i in {1..3}; do
    for j in {1..3}; do
        if (( i * j > 4 )); then
            break 2            # 跳出两层循环
        fi
        echo "i=$i j=$j"
    done
done
```

### case 模式匹配

```bash
case $1 in
    start|begin)
        echo "启动服务..."
        ;;
    stop|end)
        echo "停止服务..."
        ;;
    restart)
        echo "重启服务..."
        ;;
    *)                          # 默认匹配
        echo "用法: $0 {start|stop|restart}"
        exit 1
        ;;
esac
```

`case` 支持通配符模式：

```bash
case $filename in
    *.txt)
        echo "文本文件"
        ;;
    *.jpg|*.png|*.gif)
        echo "图片文件"
        ;;
    *.sh)
        echo "Shell 脚本"
        ;;
    *)
        echo "未知类型"
        ;;
esac
```

### select 菜单

```bash
PS3="请选择操作: "       # 自定义提示符，默认 #?
options=("启动" "停止" "重启" "退出")

select opt in "${options[@]}"; do
    case $opt in
        "启动")
            echo "正在启动..."
            ;;
        "停止")
            echo "正在停止..."
            ;;
        "重启")
            echo "正在重启..."
            ;;
        "退出")
            echo "再见"
            break
            ;;
        *)
            echo "无效选择"
            ;;
    esac
done
```

运行效果：

```
1) 启动
2) 停止
3) 重启
4) 退出
请选择操作:
```

### 逻辑操作符

#### 命令链

```bash
# &&：前一个成功才执行后一个
mkdir build && cd build && cmake ..

# ||：前一个失败才执行后一个
cd /nonexistent || { echo "目录不存在"; exit 1; }

# ;：顺序执行，不关心退出码
echo "start"; echo "end"

# &：后台执行
long_running_task &

# 组合使用
command && echo "成功" || echo "失败"
# 注意：上面的写法等价于 (command && echo "成功") || echo "失败"
```

#### 短路求值示例

```bash
# 简化 if 语句
[ -f "$file" ]( -f "$file" .md) && echo "文件存在"
[ -z "$name" ]( -z "$name" .md) && { echo "名字为空"; exit 1; }

# 默认值赋值
[ -z "${JAVA_HOME}" ]( -z "${JAVA_HOME}" .md) && export JAVA_HOME=/usr/lib/jvm/java-11
```

### 综合示例：启动脚本框架

```bash
#!/bin/bash
# 一个简单的服务管理脚本

APP_NAME="myapp"
PID_FILE="/var/run/${APP_NAME}.pid"
LOG_FILE="/var/log/${APP_NAME}.log"

start() {
    if [ -f "$PID_FILE" ]( -f "$PID_FILE" .md); then
        pid=$(< "$PID_FILE")
        if kill -0 "$pid" 2>/dev/null; then
            echo "服务已在运行 (PID: $pid)"
            return 0
        fi
        echo "发现过期 PID 文件，清理..."
        rm -f "$PID_FILE"
    fi

    echo "启动 $APP_NAME..."
    nohup ./$APP_NAME >> "$LOG_FILE" 2>&1 &
    echo $! > "$PID_FILE"
    echo "启动完成 (PID: $!)"
}

stop() {
    if [ ! -f "$PID_FILE" ]( ! -f "$PID_FILE" .md); then
        echo "服务未运行"
        return 1
    fi

    pid=$(< "$PID_FILE")
    echo "停止 $APP_NAME (PID: $pid)..."

    if kill "$pid" 2>/dev/null; then
        for i in {1..5}; do
            sleep 1
            if ! kill -0 "$pid" 2>/dev/null; then
                echo "服务已停止"
                rm -f "$PID_FILE"
                return 0
            fi
        done
        echo "强制终止..."
        kill -9 "$pid" 2>/dev/null
        rm -f "$PID_FILE"
    else
        echo "进程不存在，清理 PID 文件"
        rm -f "$PID_FILE"
    fi
}

status() {
    if [ -f "$PID_FILE" ]( -f "$PID_FILE" .md); then
        pid=$(< "$PID_FILE")
        if kill -0 "$pid" 2>/dev/null; then
            echo "$APP_NAME 运行中 (PID: $pid)"
            return 0
        fi
    fi
    echo "$APP_NAME 未运行"
    return 1
}

case $1 in
    start)  start   ;;
    stop)   stop    ;;
    restart) stop; start ;;
    status) status  ;;
    *)
        echo "用法: $0 {start|stop|restart|status}"
        exit 1
        ;;
esac
```
