## 基本语法与变量

### Shebang 行

Shell 脚本的第一行通常以 `#!` 开头，指定脚本的解释器路径：

```bash
#!/bin/bash            # 直接指定 bash 路径
#!/usr/bin/env bash    # 通过 env 查找 bash（更可移植）
#!/bin/sh              # POSIX sh
#!/usr/bin/env python3 # 也可以用于其他解释器
```

* `#!/usr/bin/env bash` 优先使用 PATH 中的 bash，适合跨平台场景
* `#!/bin/sh` 在 Debian/Ubuntu 上实际指向 dash，语法更严格

### 变量声明与使用

**声明规则**：变量名 = 值，`=` 两侧**不能有空格**：

```bash
name="world"           # 正确
name = "world"         # 错误：bash 会将 name 当作命令执行
```

**使用变量**：

```bash
name="world"
echo $name             # 简单引用（可能引起分词问题）
echo "$name"           # 双引号引用（推荐，保留变量内容）
echo ${name}           # 花括号引用（用于消除歧义）
echo ${name}_suffix    # 花括号明确变量名边界

# 最佳实践：变量展开始终用双引号包裹
path="/home/user/my dir"
ls -l "$path"          # 正确处理带空格的路径
ls -l $path            # 错误：会展开为两个参数
```

### 变量类型

Bash 变量默认是字符串，可通过 `declare` 声明特定属性：

| 声明方式 | 类型 | 示例 |
|---------|------|------|
| `var=value` | 字符串 | `str="hello"` |
| `declare -i n=10` | 整数 | 算术运算自动计算，赋值非数字则为 0 |
| `declare -a arr` | 索引数组 | `arr=(a b c)` |
| `declare -A map` | 关联数组 | `map[key]=value`（Bash 4+） |
| `declare -r var` | 只读 | `declare -r PI=3.14`，也可用 `readonly PI=3.14` |

```bash
# 整数
declare -i a=10
declare -i b=20
declare -i sum=a+b     # 自动计算，不需要 $(( ))
echo "$sum"            # 30

# 索引数组
arr=(apple banana cherry)
echo "${arr[0]}"       # apple
echo "${arr[@]}"       # 所有元素
echo "${#arr[@]}"      # 数组长度
arr+=(date)            # 追加元素

# 关联数组（Bash 4+）
declare -A scores
scores[Alice]=95
scores[Bob]=87
echo "${scores[Alice]}"    # 95
echo "${!scores[@]}"       # 所有键：Alice Bob

# 只读变量
readonly VERSION="1.0"
VERSION="2.0"          # 错误：VERSION 是只读的
```

### 环境变量

环境变量从父进程继承给子进程，使用 `export` 导出：

```bash
# 设置并导出
export MY_VAR="hello"

# 先赋值再导出
MY_VAR="hello"
export MY_VAR

# 仅在子进程环境中设置（临时）
PATH="/custom/path:$PATH" my_command

# 查看环境变量
env                    # 列出所有环境变量
echo "$PATH"           # 命令搜索路径
echo "$HOME"           # 用户家目录
echo "$USER"           # 当前用户名
echo "$SHELL"          # 当前 Shell 路径
echo "$PWD"            # 当前工作目录
echo "$LANG"           # 语言环境设置
```

### 特殊变量

| 变量 | 含义 | 示例 |
|------|------|------|
| `$0` | 脚本名称 | `./script.sh` |
| `$1` - `$9` | 位置参数第 1-9 个 | `$1` 是第一个参数 |
| `${10}` | 第 10 个及更多位置参数 | 花括号包裹 |
| `$#` | 位置参数的个数 | `./s.sh a b` → 2 |
| `$@` | 所有参数（每个参数独立引用） | `"$@"` → `"a" "b" "c"` |
| `$*` | 所有参数（合并为一个字符串） | `"$*"` → `"a b c"` |
| `$?` | 上一条命令的退出码 | 0 成功，非 0 失败 |
| `$$` | 当前 Shell 的 PID | 用于生成临时文件名 |
| `$!` | 最后一个后台进程的 PID | 配合 `wait $!` 使用 |
| `$-` | 当前 Shell 的选项标志 | `himBHs` 等 |
| `$_` | 上一条命令的最后一个参数 | 快捷操作 |

```bash
#!/bin/bash
echo "脚本名: $0"
echo "参数个数: $#"
echo "第一个参数: $1"

for arg in "$@"; do    # "$@" 保留每个参数的独立性
    echo "参数: $arg"
done

ls /nonexistent
echo "退出码: $?"      # 2

sleep 10 &
echo "后台 PID: $!"
```

### 命令替换

将命令的输出赋值给变量或嵌入到字符串中：

```bash
# 推荐：$() 语法，可嵌套
current_date=$(date +%Y-%m-%d)
files_count=$(ls | wc -l)
nested=$(echo "今天是 $(date +%A)")

# 旧式：反引号（不推荐，不可嵌套）
current_date=`date +%Y-%m-%d`

echo "日期: $current_date"
echo "文件数: $files_count"
```

### 引号机制

| 引号类型 | 行为 | 示例 |
|---------|------|------|
| 无引号 | 分词 + 通配符展开 | `echo $var` |
| 单引号 `'` | **保留字面值**，无变量展开/转义 | `echo '$HOME'` → `$HOME` |
| 双引号 `"` | **保留变量展开**，阻止分词和通配符 | `echo "$HOME"` → `/home/user` |
| $'…' | ANSI-C 转义序列 | `echo $'line1\nline2'` |

```bash
name="Alice"

echo $name             # Alice
echo '$name'           # $name（单引号原样输出）
echo "$name"           # Alice（双引号展开变量）

# 实际区别：分词与通配符
files="*.txt a.txt b.txt"
echo $files            # 展开为多个参数，*.txt 也展开为文件名
echo "$files"          # 保持一个参数：*.txt a.txt b.txt

# ANSI-C 转义
echo $'Tab:\tValue'    # \t 展开为制表符
echo $'Line1\nLine2'   # \n 换行
```

### 花括号展开（Brace Expansion）

```bash
echo {1..5}            # 1 2 3 4 5
echo {a..e}            # a b c d e
echo {1..10..2}        # 1 3 5 7 9（步进）
echo {a,b,c}.txt       # a.txt b.txt c.txt
echo file{1..3}.bak    # file1.bak file2.bak file3.bak
mkdir -p project/{src,doc,test}  # 创建多个目录
```

### 算术展开

```bash
echo $(( 3 + 5 ))           # 8
echo $(( 10 / 3 ))          # 3（整除）
echo $(( 2 ** 10 ))         # 1024（乘方）
echo $(( (3 + 5) * 2 ))     # 16

a=10
b=20
echo $(( a + b ))           # 30（变量名不需要 $）

# 进制转换
echo $(( 0xff ))            # 255（十六进制）
echo $(( 8#77 ))            # 63（八进制）
echo $(( 2#1010 ))          # 10（二进制）

# 复合赋值
(( count++ ))
(( total += 10 ))

# let 命令（等效，但不推荐）
let "result = a * b"
```

### 变量默认值与替换

```bash
# 默认值
echo "${var:-default}"      # var 未定义或为空 → default
echo "${var:=default}"      # var 未定义或为空 → 赋值为 default
echo "${var:+replacement}"  # var 有定义 → replacement（否则空）

# 变量存在性检查
echo "${var:?错误: var 未设置}"  # var 未定义 → 输出错误并退出

# 字符串截取
str="hello_world.txt"
echo "${str:0:5}"           # hello（偏移 5 字符）
echo "${str:6}"             # world.txt（偏移到末尾）
echo "${str: -4}"           # .txt（末尾 4 字符，注意空格）

# 模式匹配删除
echo "${str#*.}"            # txt（删除最短前缀匹配 *.）
echo "${str##*.}"           # txt（删除最长前缀匹配 *.）
echo "${str%.*}"            # hello_world（删除最短后缀 .*）
echo "${str%%.*}"           # hello_world（删除最长后缀 .*）

# 查找替换
echo "${str/world/everyone}"    # hello_everyone.txt（替换第一个）
echo "${str//o/x}"              # hellx_wxrld.txt（替换全部）
echo "${str/#hello/hi}"         # 前缀匹配替换
echo "${str/%.txt/.bak}"        # 后缀匹配替换

# 大小写转换（Bash 4+）
str="Hello World"
echo "${str,,}"             # hello world（全部小写）
echo "${str^^}"             # HELLO WORLD（全部大写）
echo "${str,}"              # hello World（首字母小写）
echo "${str^}"              # Hello World（首字母大写）
```
