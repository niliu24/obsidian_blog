## 文本处理

Shell 最强大的能力之一是与文本处理工具的组合。通过管道将这些工具串联起来，可以构建出极其灵活的数据处理流水线。

### grep — 文本搜索

在文件或标准输入中搜索匹配模式的行：

```bash
# 基础用法
grep "pattern" file.txt            # 在文件中搜索
grep "error" /var/log/syslog       # 搜索日志
command | grep "keyword"           # 从管道输入搜索

# 常用选项
grep -i "pattern" file.txt         # 忽略大小写
grep -v "pattern" file.txt         # 反向匹配（不包含 pattern 的行）
grep -r "pattern" /path/           # 递归搜索目录
grep -n "pattern" file.txt         # 显示行号
grep -c "pattern" file.txt         # 只计数匹配行数
grep -l "pattern" *.txt            # 只显示匹配的文件名
grep -w "word" file.txt            # 精确匹配整个单词

# 上下文控制
grep -A 3 "error" log.txt          # 匹配行 + 后 3 行
grep -B 2 "error" log.txt          # 匹配行 + 前 2 行
grep -C 2 "error" log.txt          # 匹配行 + 前后各 2 行

# 正则表达式
grep "^2024-" log.txt              # 行首匹配
grep "error$" log.txt              # 行尾匹配
grep "[0-9]\{3\}\.[0-9]\{3\}"     # 基础正则（BRE）

# 扩展正则（推荐）
grep -E "error|failed" log.txt     # 或匹配
grep -E "^[A-Z].*\." file.txt     # 以大写开头句点结尾
grep -E "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}"  # IP 地址

# grep -E 等效于 egrep（已弃用）
egrep "pattern1|pattern2" file.txt # 旧式语法
```

**实际示例**：

```bash
# 排除注释行和空行
grep -vE "^\s*(#|$)" /etc/nginx/nginx.conf

# 统计每种 HTTP 状态码的出现次数
grep -oP 'HTTP/\d\.\d" \K\d{3}' access.log | sort | uniq -c | sort -rn

# 查找所有包含 TODO/FIXME 的文件
grep -rnl "TODO\|FIXME" src/ --include="*.py" --include="*.js"
```

### sed — 流编辑器

sed（Stream Editor）对输入流进行编辑操作，常用于替换、删除、插入。

```bash
# === 替换（substitute）===
sed 's/old/new/' file.txt            # 替换每行第一个匹配
sed 's/old/new/g' file.txt           # 全局替换（所有匹配）
sed 's/old/new/2' file.txt           # 替换每行第二个匹配
sed 's/old/new/ig' file.txt          # 忽略大小写 + 全局
sed 's|/usr/local|/opt|g' file.txt   # 使用 | 作为分隔符（路径友好）

# 行地址
sed '3s/old/new/' file.txt           # 只替换第 3 行
sed '1,5s/old/new/g' file.txt        # 第 1-5 行
sed '10,$s/old/new/g' file.txt       # 第 10 行到末尾
sed '/section/s/old/new/' file.txt   # 匹配 "section" 的行

# 在原文件上修改（-i）
sed -i 's/foo/bar/g' file.txt             # 直接修改原文件
sed -i.bak 's/foo/bar/g' file.txt         # 修改前备份为 file.txt.bak

# 删除
sed '3d' file.txt                  # 删除第 3 行
sed '1,5d' file.txt                # 删除第 1-5 行
sed '/^#/d' file.txt               # 删除所有注释行
sed '/^$/d' file.txt               # 删除所有空行
sed -n '/ERROR/p' log.txt          # 只打印匹配行（-n 禁止默认输出）

# 打印
sed -n '10,20p' file.txt           # 打印 10-20 行（类似 head/tail 组合）
sed -n '/pattern/p' file.txt       # 打印匹配行

# 追加/插入
sed '5a\这是新行' file.txt         # 在第 5 行后追加
sed '5i\这是新行' file.txt         # 在第 5 行前插入

# 多命令
sed -e 's/foo/bar/g' -e 's/baz/qux/g' file.txt
sed 's/foo/bar/g; s/baz/qux/g' file.txt    # 分号分隔
```

**实际示例**：

```bash
# 去除行首行尾空白
sed 's/^[:space:](:space:.md)*//; s/[:space:](:space:.md)*$//' file.txt

# 将 Windows 换行符 (\r\n) 转为 Unix (\n)
sed 's/\r$//' windows.txt > unix.txt

# 在每行前加行号
sed = file.txt | sed 'N; s/\n/\t/'

# 删除 HTML 标签（粗暴版）
sed 's/<[^>]*>//g' page.html

# 提取 IP 地址（结合正则捕获分组）
echo "192.168.1.1 - - [01/Jan/2024]" | sed -n 's/\([0-9.]*\).*/\1/p'
```

### awk — 文本分析工具

awk 是强大的文本处理语言，天然支持字段分割、关联数组、格式化输出。

```
# 结构：awk 'pattern { action }' file
```

**字段处理**：

```bash
# 默认按空白分隔，$1/$2/... 表示第 N 个字段，$0 表示整行
awk '{print $1, $3}' /etc/passwd         # 打印第 1、3 列
awk -F: '{print $1, $6}' /etc/passwd     # 以 : 为分隔符
awk '{print NF, $NF}' file.txt           # NF=字段数，$NF=最后一个字段

# 自定义分隔符，输出
awk -F: '{printf "%-10s %s\n", $1, $7}' /etc/passwd
```

**内置变量**：

| 变量 | 含义 | 示例 |
|------|------|------|
| `NR` | 当前行号（Number of Record） | `awk 'NR==1' file` 打印首行 |
| `NF` | 当前行的字段数 | `awk '{print NF}'` |
| `$0` | 整行内容 | `awk '{print $0}'` |
| `$1`…`$NF` | 具体字段 | |
| `FS` | 字段分隔符（默认空白） | `awk -F: '…'` |
| `OFS` | 输出字段分隔符（默认空格） | `awk -v OFS=',' '…'` |
| `RS` | 记录分隔符（默认换行） | |
| `ORS` | 输出记录分隔符（默认换行） | |

**BEGIN/END 块**：

```bash
# BEGIN：在处理任何输入前执行，用于初始化
# END：处理完所有输入后执行，用于汇总

awk 'BEGIN {print "用户名","Shell"} 
     {print $1, $7}' FS=: OFS=, /etc/passwd

awk 'NR > 1 {sum += $1} 
     END {print "总和:", sum}' numbers.txt

# 统计
awk 'BEGIN {print "--- 报告 ---"} 
     {count++; total += $1} 
     END {print "行数:", count, "平均值:", total/count}' data.txt
```

**模式匹配**：

```bash
awk '/error/ {print}' log.txt              # 正则匹配行
awk '$3 > 100 {print $1, $3}' data.txt     # 条件判断
awk 'NR > 1 && $2 ~ /^A/' data.txt         # 组合条件（除首行，第2列以A开头）
```

**关联数组**：

```bash
# 统计每个 IP 的访问次数
awk '{count[$1]++} 
     END {for (ip in count) print ip, count[ip]}' access.log

# 按第二列分组求和
awk '{sum[$2] += $3} 
     END {for (k in sum) print k, sum[k]}' sales.txt

# 统计各 Shell 的用户数
awk -F: '{shells[$NF]++} 
     END {for (s in shells) print s, shells[s]}' /etc/passwd | sort -rn -k2
```

**格式化输出**：

```bash
awk '{printf "%-20s %8d %8.2f\n", $1, $2, $3}' data.txt
# %-20s：左对齐 20 字符字符串
# %8d：右对齐 8 位整数
# %8.2f：右对齐 8 位含 2 位小数的浮点数
```

### cut — 列提取

```bash
cut -d: -f1,3 /etc/passwd          # 以 : 为分隔，提取第 1,3 字段
cut -d, -f2-4 data.csv             # 提取第 2-4 字段
cut -c1-10 file.txt                # 提取每行前 10 个字符
cut -c3-5,8-10 file.txt            # 提取第 3-5 和 8-10 字符
```

### sort — 排序

```bash
sort file.txt                      # 字典序排序
sort -n numbers.txt                # 数字排序
sort -n -r data.txt                # 数字逆序
sort -u file.txt                   # 排序并去重（等效 sort | uniq）
sort -k2 data.txt                  # 按第 2 列排序
sort -t: -k3 -n /etc/passwd        # 以 : 分隔，按第 3 列（UID）数字排序
sort -t, -k2,2 -k1 file.csv       # 先按第 2 列，再按第 1 列
sort -h sizes.txt                  # 人类可读大小排序（2K, 1M, 3G...）
```

### uniq — 去重与计数

```bash
sort file.txt | uniq               # 去重（必须先排序）
sort file.txt | uniq -c            # 计数每个不重复行
sort file.txt | uniq -d            # 只显示重复行
sort file.txt | uniq -u            # 只显示不重复行

# 实际示例：日志中 IP 访问量统计
grep -oP '^\S+' access.log | sort | uniq -c | sort -rn | head -10
```

### wc — 行/词/字符统计

```bash
wc file.txt                        # 行数 词数 字节数 文件名
wc -l file.txt                     # 只统计行数
wc -w file.txt                     # 只统计词数
wc -c file.txt                     # 只统计字节数
wc -m file.txt                     # 只统计字符数

# 常用：统计代码行数
find src/ -name "*.c" | xargs wc -l
find . -name "*.py" -exec wc -l {} \; | tail -1  # 总行数
```

### tr — 字符转换

```bash
# 大小写转换
echo "Hello World" | tr 'a-z' 'A-Z'       # HELLO WORLD
cat file.txt | tr '[:lower:]' '[:upper:]'  # 大小写转换（locale 安全）

# 删除字符
echo "Hello 123 World" | tr -d '0-9'      # Hello  World
cat file.txt | tr -d '\r'                  # 删除 Windows 换行符

# 压缩连续重复字符
echo "a    b      c" | tr -s ' '          # a b c
cat file.txt | tr -s '\n'                  # 压缩连续空行为单空行

# 补集
echo "user:pass:uid:gid" | tr -c '[:alnum:]' '\n'  # 非字母数字替换为换行
```

### xargs — 参数构建

从标准输入读取数据，构建并执行命令：

```bash
# 基本用法
find . -name "*.tmp" | xargs rm -f        # 将 find 结果作为 rm 参数

# -I 指定替换字符串（用于需要控制参数位置的命令）
find . -name "*.txt" | xargs -I {} cp {} /backup/

# -n 指定每批参数个数
echo {1..10} | xargs -n 3                  # 每组 3 个参数执行一次

# -P 并行执行（批量任务加速）
seq 1 10 | xargs -P 4 -I {} ./process.sh {}

# 处理文件名中的空格（关键！）
find . -name "*.txt" -print0 | xargs -0 wc -l   # 空字符分隔，安全处理空格

# 实际示例
# 找出所有大于 100MB 的文件并删除
find /var/log -type f -size +100M -print0 | xargs -0 rm -f

# 并行压缩文件
find . -name "*.log" | xargs -P $(nproc) -I {} gzip {}
```

### 管道组合：实战

```bash
# 1. 查看最耗 CPU 的 5 个进程
ps aux | sort -nrk 3 | head -5

# 2. 查看最耗内存的 5 个进程
ps aux | sort -nrk 4 | head -5

# 3. Nginx 访问日志分析：最常访问的 10 个 URL
awk '{print $7}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -10

# 4. 找出最近修改的 5 个文件并显示详细信息
find . -type f -printf '%T@ %p\n' | sort -rn | head -5 | cut -d' ' -f2- | xargs ls -lh

# 5. 检查哪些端口在监听
ss -tlnp | awk 'NR>1 {print $4}' | cut -d: -f2 | sort -n | uniq

# 6. CSV 文件中某列求和
awk -F, '{sum+=$3} END {print sum}' sales.csv

# 7. 提取 URL 中的所有域名
grep -oP 'https?://\K[^/]+' urls.txt | sort -u

# 8. 为 Markdown 标题自动生成锚点
grep '^## ' doc.md | sed 's/^## //' | while read -r title; do
    anchor=$(echo "$title" | tr 'A-Z ' 'a-z-')
    echo "- [$title](#$anchor)"
done

# 9. 监控日志中新的 ERROR 出现
tail -f app.log | grep --line-buffered "ERROR"

# 10. 分发 SSH 公钥到多台机器
cat hosts.txt | xargs -I {} ssh-copy-id user@{}

# 11. 找出并统计代码中的函数定义（从函数声明行提取函数名）
grep -rn "^def " src/ | awk -F: '{print $3}' | sed 's/def //; s/(.*//' | sort | uniq -c | sort -rn

# 12. 提取 Docker 镜像的悬挂镜像并清理
docker images -f dangling=true -q | xargs docker rmi
```
