## 常用命令速查

### 文件操作

| 命令 | 说明 | 常用选项 |
|------|------|----------|
| `ls` | 列出目录内容 | `-l` 详细格式，`-a` 显示隐藏文件，`-h` 人类可读大小，`-t` 按时间排序，`-S` 按大小排序，`-R` 递归 |
| `cp` | 复制文件/目录 | `-r` 递归复制目录，`-p` 保留属性，`-a` 归档模式，`-i` 覆盖前提示，`-v` 显示详情 |
| `mv` | 移动/重命名 | `-i` 覆盖前提示，`-v` 显示详情，`-u` 仅源文件更新时移动 |
| `rm` | 删除文件/目录 | `-r` 递归删除目录，`-f` 强制删除不提示，`-i` 逐个确认，`-v` 显示详情 |
| `find` | 搜索文件 | `-name` 按名称，`-type f/d` 文件/目录，`-size` 按大小，`-mtime` 按修改时间，`-exec` 执行命令 |
| `touch` | 创建空文件/更新时间戳 | `-t` 指定时间戳，`-c` 不创建新文件 |
| `chmod` | 修改权限 | `u+x` 给所有者加执行，`644` `755` 数字模式，`-R` 递归 |
| `chown` | 修改所有者 | `user:group` 同时修改，`-R` 递归 |
| `ln` | 创建链接 | `-s` 符号链接（软链接），无选项创建硬链接 |
| `stat` | 查看文件详细信息 | 显示 inode、权限、时间戳、大小、块数等元数据 |

**示例**：

```bash
# 文件操作
ls -lah /etc          # 详细列出 /etc
cp -rp source/ dest/  # 递归复制并保留属性
rm -rf /tmp/build/    # 递归强制删除目录
find /var/log -name "*.log" -mtime +30 -delete  # 删除30天前的日志

# 权限与链接
chmod 755 script.sh   # rwxr-xr-x
chown -R www:www /var/www/
ln -s /usr/local/nginx/sbin/nginx /usr/local/bin/
```

**数字权限速查**：

```
7 = rwx (读+写+执行)
6 = rw- (读+写)
5 = r-x (读+执行)
4 = r-- (只读)
0 = --- (无权限)
```

### 文本查看

| 命令 | 说明 | 常用选项 |
|------|------|----------|
| `cat` | 输出文件内容 | `-n` 显示行号，`-b` 非空行编号，`-A` 显示所有字符 |
| `head` | 查看文件开头 | `-n 20` 显示前 20 行，`-c 100` 显示前 100 字节 |
| `tail` | 查看文件末尾 | `-n 20` 显示最后 20 行，`-f` 实时跟踪追加内容，`-F` 跟踪 + 轮转检测 |
| `less` | 分页查看（推荐） | `/搜索`，`n/N` 上下翻搜索结果，`g/G` 首尾，`q` 退出 |
| `more` | 分页查看（基础） | 空格翻页，Enter 逐行，`q` 退出 |

**示例**：

```bash
tail -f /var/log/syslog    # 实时查看系统日志
tail -n 100 app.log        # 查看最后 100 行
head -n 5 data.csv         # 查看 CSV 头部
less +F /var/log/nginx/access.log  # less 中按 Shift+F 进入跟踪模式
```

### 系统信息

| 命令 | 说明 | 常用选项 |
|------|------|----------|
| `ps` | 查看进程快照 | `aux` 所有进程，`ef` 完整格式，`-eo` 自定义输出列 |
| `top` | 实时进程监控 | `M` 按内存排序，`P` 按 CPU 排序，`1` 查看每个核心 |
| `htop` | 增强版 top（需安装） | 交互友好，支持滚动和鼠标操作 |
| `df` | 磁盘空间使用 | `-h` 人类可读，`-T` 显示文件系统类型，`-i` inode 使用率 |
| `du` | 目录/文件占用空间 | `-sh` 汇总人类可读，`--max-depth=1` 只查一级子目录 |
| `free` | 内存使用情况 | `-h` 人类可读，`-m` MB 单位，`-s 5` 每 5 秒刷新 |
| `uname` | 系统内核信息 | `-a` 所有信息，`-r` 内核版本，`-m` 架构 |
| `uptime` | 系统运行时间 | 显示已运行时间、登录用户数、平均负载 |
| `lscpu` | CPU 详细信息 | 架构、核心数、线程数、缓存 |
| `lsblk` | 块设备列表 | 磁盘、分区、挂载点的树形视图 |

**示例**：

```bash
ps aux --sort=-%mem | head -10          # 内存占用 Top 10
du -sh * | sort -rh                     # 当前目录各项目大小排序
df -hT                                  # 磁盘使用情况 + 文件系统类型
free -h                                 # 内存使用人类可读
```

### 网络工具

| 命令 | 说明 | 常用选项 |
|------|------|----------|
| `curl` | HTTP 请求工具 | `-I` 只查头部，`-O` 下载文件，`-o` 指定输出文件，`-L` 跟随重定向，`-s` 静默模式 |
| `wget` | 文件下载工具 | `-c` 断点续传，`-r` 递归下载，`-O` 指定输出文件名，`-q` 安静模式 |
| `ping` | 网络连通测试 | `-c N` 发送 N 个包，`-i N` 间隔秒数，`-W N` 超时秒数 |
| `ss` | 套接字统计（现代版） | `-t` TCP，`-l` 监听态，`-n` 不解析服务名，`-p` 显示进程 |
| `netstat` | 网络状态（旧版） | `-tlnp` TCP 监听端口，`-r` 路由表 |
| `nc` | 网络瑞士军刀 | `-z` 扫描端口，`-v` 详细，`-l` 监听模式，`-k` 保持连接 |
| `dig` | DNS 查询 | `+short` 简洁输出，`@server` 指定 DNS 服务器，`-x` 反向查询 |
| `nslookup` | DNS 查询（旧版） | `-type=MX` 查询 MX 记录 |
| `traceroute` | 路由追踪 | 显示到目标经过的每一跳 |

**示例**：

```bash
curl -I https://example.com                              # 查看 HTTP 响应头
curl -s https://api.github.com/repos/user/repo | jq .    # JSON API 调用
ss -tlnp                                                  # 查看监听端口和对应进程
dig +short example.com                                    # 快速 DNS 查询
nc -zv host 22 80 443                                     # 扫描目标端口
```

### 进程管理

| 命令 | 说明 | 常用选项 |
|------|------|----------|
| `kill` | 发送信号给进程 | `-15` SIGTERM（默认，优雅终止），`-9` SIGKILL（强制），`-0` 测试进程存在 |
| `killall` | 按名称杀进程 | `-9` 强制，`-i` 交互确认，`-r` 正则匹配 |
| `pkill` | 按名称/条件杀进程 | `-f` 匹配完整命令行，`-u user` 只杀某用户的进程 |
| `nohup` | 忽略 HUP 信号运行 | 终端关闭后保持运行，输出到 nohup.out |
| `bg` | 后台继续运行 | 将挂起的进程放到后台 |
| `fg` | 前台运行 | 将后台进程调回前台 |
| `jobs` | 查看后台任务 | `-l` 显示 PID |

**示例**：

```bash
kill -15 1234        # 优雅终止 PID 1234
kill -9 1234         # 强制终止（最后手段）
killall -9 chrome    # 强制杀掉所有 chrome 进程
nohup python server.py &
nohup ./app > app.log 2>&1 &  # 指定日志文件后台运行

# 作业控制
sleep 100            # Ctrl+Z 挂起
bg                   # 后台运行
jobs -l              # 查看后台任务
fg %1                # 调回前台
```

### 归档压缩

| 命令 | 说明 | 常用选项 |
|------|------|----------|
| `tar` | 打包/解包 | `-czf` 创建 gz 压缩包，`-xzf` 解压 gz 包，`-cjf` bz2，`-cJf` xz，`-tf` 查看内容，`-v` 显示详情 |
| `gzip` | gz 压缩 | `-k` 保留原文件，`-d` 解压，`-r` 递归，`-v` 显示压缩比 |
| `gunzip` | gz 解压 | 等效 `gzip -d` |
| `zip` | zip 压缩（跨平台） | `-r` 递归目录，`-q` 安静，`-d` 从压缩包删除 |
| `unzip` | zip 解压 | `-l` 查看内容不解压，`-d dir` 解压到指定目录 |

**示例**：

```bash
tar -czf project.tar.gz project/        # 创建 tar.gz 压缩包
tar -xzf project.tar.gz -C /tmp/        # 解压到 /tmp
tar -tf project.tar.gz                  # 查看包内容

tar -cjf project.tar.bz2 project/       # bz2 压缩（更小但更慢）
tar -cJf project.tar.xz project/        # xz 压缩（最小）

tar -czf archive.tar.gz --exclude="*.log" --exclude="node_modules" project/

zip -r archive.zip project/
unzip -l archive.zip                    # 查看 zip 内容
unzip archive.zip -d /tmp/extracted/
```

### 搜索命令

| 命令 | 说明 | 常用选项 |
|------|------|----------|
| `find` | 文件搜索（最强大） | `-name`，`-type`，`-size`，`-mtime`，`-perm`，`-exec`，`-delete` |
| `grep` | 文件内容搜索 | `-r` 递归，`-i` 忽略大小写，`-n` 行号，`-l` 仅文件名，`-c` 计数 |
| `locate` | 快速文件名搜索（基于数据库） | `-i` 忽略大小写，`-c` 计数，需 `updatedb` 更新数据库 |
| `which` | 查找可执行文件路径 | 只在 PATH 中搜索 |
| `whereis` | 查找二进制/源码/man 页 | 搜索标准系统目录，比 `which` 范围广 |

**示例**：

```bash
find /var -name "*.log" -size +100M -mtime +7    # 大且旧的日志文件
find . -type f -name "*.py" -exec grep -l "TODO" {} \;  # 含 TODO 的 Python 文件
find / -perm -4000 -type f                        # 查找所有 SUID 文件

grep -rn "FIXME" --include="*.{py,js,go}" .       # 在 py/js/go 文件中搜索 FIXME
locate -i nginx.conf                               # 快速查找 nginx.conf 位置
which python3                                      # 查看 python3 路径
whereis ls                                         # 查看 ls 的二进制和 man 页位置
```
