> C++ 的类（class）是面向对象编程的核心机制，将数据和操作封装为一个单元。支持继承、多态、访问控制等 OOP 特性。struct 与 class 的唯一区别是默认访问权限不同——struct 默认 public，class 默认 private。

## Class vs Struct

```cpp
struct Point {
    int x, y;                // 默认 public
    void print() const { /*...*/ }
};

class Circle {
    double radius;           // 默认 private
public:
    explicit Circle(double r) : radius(r) {}
    double area() const { return 3.14159 * radius * radius; }
};
```

| 特性 | struct | class |
|------|--------|-------|
| 默认访问权限 | `public` | `private` |
| 默认继承方式 | `public` | `private` |
| 语义约定 | 轻量数据聚合（POD） | 封装 + 行为的抽象数据类型 |

## 构造函数

构造函数在对象创建时自动调用，负责初始化成员。

### 默认构造函数

```cpp
class Widget {
public:
    Widget() = default;                    // 编译器生成版本
    Widget(const std::string& name) {}     // 参数化构造函数
};

Widget w;                                  // 调用默认构造函数
Widget w2("hello");                        // 调用参数化构造函数
```

> 一旦用户定义**任意**构造函数，编译器**不再**生成默认构造函数，需要显式声明 `Widget() = default;`。

### 初始化列表 vs 赋值

```cpp
class Employee {
    std::string name;
    const int id;               // const 成员必须在初始化列表中
    int& ref;                   // 引用成员也必须在初始化列表中
public:
    // 正确：使用初始化列表
    Employee(const std::string& n, int i)
        : name(n), id(i), ref(id) {}

    // 错误：赋值方式，id 和 ref 必须先默认初始化（失败）
    // Employee(const std::string& n, int i) { name = n; id = i; }
};
```

**初始化列表规则**:

* 成员按**声明顺序**初始化（而非初始化列表顺序）
* const 和引用成员**必须**用初始化列表
* 基类和非默认构造的子对象也必须在初始化列表中指定

### 拷贝构造函数

```cpp
class String {
    char* data;
public:
    String(const char* s) { /* 分配并拷贝 */ }
    // 拷贝构造函数
    String(const String& other) {
        data = new char[strlen(other.data) + 1];
        strcpy(data, other.data);
    }
    ~String() { delete[] data; }
};

String a("hello");
String b = a;       // 调用拷贝构造函数
```

### 移动构造函数（C++11）

```cpp
class String {
    char* data;
public:
    // 移动构造函数："窃取"资源而非拷贝
    String(String&& other) noexcept
        : data(other.data) {
        other.data = nullptr;   // 原对象置空
    }
};

String c = std::move(a);  // 调用移动构造函数
```

> 详见 [移动语义](移动语义.md)。

### 委托构造函数（C++11）

```cpp
class Point {
    int x, y;
public:
    Point() : Point(0, 0) {}           // 委托给下面的构造函数
    Point(int a, int b) : x(a), y(b) {}
};
```

### explicit 构造函数

```cpp
class SafeBool {
    bool value;
public:
    explicit SafeBool(bool v) : value(v) {}
    explicit operator bool() const { return value; }
};

SafeBool sb = true;    // 错误：explicit 禁止隐式转换
SafeBool sb2(true);    // 正确：显式调用
```

`explicit` 防止单参数构造函数被用作隐式类型转换。C++11 起也可用于转换运算符。

## 析构函数

```cpp
class Buffer {
    int* ptr;
public:
    Buffer(size_t n) : ptr(new int[n]) {}
    ~Buffer() { delete[] ptr; }   // 析构：对象销毁时自动释放资源
};
```

* 析构函数不接受参数，无返回值，不能重载
* 析构顺序与构造顺序**相反**：先派生后基类、先成员后自身
* 如果基类有多态行为，析构函数应为 `virtual`（详见 [虚函数与vtable](虚函数与vtable.md)）

## 继承

### 访问控制

| 基类成员权限 | public 继承 | protected 继承 | private 继承 |
|-------------|-------------|----------------|--------------|
| `public`    | public      | protected      | private      |
| `protected` | protected   | protected      | private      |
| `private`   | 不可见      | 不可见          | 不可见        |

```cpp
class Base {
public:
    int a;
protected:
    int b;
private:
    int c;
};

struct DerivedPublic : Base {
    // a: public,  b: protected,  c: 不可访问
};

class DerivedPrivate : Base {      // class 默认 private 继承
    // a: private, b: private, c: 不可访问
};
```

### 虚继承（菱形继承问题）

```cpp
// 菱形继承：D 包含两个 A 子对象
class A { public: int x; };
class B : public A {};
class C : public A {};
class D : public B, public C {};   // D 中有两个 A::x，访问二义

// 解决方案：虚继承
class B : virtual public A {};  // 或者 public virtual A
class C : virtual public A {};
class D : public B, public C {};   // D 中只有一个 A::x

D d;
d.x = 42;  // 虚继承后无歧义
```

**虚继承代价**: 需要 vtable 机制来定位虚基类子对象，增加间接性和内存开销。

## this 指针

```cpp
class Counter {
    int count = 0;
public:
    Counter& increment() {
        ++count;
        return *this;           // 返回自身引用，支持链式调用
    }
    void set(int count) {
        this->count = count;    // 区分参数和成员
    }
};
```

* `this` 是**右值指针**，指向调用成员函数的对象
* 静态成员函数中没有 `this`
* 返回 `*this` 是实现运算符重载（如 `operator=`）的惯用方式

## 静态成员

```cpp
class Logger {
    static int instanceCount;          // 静态成员声明
    static const int MAX = 100;        // 静态常量可在类内初始化
    static Logger& getInstance();      // 静态成员函数
};

int Logger::instanceCount = 0;         // 静态成员定义（唯一一次）
```

| 特性 | 说明 |
|------|------|
| 静态成员变量 | 所有对象共享一份，类外定义 |
| 静态成员函数 | 无 `this` 指针，只能访问静态成员 |
| 调用方式 | `ClassName::static_member` 或通过对象 `.` 访问 |

## 友元

```cpp
class Matrix {
    int data[4][4];
public:
    friend Matrix operator+(const Matrix& a, const Matrix& b);  // 友元函数
    friend class Vector;                                         // 友元类
};

// 友元函数可以访问私有成员
Matrix operator+(const Matrix& a, const Matrix& b) {
    Matrix result;
    for (int i = 0; i < 4; ++i)
        for (int j = 0; j < 4; ++j)
            result.data[i][j] = a.data[i][j] + b.data[i][j];
    return result;
}
```

**注意事项**:

* 友元关系**不能继承**
* 友元关系**不传递**（A 是 B 的友元，B 是 C 的友元，A 不一定是 C 的友元）
* 友元破坏了封装性，应谨慎使用

## const 成员函数

```cpp
class Vector2D {
    double x, y;
public:
    double length() const {          // const 成员函数
        return std::sqrt(x*x + y*y);
    }
    void scale(double factor) {      // 非 const
        x *= factor; y *= factor;
    }
};

void print(const Vector2D& v) {     // const 引用
    v.length();                      // 正确：const 对象只能调 const 函数
    // v.scale(2.0);                 // 错误：const 对象不能调非 const 函数
}
```

* `const` 成员函数保证不修改 `*this` 的（非 mutable）成员
* 重载可以按 const 区分：`void get() const {}` vs `void get() {}`
* `mutable` 关键字允许在 const 函数中修改特定成员（如缓存、互斥锁计数）
