> 移动语义（Move Semantics）是 C++11 引入的重大改进，允许将资源从一个对象 " 窃取 " 到另一个对象，避免昂贵的深拷贝。配合右值引用（Rvalue Reference, `T&&`），实现了零开销的资源转移。

## 左值与右值

C++ 中每个表达式要么是左值要么是右值：

```cpp
int x = 42;          // x 是左值（有地址、有名字）
int y = x;           // x 是左值（可出现在赋值左边）
int z = x + 1;       // x + 1 是右值（没有名字，没有地址，临时量）

int& ref = x;        // 左值引用
// int& ref2 = x + 1; // 编译错误！不能将左值引用绑定到右值

int&& rref = x + 1;  // 右值引用：可以绑定到右值
// int&& rref2 = x;   // 编译错误！不能将右值引用绑定到左值
```

| 类别 | 特征 | 示例 |
|------|------|------|
| **左值（lvalue）** | 有身份、有名字、可取地址 | 变量名、`*ptr`、`a[i]`、`++it` |
| **纯右值（prvalue）** | 临时量、无身份 | `42`、`x + y`、`&x`、Lambda |
| **亡值（xvalue）** | 有身份但可移动 | `std::move(x)`、`static_cast<T&&>(x)` |

## 右值引用（Rvalue Reference, T&&）

```cpp
void func(int& x)  { std::cout << "lvalue ref\n"; }     // 左值引用
void func(int&& x) { std::cout << "rvalue ref\n"; }     // 右值引用

int a = 1;
func(a);          // 输出 "lvalue ref"
func(42);         // 输出 "rvalue ref"
func(std::move(a)); // 输出 "rvalue ref"（用 move 把左值转为右值）
```

## 移动构造函数与移动赋值

```cpp
class Buffer {
    int* data;
    size_t size;
public:
    // 构造函数
    explicit Buffer(size_t n) : size(n), data(new int[n]) {
        std::cout << "Construct\n";
    }

    // 拷贝构造函数
    Buffer(const Buffer& other)
        : size(other.size), data(new int[other.size]) {
        std::copy(other.data, other.data + size, data);
        std::cout << "Copy\n";
    }

    // 移动构造函数
    Buffer(Buffer&& other) noexcept
        : data(other.data), size(other.size) {
        other.data = nullptr;     // 原对象置空
        other.size = 0;
        std::cout << "Move\n";
    }

    // 移动赋值
    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data;             // 释放自身资源
            data = other.data;         // 窃取资源
            size = other.size;
            other.data = nullptr;     // 原对象置空
            other.size = 0;
        }
        return *this;
    }

    // 析构函数
    ~Buffer() { delete[] data; }

    // 禁止拷贝赋值（简化示例）
    Buffer& operator=(const Buffer&) = delete;
};

// 使用
Buffer createBuffer() {
    return Buffer(1024);              // 返回临时对象，触发移动（或 RVO）
}

Buffer a(100);                        // Construct
Buffer b = std::move(a);             // Move（a 被置空，不再拥有资源）
// 注意：移动后 a 处于有效但未指定的状态——可以析构，不应再使用 a.data
```

### noexcept 的重要性

```cpp
void foo(Buffer b) { /*...*/ }

std::vector<Buffer> vec;
Buffer buf(100);

vec.push_back(std::move(buf));  // 如果移动构造函数是 noexcept，vector 增长时会移动而非拷贝
                                // 如果非 noexcept，vector 为保证异常安全退化为拷贝！
```

> **关键规则**: `std::vector` push_back 时，如果移动构造函数不是 `noexcept`，则使用拷贝构造函数（更强的异常安全保证）。

## std::move —— 它并不移动

```cpp
Buffer a(100);
Buffer b = std::move(a);     // std::move(a) 只是把 a 转为右值引用，触发移动构造
```

`std::move` 的本质只是一个 `static_cast<T&&>` 的包装：

```cpp
// std::move 的近似实现
template <typename T>
constexpr std::remove_reference_t<T>&& move(T&& t) noexcept {
    return static_cast<std::remove_reference_t<T>&&>(t);
}
```

**关键理解**: `std::move` 不做任何实际移动操作，它只是一个**类型转换**——将参数转为右值引用，从而允许移动构造函数/赋值被选中。

## 完美转发（Perfect Forwarding）

### 转发引用 / 万能引用

```cpp
template <typename T>
void wrapper(T&& arg) {              // T&& 不是右值引用，而是转发引用
    // 看似右值引用，实际行为取决于传入参数类型
    foo(std::forward<T>(arg));        // 保持参数的左值/右值属性
}

int x = 42;
wrapper(x);          // T = int&,   arg 是左值引用
wrapper(42);         // T = int,    arg 是右值引用
```

| 上下文 | `T&&` 含义 | 示例 |
|--------|-----------|------|
| 模板参数 `template<typename T> void f(T&&)` | **转发引用**（万能引用） | 可绑定左值或右值 |
| `auto&&` | **转发引用** | `auto&& x = expr;` |
| 具体类型 `void f(int&&)` | **右值引用** | 仅绑定右值 |

### std::forward

```cpp
#include <utility>

// 可变参数的完美转发
template <typename... Args>
void logAndExecute(Args&&... args) {
    std::cout << "Calling function\n";
    actualFunction(std::forward<Args>(args)...);   // 完美转发所有参数
}

// std::forward 的近似实现
template <typename T>
T&& forward(std::remove_reference_t<T>& t) noexcept {
    return static_cast<T&&>(t);
}
// 如果 T = int&,  则 T&& = int&,  forward 返回左值引用
// 如果 T = int,   则 T&& = int&&, forward 返回右值引用
```

### 完美转发的实际用途

```cpp
class Widget {
    std::string name;
public:
    // 完美转发构造：避免不必要的拷贝/移动
    template <typename S>
    explicit Widget(S&& n) : name(std::forward<S>(n)) {}
};

std::string s("hello");
Widget w1(s);                    // 拷贝一次（s 是左值）
Widget w2(std::move(s));         // 移动一次（s 被转为右值）
Widget w3("temporary");          // 零拷贝（字符串字面量直接构造）
```

## RVO / NRVO（返回值优化）

```cpp
Buffer makeBuffer() {
    Buffer b(100);               // 局部变量
    return b;                    // NRVO（Named Return Value Optimization）
}

Buffer b = makeBuffer();         // C++17 起：保证 RVO（拷贝/移动被省略）

// 编译器允许省略拷贝/移动构造，即使它们有 side effect（如打印）
// 在 C++17 中，纯右值不被具体化之前不做拷贝
```

| 优化 | 说明 |
|------|------|
| **RVO** | 返回临时对象时省略拷贝/移动 |
| **NRVO** | 返回具名局部变量时省略拷贝/移动（非强制的） |
| **C++17 Guaranteed RVO** | 返回纯右值（prvalue）时**强制**省略拷贝 |

### 何时不应该使用 std::move

```cpp
// 错误：阻止了 NRVO
std::string createString() {
    std::string s = "hello";
    return std::move(s);        // 阻止 NRVO！强制移动构造
}

// 正确：让编译器自行决定 NRVO
std::string createString() {
    std::string s = "hello";
    return s;                   // 可能 NRVO（零拷贝）或隐式 move
}
```

| 场景 | 建议 |
|------|------|
| 函数返回值 | 直接 `return x;`，编译器自动处理 |
| 函数参数传递 | 不再需要时用 `std::move` |
| 容器插入 | 不再需要时用 `std::move` |
| `std::move(this->field)` | 避免——移动后对象状态可能被破坏 |

## 拷贝与移动对比

```
拷贝构造：深拷贝所有数据
┌────┐      ┌────┐
│ a  │ ───→ │ b  │  两对象各自持有独立资源
│data│      │data│
└────┘      └────┘

移动构造：窃取资源
┌────┐      ┌────┐
│ a  │      │ b  │  原对象被置空
│null│ ←── │data│  新对象拥有原资源
└────┘      └────┘
```

| 操作 | 复杂度 | 异常保证 |
|------|--------|----------|
| 拷贝 1GB vector | O(1GB) | 强异常保证（拷贝失败原对象不变） |
| 移动 1GB vector | O(1)（3 个指针赋值） | noexcept（无资源分配） |
