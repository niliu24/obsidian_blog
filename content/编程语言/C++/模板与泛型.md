> 模板（Template）是 C++ 泛型编程的基础，允许编写与类型无关的通用代码。C++ 模板是**图灵完备**的编译期元编程语言，由 C++98 引入，历经 C++11 可变参模板、C++17 `if constexpr`、C++20 Concepts 的持续增强。

## 函数模板

```cpp
template <typename T>
T max(T a, T b) {
    return (a > b) ? a : b;
}

// 使用
max(3, 7);                    // 推导 T = int
max(3.14, 2.72);              // 推导 T = double
max<double>(3, 4.5);          // 显式指定 T = double

// 多个类型参数
template <typename T, typename U>
auto sum(T a, U b) -> decltype(a + b) {     // 尾置返回类型（C++11）
    return a + b;
}

// C++14 起可简写
template <typename T, typename U>
auto sum(T a, U b) {
    return a + b;
}
```

### 模板参数推导

| 机制 | 说明 | 示例 |
|------|------|------|
| **隐式推导** | 编译器根据参数类型推断模板参数 | `max(1, 2)` → `T=int` |
| **显式指定** | 调用时用尖括号指定 | `max<double>(1, 2.5)` |
| **默认模板参数** | C++11 支持 | `template <typename T = int>` |

## 类模板

```cpp
template <typename T>
class Stack {
    std::vector<T> data;
public:
    void push(const T& value) { data.push_back(value); }
    T pop() {
        T top = data.back();
        data.pop_back();
        return top;
    }
    bool empty() const { return data.empty(); }
};

// 使用
Stack<int> intStack;
intStack.push(42);

Stack<std::string> stringStack;
stringStack.push("hello");

// 模板成员函数类外定义
template <typename T>
void Stack<T>::push(const T& value) {
    data.push_back(value);
}
```

### 非类型模板参数

```cpp
template <typename T, size_t N>
class Array {
    T data[N];
public:
    constexpr size_t size() const { return N; }
    T& operator[](size_t i) { return data[i]; }
};

Array<int, 100> arr;                    // 100 个 int 的固定数组
```

## 模板特化

### 完全特化（Full Specialization）

```cpp
// 通用模板
template <typename T>
struct IsPointer { static constexpr bool value = false; };

// 对指针类型的完全特化
template <typename T>
struct IsPointer<T*> { static constexpr bool value = true; };

IsPointer<int>::value;      // false
IsPointer<int*>::value;     // true
```

### 偏特化（Partial Specialization）

```cpp
// 通用模板
template <typename T, typename U>
struct Pair { /*...*/ };

// 偏特化：两个类型相同时
template <typename T>
struct Pair<T, T> { /*...*/ };

// 偏特化：第二个参数为指针时
template <typename T, typename U>
struct Pair<T, U*> { /*...*/ };
```

> **特化规则**: 完全特化可以用于函数模板和类模板；**偏特化只能用于类模板**（函数模板偏特化通过重载实现）。

## SFINAE（Substitution Failure Is Not An Error）

SFINAE 是模板元编程的核心原则：当模板参数替换失败时，编译器**不会报错**，只是从重载集合中移除该候选。

```cpp
// 辅助工具：只有 T 是整数类型时才启用
template <typename T,
          typename = std::enable_if_t<std::is_integral_v<T>>>
T half(T value) {
    return value / 2;
}

// 只有 T 是浮点类型时才启用
template <typename T,
          typename = std::enable_if_t<std::is_floating_point_v<T>>>
T half(T value) {
    return value / 2.0;
}

half(10);           // 调用 int 版本
half(3.14);         // 调用 double 版本
// half("hello");   // 编译错误：无匹配的重载
```

### enable_if 惯用写法

```cpp
// 作为返回类型（C++11）
template <typename T>
auto compute(T value) -> std::enable_if_t<std::is_integral_v<T>, T> {
    return value * 2;
}

// 作为默认模板参数（C++11）
template <typename T, std::enable_if_t<std::is_floating_point_v<T>, int> = 0>
T compute(T value) {
    return value * 2.0;
}

// C++17: if constexpr（更简洁）
template <typename T>
auto compute(T value) {
    if constexpr (std::is_integral_v<T>) {
        return value * 2;
    } else if constexpr (std::is_floating_point_v<T>) {
        return value * 2.0;
    } else {
        static_assert(false, "Unsupported type");
    }
}
```

## 可变参数模板（Variadic Templates, C++11）

```cpp
// 基本递归结构
template <typename T>
T sum(T t) {                          // 终止函数
    return t;
}

template <typename T, typename... Args>
T sum(T first, Args... args) {        // 包展开
    return first + sum(args...);
}

sum(1, 2, 3, 4, 5);                   // 15
```

### 折叠表达式（Fold Expressions, C++17）

```cpp
// 一元右折叠 (args op ...)
template <typename... Args>
auto sum(Args... args) {
    return (args + ...);              // ((a + b) + c) + d
}

// 一元左折叠 (... op args)
template <typename... Args>
auto sum_left(Args... args) {
    return (... + args);              // a + (b + (c + d))
}

// 二元折叠
template <typename... Args>
void print(Args... args) {
    (std::cout << ... << args) << "\n";  // cout << a << b << c << d
}

// 使用逗号运算符遍历
template <typename... Args>
void forEach(Args... args) {
    ((std::cout << args << " "), ...);   // 逗号表达式包展开
}

// 检查包中所有元素满足条件
template <typename... Args>
bool allPositive(Args... args) {
    return ((args > 0) && ...);
}
allPositive(1, 2, 3);      // true
allPositive(1, -1, 3);     // false
```

## Concepts（C++20）

Concepts 解决了模板的错误信息难以阅读和约束不明确的问题。

```cpp
#include <concepts>

// 定义 Concept
template <typename T>
concept Integral = std::is_integral_v<T>;

template <typename T>
concept Hashable = requires(T t) {
    { std::hash<T>{}(t) } -> std::convertible_to<std::size_t>;
};

// 使用 Concept（三种方式）
// 1. template 参数约束
template <Integral T>
T half(T value) { return value / 2; }

// 2. requires 子句
template <typename T> requires Hashable<T>
void useHash(const T& t) {
    auto h = std::hash<T>{}(t);
}

// 3. 缩写函数模板（C++20）
Integral auto triple(Integral auto value) {  // 等价于 template<Integral T>
    return value * 3;
}

// 自定义 Concept
template <typename T>
concept Printable = requires(T t, std::ostream& os) {
    { os << t } -> std::same_as<std::ostream&>;
};

template <Printable... Args>
void printAll(Args... args) {
    (std::cout << ... << args) << "\n";
}
```

## 模板元编程（TMP）

### 编译期计算

```cpp
// 阶乘的编译期计算（C++11 之前的方式）
template <int N>
struct Factorial {
    static constexpr int value = N * Factorial<N - 1>::value;
};

template <>
struct Factorial<0> {
    static constexpr int value = 1;
};

static_assert(Factorial<5>::value == 120);

// C++14 起更简洁
constexpr int factorial(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) result *= i;
    return result;
}
static_assert(factorial(5) == 120);
```

### if constexpr（C++17）

```cpp
template <typename T>
auto toString(const T& value) {
    if constexpr (std::is_same_v<T, std::string>) {
        return value;                      // T = string 时编译
    } else if constexpr (std::is_arithmetic_v<T>) {
        return std::to_string(value);      // T = int/double 时编译
    } else {
        return std::string("?");           // 其余类型
    }
}

// if constexpr 确保未选中的分支在实例化时不编译
// 和普通 if 不同——普通 if 两分支都必须能编译
```

### 类型萃取（Type Traits）

```cpp
#include <type_traits>

template <typename T>
void foo(T value) {
    // 编译期查询类型属性
    static_assert(std::is_copy_constructible_v<T>, "T must be copyable");

    using CleanType = std::remove_cvref_t<T>;  // 去掉 const/volatile/引用
    using ElementType = typename CleanType::value_type;  // 容器值类型

    if constexpr (std::is_pointer_v<T>) {
        // 指针分支
    }
}
```

## 编译模型注意事项

| 概念 | 说明 |
|------|------|
| **头文件实现** | 模板定义通常放在头文件中（非 .cpp），因为实例化时需要完整定义 |
| **显式实例化** | 在 .cpp 中 `template class std::vector<int>;` 避免重复实例化 |
| **export template** | C++98 曾支持但 C++11 移除（实现过于复杂） |
| **模块（C++20）** | 改善模板编译时间，通过 `export` 导出模板 |
