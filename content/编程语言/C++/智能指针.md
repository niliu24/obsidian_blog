> 智能指针是 C++11 引入的 RAII 封装，自动管理动态对象的生命周期。`<memory>` 头文件提供 `unique_ptr`（独占所有权）、`shared_ptr`（共享所有权）、`weak_ptr`（弱引用）。在现代 C++ 中应**避免使用裸 `new`/`delete`**。

## unique_ptr —— 独占所有权

`unique_ptr` 是**独占所有权**的智能指针，不可复制（copy 构造/赋值 = delete），只能移动。

```cpp
#include <memory>

struct Resource {
    Resource() { std::cout << "Acquire\n"; }
    ~Resource() { std::cout << "Release\n"; }
    void work() { std::cout << "Working\n"; }
};

// 推荐：make_unique（C++14）
auto ptr = std::make_unique<Resource>();

// 等价但不推荐：裸 new
// std::unique_ptr<Resource> ptr(new Resource());

ptr->work();                    // operator->

// 所有权转移（移动）
auto ptr2 = std::move(ptr);     // ptr 变为 nullptr
// auto ptr3 = ptr;             // 编译错误：不能复制

// 函数传参
void take(std::unique_ptr<Resource> p);      // 转移所有权
void borrow(const Resource& r);              // 不转移所有权：传引用
```

### 自定义删除器

```cpp
// 文件句柄：使用 fclose 而非 delete
auto file_deleter = [](FILE* fp) {
    if (fp) fclose(fp);
    std::cout << "File closed\n";
};

std::unique_ptr<FILE, decltype(file_deleter)> fp(fopen("test.txt", "w"), file_deleter);
```

> `unique_ptr` 自定义删除器是类型签名的一部分，不同删除器产生不同类型。

### 数组特化

```cpp
std::unique_ptr<int[]> arr(new int[100]);  // 调用 delete[]
// 或
auto arr = std::make_unique<int[]>(100);   // C++20 支持
arr[0] = 42;
```

## shared_ptr —— 共享所有权

`shared_ptr` 通过**引用计数**实现共享所有权。最后一个 `shared_ptr` 销毁时释放资源。

```cpp
auto p1 = std::make_shared<Resource>();
{
    auto p2 = p1;           // 引用计数 = 2
    auto p3 = p1;           // 引用计数 = 3
    p2->work();
}                           // p2、p3 销毁，引用计数 = 1
                            // p1 销毁，引用计数 = 0，释放 Resource
```

### 控制块（Control Block）

```
make_shared 分配的内存:
┌──────────────────────────────┐
│ Resource 对象                │  ← 引用计数 + 弱计数 + 删除器等
│                              │
│ 控制块（嵌入在对象前方/后方）  │
│ ┌────────────┐              │
│ │ ref_count  │   = 1        │
│ │ weak_count │   = 0        │
│ │ deleter    │              │
│ │ allocator  │              │
│ └────────────┘              │
└──────────────────────────────┘
```

### make_shared 优化

```cpp
// 推荐：一次分配，对象和控制块在同一内存块
auto p = std::make_shared<Resource>();

// 不推荐：两次分配，且异常不安全（在 C++17 中已修复）
std::shared_ptr<Resource> p2(new Resource());
```

| 方式 | 内存分配次数 | 异常安全性 | 内存局部性 |
|------|-------------|-----------|-----------|
| `make_shared` | 1 次（对象 + 控制块） | 好 | 好 |
| `shared_ptr(new T)` | 2 次（对象 + 控制块） | 差（C++17 前） | 差 |

> **`make_shared` 的弱点**: 控制块和对象在同一内存块，若仍有 `weak_ptr` 存活，即使 `shared_ptr` 全销毁，对象内存也不会释放（只能释放对象本身，但控制块所在内存块仍在）。

### 别名构造函数（Aliasing Constructor）

```cpp
struct Big { int data[1024]; };
struct Small { int x; };

auto big = std::make_shared<Big>();
// 共享 big 的控制块，但指向 big->data
std::shared_ptr<int> alias(big, &big->data[0]);
// 此时两个 shared_ptr 共享同一控制块，big 不会被提前释放
```

## weak_ptr —— 弱引用

`weak_ptr` 不增加引用计数，用于**打破循环引用**。

```cpp
class Node {
public:
    std::shared_ptr<Node> next;
    ~Node() { std::cout << "~Node()\n"; }
};

{
    auto a = std::make_shared<Node>();
    auto b = std::make_shared<Node>();
    a->next = b;
    b->next = a;         // 循环引用！a 和 b 永远不会被释放（内存泄漏）
}
```

### 用 weak_ptr 打破循环

```cpp
class Node {
public:
    std::weak_ptr<Node> next;   // 弱引用
    ~Node() { std::cout << "~Node()\n"; }
};

{
    auto a = std::make_shared<Node>();
    auto b = std::make_shared<Node>();
    a->next = b;
    b->next = a;                     // 不增加引用计数，无循环
}   // a、b 正确销毁
```

### weak_ptr 用法

```cpp
auto sp = std::make_shared<int>(42);
std::weak_ptr<int> wp = sp;

// 访问前需要 lock() —— 转换为 shared_ptr
if (auto locked = wp.lock()) {
    std::cout << *locked << "\n";    // 42
} else {
    std::cout << "对象已释放\n";
}

sp.reset();          // 释放对象
// wp.lock() → 返回空的 shared_ptr（因为对象已释放）
```

| `weak_ptr` 方法 | 说明 |
|-----------------|------|
| `lock()` | 返回 `shared_ptr`，若对象已释放则返回空 |
| `expired()` | 检查引用计数是否为 0 |
| `use_count()` | 返回 `shared_ptr` 的数量（调试用） |

## 比较与选择

| 特性 | `unique_ptr` | `shared_ptr` | `weak_ptr` |
|------|-------------|-------------|-----------|
| 所有权 | 独占 | 共享 | 无（弱引用） |
| 开销 | 与裸指针相同 | 控制块 + 原子计数 | 控制块引用 |
| 可复制 | 否（只能移动） | 是（计数 +1） | 是 |
| 线程安全 | 是（移动） | 是（引用计数原子操作） | 同 shared |
| 自定义删除器 | 是（类型参数） | 是（类型擦除） | — |
| 转换 | → `shared_ptr` | → `weak_ptr` | → `shared_ptr` (lock) |

### 使用指南

| 场景 | 推荐 |
|------|------|
| 独占资源、明确所有权 | `unique_ptr` |
| 共享所有权、不确定生命周期 | `shared_ptr` |
| 观察者、缓存、打破循环 | `weak_ptr` |
| 函数参数（不涉及所有权） | `T&` 或 `const T&` |
| 函数参数（转移所有权） | `unique_ptr` by value |
| 工厂函数返回值 | `unique_ptr`（可隐式转换为 `shared_ptr`） |

### 总结示例

```cpp
class Database {
    std::shared_ptr<Connection> conn;
public:
    explicit Database(std::shared_ptr<Connection> c) : conn(std::move(c)) {}
    void runQuery(const std::string& sql) { /*...*/ }
};

class ConnectionPool {
    std::vector<std::weak_ptr<Connection>> connections;
public:
    std::shared_ptr<Connection> acquire() {
        // 清理过期连接
        std::erase_if(connections, [](auto& wp) { return wp.expired(); });
        // ... 创建新连接
        auto conn = std::make_shared<Connection>();
        connections.push_back(conn);
        return conn;
    }
};
```
