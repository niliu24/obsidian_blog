C 通过 `<stdlib.h>` 提供的函数在堆（heap）上动态分配内存。与栈上的自动变量不同，堆内存的生命周期由程序员手动控制，这是 C 强大与危险的来源。

## 内存布局

```
高地址 ┌──────────┐
      │   栈     │ ← 局部变量、函数调用帧，自动管理
      │   ↓      │
      │          │
      │   ↑      │
      │   堆     │ ← 动态分配区域，手动管理
      ├──────────┤
      │  BSS 段  │ ← 未初始化全局/静态变量
      ├──────────┤
      │ 数据段   │ ← 已初始化全局/静态变量
      ├──────────┤
低地址 │ 代码段   │ ← 程序指令，只读
      └──────────┘
```

## 内存分配函数

```c
void *malloc(size_t size);                // 分配未初始化内存
void *calloc(size_t nmemb, size_t size);  // 分配并清零
void *realloc(void *ptr, size_t size);    // 调整已分配内存大小
void free(void *ptr);                     // 释放内存
```

### malloc

```c
int *p = (int *)malloc(sizeof(int) * 10);  // 分配 10 个 int 的空间
if (p == NULL) {
    // 分配失败处理
}
```

`malloc` 分配的字节内容未初始化（包含随机值），必须检查返回是否为 `NULL`。C 中 `malloc` 返回值可隐式转为任意指针类型，但建议显式转型以兼容 C++。

### calloc

```c
int *p = (int *)calloc(10, sizeof(int));  // 分配 10 个 int，全部初始化为 0
```

`calloc` 在分配后会将所有字节置零。参数为（元素个数，每个元素大小）。

### realloc

```c
int *p = (int *)malloc(sizeof(int) * 5);
// ... 使用 p ...
int *tmp = (int *)realloc(p, sizeof(int) * 10);  // 扩容到 10 个 int
if (tmp == NULL) {
    free(p);      // realloc 失败时原内存仍有效，需释放
    return -1;
}
p = tmp;
```

`realloc` 尝试原地扩展/收缩内存。若原地无法满足，会分配新块、复制旧数据、释放旧块。`realloc(NULL, size)` 等价于 `malloc(size)`，`realloc(p, 0)` 等价于 `free(p)`（实现定义行为）。

### free

```c
free(p);    // 释放 p 指向的内存
p = NULL;   // 避免悬垂指针
```

每条 `malloc`/`calloc`/`realloc`（成功的）必须有对应的 `free`。`free(NULL)` 是安全的，什么都不做。

## 常见内存错误

| 错误类型 | 示例 | 后果 |
|---------|------|------|
| 内存泄漏 | `malloc` 后未 `free` | 内存持续增长，最终耗尽 |
| 悬垂指针 | `free(p)` 后再访问 `*p` | 未定义行为 |
| 重复释放 | 同一指针 `free` 两次 | 破坏堆结构，通常崩溃 |
| 越界访问 | `p[10]` 但只分配了 5 个元素 | 破坏相邻内存，未定义行为 |
| 使用未分配内存 | 解引用 `NULL` 或未初始化的指针 | 段错误 (segfault) |
| 释放非堆内存 | `free` 栈变量或全局变量的地址 | 未定义行为 |
| 释放已偏移指针 | `free(p + 1)` | 堆元数据错乱 |

## 最佳实践

1. 每次 `malloc` 都检查返回值是否为 `NULL`
2. `free` 后立即将指针置为 `NULL`
3. 一个分配对应一个释放，成对编写（类似 RAII 思想）
4. 保存 `malloc` 返回的原始指针，不要偏移后再 `free`
5. 使用工具检测内存错误：Valgrind（memcheck）、AddressSanitizer（`-fsanitize=address`）
6. 考虑在较高层次使用内存池（memory pool）减少碎片和分配开销
