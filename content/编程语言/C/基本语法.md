C 语言是面向过程的编译型语言，1972 年诞生于贝尔实验室，由 Dennis Ritchie 设计。它是 UNIX 系统的核心语言，也是操作系统、嵌入式、驱动开发等领域的基础。

## 程序结构

一个完整的 C 程序从 `main()` 开始执行：

```c
#include <stdio.h>          // 预处理指令，引入标准 I/O 库

int main(int argc, char *argv[]) {
    printf("Hello, World!\n");   // 输出到标准输出
    return 0;                    // 返回值给操作系统
}
```

* `#include`：预处理指令，在编译前将头文件内容插入源文件
* `main()`：程序入口，返回 `int`，0 表示正常退出
* `{}`：代码块边界
* 每条语句以 `;` 结尾
* `//` 单行注释，`/* */` 多行注释

## 数据类型

| 类型 | 关键字 | 32 位大小 | 64 位大小 | 说明 |
|------|--------|---------|---------|------|
| 字符 | `char` | 1 | 1 | 最小可寻址单元 |
| 短整型 | `short` | 2 | 2 | |
| 整型 | `int` | 4 | 4 | 最自然的整数类型 |
| 长整型 | `long` | 4 | 8 | 32 位下 4 字节，64 位 Linux 下 8 字节 |
| 长长整型 | `long long` | 8 | 8 | C99 |
| 单精度浮点 | `float` | 4 | 4 | 约 6-7 位有效数字 |
| 双精度浮点 | `double` | 8 | 8 | 约 15-16 位有效数字 |
| 长双精度 | `long double` | 12/16 | 16 | 实现相关 |
| 空类型 | `void` | - | - | 无值/无参数/无返回值 |
| 布尔 | `_Bool` | 1 | 1 | C99，`stdbool.h` 提供 `bool` 别名 |

`sizeof` 运算符返回类型或变量占用的字节数，`sizeof(int)` 的具体值取决于平台和编译器。

### 整型限定符

* `signed`：有符号（默认）
* `unsigned`：无符号，表示非负数，范围扩大一倍
* 例：`unsigned int` 范围 0 到 2³²-1（32 位下）

### 类型转换

* **隐式转换**：低精度 → 高精度自动提升（整型提升）
* **显式转换**（强制类型转换）：`(type)expression`
* 在表达式和赋值中，较小类型会自动提升到 `int` 或 `unsigned int`

## 控制流

### 条件语句

```c
if (condition) {
    // ...
} else if (condition2) {
    // ...
} else {
    // ...
}
```

```c
// switch 用于多分支选择，表达式必须是整数类型
switch (expression) {
    case 1:
        // ...
        break;          // 跳出 switch，没有 break 会 fall-through
    case 2:
        // ...
        break;
    default:            // 可选的默认分支
        // ...
}
```

### 循环语句

```c
// while：先判断后执行，可能执行零次
while (condition) { /* ... */ }

// do-while：先执行后判断，至少执行一次
do { /* ... */ } while (condition);

// for：初始化 → 判断 → 循环体 → 更新 → 判断...
for (int i = 0; i < N; i++) { /* ... */ }
```

`break` 跳出当前循环，`continue` 跳过本次循环剩余部分。`goto` 跳转到标签位置，应谨慎使用（通常仅在错误处理统一清理时使用）。

## 函数

```c
// 声明（原型）
int add(int a, int b);

// 定义
int add(int a, int b) {
    return a + b;
}
```

* **参数传递**：C 中参数按值传递（pass by value），函数内修改形参不影响实参
* **return**：返回一个值给调用者，`void` 函数可用 `return;` 直接返回
* **递归**：函数可调用自身
* **函数指针**：`int (*fp)(int, int) = &add;` 调用：`fp(3, 4)` 或 `(*fp)(3, 4)`

`main` 函数的两种标准签名：

```c
int main(void);
int main(int argc, char *argv[]);  // argc: 参数个数, argv: 参数字符串数组
```

## 数组

```c
int arr[5];                 // 声明，未初始化（值不确定）
int arr[5] = {1, 2, 3};     // 初始化，剩余元素自动补 0
int arr[] = {1, 2, 3};      // 大小自动推导为 3

int matrix[3][4];           // 二维数组，3行4列
int matrix[2][3] = {{1,2,3}, {4,5,6}};
```

* 下标从 0 开始
* 数组名在大多数表达式中退化为指向首元素的指针
* 越界访问不检查，属于未定义行为
* 数组名不是可修改的左值（`arr = p;` 非法）
* 数组作为函数参数时退化为指针：`void func(int a[], int n)` 等价于 `void func(int *a, int n)`

### 零长度数组与柔性数组成员

结构体的最后一个成员可以是大小未知的数组，用于实现变长结构体，一次分配即可容纳结构体元数据 + 可变长度数据。

```c
// GCC 零长度数组（GCC 扩展，C99 前使用）
struct Buffer {
    int len;
    char data[0];    // 不占空间，标记可变数据的起始位置
};

// C99 柔性数组成员（标准方式）
struct Buffer {
    int len;
    char data[];     // 必须为最后一个成员，且结构体至少还有一个其他成员
};

// 分配：结构体大小 + 实际数据大小
int data_len = 100;
struct Buffer *buf = (struct Buffer *)malloc(sizeof(struct Buffer) + data_len);
buf->len = data_len;
buf->data[0] = 'a';   // 合法访问

// sizeof 不计算柔性数组成员
sizeof(struct Buffer) == sizeof(int);  // 仅包含 len 的大小（及对齐填充）
```

**关键规则**：

* 柔性数组成员必须是结构体的最后一个成员
* 结构体至少还要有一个其他命名成员
* `sizeof` 返回的大小不包含柔性数组成员（但可能包含对齐填充）
* 通过 `malloc` 分配额外空间来使用，不能声明为自动变量
* GCC 的 `char data[0]` 是 C99 前的过渡方案，新代码应使用 `char data[]`

典型应用：网络数据包、字符串表、文件系统元数据等需要 " 头部 + 可变长度载荷 " 的场景。

## 字符串

C 没有内置字符串类型，用 `char` 数组以空字符 `\0` 结尾表示：

```c
char s1[] = "hello";              // 自动分配 6 字节（含 '\0'）
char s2[6] = {'h','e','l','l','o','\0'};
char *s3 = "hello";               // 指向只读字符串字面量
```

常用 `<string.h>` 函数：

| 函数 | 说明 |
|------|------|
| `strlen(s)` | 返回字符串长度（不含 `\0`） |
| `strcpy(d,s)` | 复制 s 到 d |
| `strcat(d,s)` | 拼接 s 到 d 末尾 |
| `strcmp(a,b)` | 比较，返回 0 相等、<0 a<b、>0 a>b |
| `strchr(s,c)` | 查找字符 c 首次出现位置 |
| `strstr(h,n)` | 查找子串 n 在 h 中的位置 |
| `sprintf(buf,fmt,…)` | 格式化输出到字符串 |

`strcpy` 不检查缓冲区大小，安全版本用 `strncpy`。`gets` 已废弃（C11 移除），用 `fgets` 代替。

## 结构体与联合体

### 结构体 (struct)

```c
struct Point {
    int x;
    int y;
};

struct Point p1;                  // 声明变量
struct Point p2 = {10, 20};       // 初始化
p2.x = 30;                        // 成员访问

struct Point *pp = &p2;
pp->y = 40;                       // 通过指针访问成员

// typedef 简化
typedef struct {
    int x, y;
} Point;
Point p3 = {.y = 20, .x = 10};    // C99 指定初始化器
```

结构体内存布局：成员按声明顺序存放，可能有填充字节（padding）以满足对齐要求。`sizeof(struct)` 可能大于各成员之和。

### 位域 (Bit-field)

```c
struct Flags {
    unsigned int a : 1;
    unsigned int b : 3;
    unsigned int   : 4;  // 未命名位域，占位用的填充
    unsigned int c : 2;
};
```

### 联合体 (union)

所有成员共享同一块内存，大小等于最大成员的大小。同一时间只有一个成员有效。

```c
union Data {
    int i;
    float f;
    char str[20];
};
union Data d;
d.i = 10;       // 此时 d.i 有效
d.f = 3.14;     // 覆盖 d.i，现在 d.f 有效
```

常用于类型双关（type punning）、节省内存、实现变体类型。

## 枚举 (enum)

```c
enum Color { RED, GREEN, BLUE };            // RED=0, GREEN=1, BLUE=2
enum Color { RED = 1, GREEN, BLUE = 10 };   // RED=1, GREEN=2, BLUE=10
enum Color c = RED;
```

枚举是 `int` 类型的具名常量集合，增强代码可读性。

## 预处理器

预处理在编译前由预处理器（cpp）完成，处理以 `#` 开头的指令。

```c
#include <stdio.h>          // 系统头文件搜索路径
#include "myheader.h"       // 当前目录优先搜索

#define MAX 100             // 宏常量
#define SQUARE(x) ((x)*(x)) // 宏函数（注意括号防止运算符优先级问题）

#undef MAX                  // 取消宏定义

#ifdef DEBUG                 // 条件编译
    // ...
#else
    // ...
#endif

#ifndef HEADER_H            // 头文件保护，防止重复包含
#define HEADER_H            // 现代替代方案：#pragma once
// ...
#endif
```

宏只是文本替换，不做类型检查。宏函数参数可能有副作用（如 `SQUARE(i++)` 会展开为 `((i++)*(i++))` 产生未定义行为）。

预定义宏：`__FILE__` `__LINE__` `__DATE__` `__TIME__` `__STDC__` `__STDC_VERSION__`

## 存储类

| 关键字 | 生命周期 | 作用域 | 说明 |
|--------|---------|--------|------|
| `auto` | 自动（函数调用期间） | 块 | 默认存储类，几乎从不显式使用 |
| `register` | 自动 | 块 | 提示编译器将变量放寄存器，不可取地址（C 中） |
| `static` | 整个程序运行期 | 块/文件 | 函数内：持久化局部变量；文件作用域：内部链接 |
| `extern` | 整个程序运行期 | 全局 | 声明变量/函数在其他文件中定义 |

```c
void counter() {
    static int count = 0;   // 只初始化一次，值在多次调用间保持
    count++;
}
```

## 类型限定符

| 限定符 | 说明 |
|--------|------|
| `const` | 值不可修改，编译器会在尝试修改时报警告/错误 |
| `volatile` | 告知编译器变量可能被外部因素修改（硬件寄存器、信号处理、多线程），禁止优化 |
| `restrict` | C99，告知编译器指针是访问对应内存的唯一途径，帮助优化（如 `memcpy` 的原型） |
| `_Atomic` | C11，原子类型，保证读写操作的原子性 |

```c
const int *p;          // *p 不可变
int *const p;          // p 不可变
volatile int status;   // 每次读取都从内存加载，不缓存到寄存器
```
