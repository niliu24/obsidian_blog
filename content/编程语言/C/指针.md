指针是存储内存地址的变量，是 C 最核心也最复杂的特性。指针提供直接操作内存的能力，是 C 高效和灵活的重要来源。

## 指针基础

```c
int x = 10;
int *p = &x;         // p 指向 x 的地址
printf("%d\n", *p);  // 解引用，输出 10
*p = 20;             // 通过指针修改 x
```

* `&` 取地址运算符，返回变量的内存地址
* `*` 解引用运算符，访问指针指向的值
* 指针变量本身也存储在内存中，也有自己的地址

## 指针与数组

数组名在大多数表达式中退化为指向首元素的指针：

```c
int arr[] = {1, 2, 3};
int *p = arr;        // 等价于 int *p = &arr[0];
// arr[i] 等价于 *(arr + i) 等价于 p[i] 等价于 *(p + i)
```

关键区别：`sizeof(arr)` 返回整个数组的大小，`sizeof(p)` 返回指针本身的大小。数组名不是可修改的左值（`arr = p;` 非法）。

## 指针算术

指针与整数做加减时，按指针指向类型的大小为步长移动：

```c
int arr[] = {10, 20, 30, 40};
int *p = arr;
p + 1;    // 地址增加 sizeof(int)，指向 arr[1]
p + 2;    // 地址增加 2 * sizeof(int)，指向 arr[2]
```

`p + n` 移动 `n * sizeof(*p)` 字节。两个同类型指针相减得到元素个数，结果为 `ptrdiff_t` 类型。指针比较（`<` `>` `==` `!=`）在同一数组内有效。

## 多级指针

```c
int x = 10;
int *p = &x;       // 一级指针
int **pp = &p;     // 二级指针，指向指针的指针

**pp = 30;         // 通过二级指针修改 x 的值
```

多级指针常用于函数需要修改指针本身（如动态分配二维数组）、`main` 的 `argv` 参数等场景。

## const 与指针

```c
const int *p;        // 指向的值为常量，不能通过 p 修改 (*p) 不可写
int *const p;        // 指针本身为常量，不能修改 p 的指向
const int *const p;  // 指针和指向的值都为常量，两者都不可修改
```

记忆方法：从右向左读。`const` 修饰其左侧的类型（若左侧无类型则修饰右侧）。

## void 指针

```c
void *vp;            // 通用指针，可接受任意类型的地址
int x = 10;
vp = &x;             // 合法，任意类型指针可隐式转为 void*

// 使用时必须强制类型转换
int *ip = (int *)vp;
printf("%d\n", *ip);
```

`void*` 常用于通用接口（如 `malloc` 返回 `void*`，`memcpy` 参数为 `void*`）。不能直接解引用 `void*`，不能做指针算术（GCC 扩展允许，但非标准）。

## 函数指针

函数指针指向代码段中的函数地址，用于实现回调和动态调用：

```c
int add(int a, int b) { return a + b; }

int (*func_ptr)(int, int);          // 声明：指向返回 int、接受两个 int 参数的函数
func_ptr = &add;                    // 赋值（& 可省略）
int result = func_ptr(3, 4);        // 调用（* 可省略）

// 回调：将函数作为参数传递
void foreach(int *arr, int n, int (*fn)(int)) {
    for (int i = 0; i < n; i++) arr[i] = fn(arr[i]);
}
```

函数指针常用场景：`qsort` 的比较函数、信号处理的回调（`signal`）、状态机/插件架构。

## 野指针与悬垂指针

```c
// 野指针：未初始化的指针，指向随机地址
int *p;                // 危险！值不确定
*p = 10;               // 未定义行为

// 悬垂指针：指向已释放内存的指针
int *p = malloc(sizeof(int));
free(p);
*p = 10;               // 危险！p 指向已释放的内存
```

正确做法：声明时初始化为 `NULL`，`free` 后置为 `NULL`。
