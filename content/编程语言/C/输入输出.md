C 标准库通过 `<stdio.h>` 提供输入输出功能，包括标准流（stdin/stdout/stderr）和文件操作。

## 标准流

程序启动时自动打开三个标准流：

| 流 | 文件指针 | 说明 |
|----|---------|------|
| 标准输入 | `stdin` | 默认来自键盘 |
| 标准输出 | `stdout` | 默认输出到屏幕（行缓冲） |
| 标准错误 | `stderr` | 默认输出到屏幕（无缓冲） |

## 格式化输出 (printf)

```c
int printf(const char *format, ...);
```

`printf` 将格式化字符串写入 `stdout`，返回写入的字符数。

```c
printf("整数: %d, 浮点: %f, 字符: %c, 字符串: %s, 指针: %p\n",
       42, 3.14, 'A', "hello", (void*)&x);
```

### 主要格式说明符

| 说明符 | 类型 | 说明符 | 类型 |
|--------|------|--------|------|
| `%d` / `%i` | int (有符号十进制) | `%u` | unsigned int |
| `%ld` | long | `%lu` | unsigned long |
| `%lld` | long long | `%f` / `%lf` | float / double |
| `%c` | char | `%s` | char* (字符串) |
| `%p` | void* (地址) | `%x` / `%X` | 十六进制 (小写/大写) |
| `%o` | 八进制 | `%e` / `%E` | 科学计数法 |
| `%%` | 输出 `%` 字符 | `%zu` | size_t |

常用格式化标志：`%-10d`（左对齐宽 10）、`%04d`（补零宽 4）、`%.2f`（保留 2 位小数）。

## 格式化输入 (scanf)

```c
int scanf(const char *format, ...);
```

`scanf` 从 `stdin` 读取格式化输入，**参数必须是指针**。返回成功匹配并赋值的项数，失败时返回 `EOF`。

```c
int age;
char name[32];
scanf("%d %s", &age, name);   // name 是数组，已退化为指针，不需要 & 
```

`scanf` 读取字符串遇到空白字符（空格、制表符、换行）会停止。读取一行用 `fgets`。

## 字符 I/O

```c
int getchar(void);              // 从 stdin 读取一个字符，返回 EOF 表示结束
int putchar(int c);             // 向 stdout 写入一个字符
```

## 字符串 I/O

```c
char *fgets(char *s, int n, FILE *stream);  // 读取最多 n-1 个字符，保留换行
int puts(const char *s);                     // 输出字符串并自动追加换行
```

`fgets` 会保留读到的换行符（若有），并在末尾添加 `\0`。`gets` 因缓冲区溢出风险已在 C11 中被移除，永远用 `fgets` 代替。

## 文件操作

```c
FILE *fp = fopen("file.txt", "r");    // 打开文件
if (fp == NULL) { /* 错误处理 */ }

// 读写操作...

fclose(fp);                            // 关闭文件，刷新缓冲区
```

### 文件打开模式

| 模式 | 说明 |
|------|------|
| `"r"` | 只读，文件必须存在 |
| `"w"` | 只写，文件不存在则创建，存在则清空 |
| `"a"` | 追加，文件不存在则创建 |
| `"r+"` | 读写，文件必须存在 |
| `"w+"` | 读写，文件不存在则创建，存在则清空 |
| `"a+"` | 读 + 追加，文件不存在则创建 |
| `"rb"` / `"wb"` 等 | 二进制模式（b），行为同上 |

## 格式化文件 I/O

```c
int fprintf(FILE *stream, const char *format, ...);  // 格式化输出到文件
int fscanf(FILE *stream, const char *format, ...);    // 从文件格式化输入
int sprintf(char *buf, const char *format, ...);      // 格式化输出到字符串
int sscanf(const char *s, const char *format, ...);   // 从字符串格式化输入
int snprintf(char *buf, size_t n, const char *fmt, ...); // 安全版本，限制写入长度
```

推荐使用 `snprintf` 代替 `sprintf`，避免缓冲区溢出。

## 文件读写函数

```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);   // 二进制读
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream); // 二进制写
int fseek(FILE *stream, long offset, int whence);   // 移动文件位置指针
long ftell(FILE *stream);                            // 获取当前位置
void rewind(FILE *stream);                           // 回到文件开头
int feof(FILE *stream);                              // 检查是否到达文件末尾
int ferror(FILE *stream);                            // 检查流错误
```

二进制 I/O（`fread`/`fwrite`）按原始字节读写，不做格式转换。文本 I/O（`fprintf`/`fscanf`）会做格式解析和转换。

## 缓冲区

标准 I/O 使用三种缓冲策略：

| 缓冲类型 | 触发条件 | 典型使用 |
|---------|---------|---------|
| 全缓冲 | 缓冲区满 | 磁盘文件 |
| 行缓冲 | 遇到换行符 | `stdin`/`stdout`（连终端时） |
| 无缓冲 | 立即写入 | `stderr` |

`fflush(FILE *stream)` 强制刷新缓冲区。`setbuf`/`setvbuf` 可自定义缓冲行为。
